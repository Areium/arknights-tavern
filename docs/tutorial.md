# Arknights Tavern 使用教程

> 明日方舟主题的文字角色扮演（Text RPG）桌面程序。本文档面向玩家/使用者，介绍如何安装、配置与使用本程序的全部功能。
>
> 最后更新：2025 年。若界面与实际不符，以程序内实际显示为准。

---

## 一、程序简介

本程序是一款基于明日方舟世界观的**文字角色扮演游戏**，由本地后端（Python Flask）与桌面前端（Electron + React）组成，主要提供：

- **剧情模式** — LLM 驱动的沉浸式叙事，系统自动推进剧情、提供行动选项，并带有记忆、环境、任务等辅助系统
- **自由模式** — 沙盒式角色互动，可自由加载角色与物品、编辑环境，与单个或多个角色对话
- **回合制战斗** — 7×7 等距网格卡牌战斗，剧情中遭遇敌人时可进入战斗场景
- **世界书（Lorebook）** — 兼容酒馆（SillyTavern）世界书格式的关键词触发式设定注入
- **资产与索引** — 在线浏览、编辑角色/物品/世界观文档，并管理文档间引用关系

## 二、快速开始

### 2.1 环境要求

- Python 3.10+（后端）
- Node.js 18+（前端）
- 一个可用的 LLM 服务：云端 API（OpenAI 兼容）或本地 [Ollama](https://ollama.com)

### 2.2 安装依赖

```bash
# Python 后端依赖
pip install -r requirements.txt

# 前端依赖
cd frontend && npm install
```

### 2.3 启动服务

需要同时启动后端 API 与前端界面：

```bash
# 终端 1：启动后端 API 服务（监听 127.0.0.1:5000）
python src/app.py

# 终端 2：启动前端开发服务器（浏览器访问 http://localhost:5173）
cd frontend && npm run dev
```

也可以直接以桌面应用方式运行（自动拉起后端）：

```bash
cd frontend && npm run dev:electron
```

> 提示：前端通过 Vite 将 `/api` 请求代理到后端 5000 端口，因此**必须先启动后端**，否则界面会提示后端离线。

### 2.4 运行测试（可选）

```bash
python -m pytest tests/ -q
```

> 注：`tests/` 目录被 .gitignore 忽略（仓库约定），仅本地运行。

## 三、配置 LLM

打开左侧导航「⚙️ 设置」，在「LLM 配置」区域填写模型服务信息。

### 3.1 云端 API（OpenAI 兼容）

- **API Key** — 服务商提供的密钥
- **接口地址** — API 端点，如 `https://api.openai.com/v1` 或兼容服务地址
- **模型名称** — 如 `gpt-4o`、`deepseek-chat` 等
- 填写后点击「测试连接」验证是否可用

### 3.2 Ollama 本地模型

- **Ollama 地址** — 默认 `http://127.0.0.1:11434`
- **模型名称** — 需先安装 [Ollama](https://ollama.com) 并拉取模型，如 `ollama pull qwen2.5:7b`
- 点击「测试连接」验证

### 3.3 主备降级（可选）

可配置主/备两个模型服务。当主服务失败（连接错误、限流 429、5xx 等）时，程序会自动降级到备用服务，并在短暂冷却后尝试恢复主服务，保证对话不中断。

### 3.4 其他设置

- **主题** — 深色 / 浅色主题切换
- **叙述选项** — 见「剧情选项设置」一节

## 五、对话模式

左侧栏底部（对话页）可切换两种对话模式：

### 5.1 剧情模式（默认）

适合体验完整故事线：

- 系统自动推进剧情，生成场景叙述文本
- 每次叙述后提供行动选项（点击即可选择下一步行动）
- 剧情发展受环境、角色状态和之前的选择影响
- 支持回退到任意历史轮次重新选择（见「回退系统」）
- 场景角色、物品、环境由剧情自动加载，无需手动管理
- 对话中触发战斗时自动进入战斗场景

### 5.2 自由模式

适合与角色自由互动：

- 手动加载角色到场景中，自由对话
- 可选择与单个角色对话或发起群聊
- 自由编辑环境信息（地点、天气、时间）
- 手动管理场景中的角色与物品

## 六、会话管理

对话页左侧面板顶部为会话列表，当前模式的会话会自动过滤显示。

- **新建会话** — 点击「+ 新建」创建当前模式下的新会话
- **切换会话** — 点击会话条目即可切换，对话记录自动保存；切换会话不会丢失各自的消息与输入状态
- **重命名** — 双击会话名称进行重命名
- **删除** — 点击 ✕ 删除单个会话，或勾选多条后批量删除
- **回滚** — 支持将会话回滚到历史版本

> 会话数据保存在后端 `data/` 目录中，按模式（剧情/自由）分目录存储。

---

## 七、场景角色与物品

### 剧情模式

角色和物品由场景自动加载，无需手动操作。点击角色旁的「对话」按钮可切换当前对话目标。

### 自由模式

- 点击「+ 添加」打开角色库/物品库，选择后加载到当前场景
- 悬停角色或物品可预览详细属性
- 点击 📌 可固定详情卡片；固定后可在线编辑，修改仅影响当前会话（会话级覆盖）
- 会话资源面板可管理形象/背景覆盖（见「会话资源」一节）

---

## 八、环境控制

- **自由模式** — 点击「编辑」可从预设下拉列表中选择地点/天气/时间，或选择「✏️ 自定义...」输入任意值
- **剧情模式** — 环境由剧情发展决定，不可直接修改；点击「切换场景」可从预设地点中选择目的地，选择后系统自动生成场景过渡叙述

---

## 九、剧情回忆

剧情模式下，左侧面板底部会显示「回忆」卡片。系统每隔一定轮次自动调用 LLM 将最近的剧情进展总结为章节回忆：

- 回忆以手风琴列表展示，点击展开查看完整摘要
- 默认展开最新一条回忆
- 点击「重新生成」可清除已有回忆，按当前设置重新总结全部历史
- 回忆间隔可在设置页面调整（1-20 轮，默认 5 轮）

---

## 十、回退系统

剧情模式下支持多种回退方式，让你可以回到之前的节点重新选择：

- **轮次分割线** — 对话中每两个轮次之间显示 `↩ 回退` 按钮，点击后确认即可回退到该轮，之后的对话记录和回忆将被删除
- **回忆回退** — 展开任意一条回忆，点击底部的 `↩ 回退到此`，回退到该回忆覆盖的最后一轮
- **编辑消息** — 悬停自己发送的消息，点击右上角 `✎` 按钮，修改内容后点「保存并继续」，系统会回退到该消息并重新生成后续叙述
- **删除消息** — 悬停任意消息，点击左上角 `×` 按钮删除单条消息

---

## 十一、叙述变体

剧情模式下，每条系统生成的叙述消息右下角显示 `◂ 1/1 ▸` 导航：

- 点击 `◂` `▸` 在不同生成版本间切换
- 当前显示的版本即为该轮对话的正式记录
- 点击 `▸` 在最后一个版本时，可输入提示词（或留空）让 LLM 重新生成新版本
- 切换版本后，后续对话上下文仅包含当前选中的版本

---

## 十二、发送前编辑与剧情选项设置

### 发送前编辑

设置页面「剧情选项」区域中可开启「选项填充到输入框」功能：

- **开启后** — 点击 LLM 生成的选项会将文本填入输入框，可编辑后再手动发送
- **关闭后**（默认） — 点击选项直接发送

### 剧情选项设置

在设置页面可配置：

- **自动生成选项** — 开启后 LLM 根据当前剧情生成多个有意义的后续行动选项（1-5 个）
- **回忆间隔** — 每隔多少轮对话自动生成一次剧情回忆（1-20 轮）
- **选项填充到输入框** — 控制点击选项后的行为

## 十三、资产（文档管理）

左侧导航切换到「📄 资产」可浏览和编辑数据文档：

- **文档树** — 按目录结构浏览角色、物品、世界观设定等文档
- **在线编辑** — 内置 Markdown 编辑器，支持保存到后端
- **图片资产管理** — 上传图片、裁剪，可设置为角色卡面等
- **哈希冲突检测** — 重复内容文档自动提示

「🔗 索引」页面管理文档间 `imports` 引用关系，支持 YAML 导出/导入。

---

## 十四、世界书（Lorebook）

左侧导航「📖 世界书」管理酒馆（SillyTavern）Lorebook 兼容的世界书：

- **导入** — 支持酒馆世界书导出 JSON（v1/v2）、角色卡内嵌世界书、聊天备份 `.jsonl`，自动探测格式并报告导入/跳过/警告
- **触发机制** — 条目按主/副关键词扫描最近对话自动注入叙述与对话的提示词；支持常驻、选择性、概率、大小写、全词匹配等酒馆语义
- **绑定** — 每本书可绑定到指定会话，未绑定时回落到全局默认书
- **导出** — 一键导出回酒馆 v1 格式，无损回灌（保留 `disable`/`extensions` 等原始字段）

## 十五、战斗系统

剧情模式下可通过遭遇战进入回合制战斗，使用卡牌指挥角色在 7×7 网格地图上作战。

### 启动战斗

- 点击左侧导航切换到「⚔️ 战斗」，配置出战角色和遭遇战 ID 后开始
- 在剧情模式中，当故事触发战斗时，系统会自动进入战斗场景
- 「战斗测试」模式：无需会话，从 `data/plots/combat-test/` 加载预设战斗

### 战斗操作

| 操作 | 方式 |
| ---- | ---- |
| 选择卡牌 | 点击手牌中的卡牌，或按数字键 1-5 快捷选牌 |
| 打出卡牌 | 选中卡牌后点击敌方区域的格子，或直接拖拽卡牌到目标格子 |
| 移动角色 | 点击地图上的我方角色选中，再点击蓝色高亮格子移动 |
| 查看属性 | 点击角色头像或格子上的小人选中角色，悬停查看详细属性浮窗 |
| 结束回合 | 点击「结束回合」或按 F 键 |
| 取消操作 | 按 Esc 键 |

### 战斗界面布局

- 左侧：我方角色状态面板（HP 条、AP 点、头像）
- 中央：7×7 等距 3D 网格地图（CSS 3D 透视效果），角色小人 + 特效粒子 + Spine 骨骼动画
- 右侧：敌方角色状态面板
- 底部：手牌区（弧形排列）+ 操作栏 + 事件日志

### 数据回写与背景

- **数据回写** — 战斗结束后，角色的 HP 变化、受伤、死亡等状态自动回写到当前会话
- **战斗背景** — 按场景显示背景图：遭遇战配置（`background` 字段）优先，其次取当前剧情地点（`combat_bg` 字段），都没有则用默认背景。背景图存放于 `data/combat/backgrounds/`

### 会话级背景覆盖

每个会话有自己的背景目录 `data/memory/sessions/<模式>/<会话ID>/backgrounds/`（会话详情接口的 `backgrounds_dir` 字段返回该路径）。直接把图片放进去即可覆盖本场战斗的背景——文件名对应背景 ID（如 `wasteland_ruins.jpg` 替换该背景，`default.jpg` 替换兜底背景），只影响当前会话，不改动全局资源。

## 十六、会话资源面板

对话页右侧可展开「会话资源」面板，用于管理当前会话的覆盖资源：

- **形象覆盖** — 覆盖场景角色的展示形象
- **背景覆盖** — 覆盖本会话战斗背景（见上文）
- 所有覆盖仅影响当前会话，不修改全局数据

## 十七、数据目录说明

程序运行数据均保存在项目根目录的 `data/` 下：

| 路径 | 内容 |
| ---- | ---- |
| `data/characters/<名>/` | 角色卡（含 `combat.json` 战斗数据） |
| `data/items/` | 物品文档 |
| `data/environment/` | 环境状态机（地点/天气/时间预设） |
| `data/combat/enemies/encounters/backgrounds/` | 战斗数据：敌人、遭遇战、背景图 |
| `data/plots/combat-test/` | 战斗测试预设 |
| `data/worldbooks/` | 世界书（gitignored） |
| `data/memory/` | 向量记忆与会话数据（gitignored） |
| `data/classes/<职业>/cards.json` | 职业基础卡牌 |

> 注意：`data/worldbooks/` 与 `data/memory/` 不入库（gitignored），迁移/备份时需单独拷贝。

## 十八、常见问题

**Q：启动后界面提示后端离线？**
A：请确认已先运行 `python src/app.py`（监听 127.0.0.1:5000），浏览器模式下前端通过 Vite 代理访问后端。

**Q：对话没有回复 / 报错？**
A：请到「设置 → LLM 配置」点击「测试连接」确认模型服务可用；若配置了主备服务，程序会自动降级。查看终端日志可获取详细错误信息。

**Q：如何备份我的会话与角色数据？**
A：备份整个 `data/` 目录即可（注意 `worldbooks/` 与 `memory/` 为 gitignored，不会随代码仓库同步）。

**Q：战斗没有背景图？**
A：背景按「遭遇战配置 → 当前剧情地点 → 默认背景」三级回退；也可使用会话级背景覆盖，或用 `tools/generate_combat_backgrounds.py` 批量生成（见 `docs/combat-background-prompts.md`）。
