# Arknights Tavern 使用教程

> 欢迎来到罗德岛！本教程带你从零开始玩转 Arknights Tavern —— 一款明日方舟主题的文字角色扮演游戏。你不需要懂任何编程知识，跟着本教程一步步操作即可。
>
> 文中的截图用于帮助你找到对应的按钮和界面，如果程序界面与截图略有差异，以你打开的版本为准。

---

## 一、Arknights Tavern 是什么？

这是一款由电脑上的 AI 扮演"主持人"的文字游戏：你输入一句话、做一次选择，AI 就会接着把故事讲下去，就像在玩一个会自己写剧情的小说。游戏内置了：

- **剧情模式** — AI 自动推进故事线，你只需要在关键时刻做出选择
- **自由模式** — 和喜欢的角色自由聊天，想聊什么聊什么
- **战斗系统** — 剧情中遭遇敌人时，用卡牌指挥角色在战场上作战
- **世界书** — 为 AI 提供世界观设定的"背景资料库"，让剧情更贴合方舟世界

开始前你需要准备：一台电脑，以及一个可用的 AI 模型服务（见「配置 AI 模型」一节）。

## 二、快速开始：安装与启动

### 2.1 安装依赖

打开终端（Mac 的"终端"应用），依次复制粘贴以下两行命令并回车：

```bash
pip install -r requirements.txt
cd frontend && npm install
```

> 第一行安装程序运行所需的组件；第二行安装界面组件。如果某一行报错，请检查电脑是否已安装 Python 和 Node.js（详见"环境要求"）。

### 2.2 启动程序

每次游玩需要先启动两个服务，打开**两个**终端窗口，分别运行：

**窗口 1 —— 启动游戏引擎（后端）：**

```bash
python src/app.py
```

**窗口 2 —— 启动游戏界面（前端）：**

```bash
cd frontend && npm run dev
```

稍等片刻，浏览器会自动打开游戏界面（地址为 http://localhost:5173）。如果浏览器没有自动打开，手动输入这个地址即可。

> 提示：请保持两个终端窗口都开着。关闭任意一个，游戏都会停止。

### 2.3 桌面版（可选）

如果你更喜欢桌面窗口而不是浏览器，也可以把窗口 2 的命令换成：

```bash
cd frontend && npm run dev:electron
```

## 三、配置 AI 模型

游戏需要连接一个 AI 模型才能讲故事。点击左侧栏最下方的「⚙️ 设置」，在「LLM 配置」区域填写：

![设置页面](images/08-settings.jpg)

### 3.1 使用云端 AI（推荐）

如果你有云端 AI 服务的账号（例如 DeepSeek、OpenAI 等）：

1. 在「接口类型」选择服务商类型
2. 填入服务商提供的 **API Key**（密钥）和 **模型名称**
3. 点击「测试连接」，显示"可用"即表示配置成功

### 3.2 使用本地 AI（Ollama）

如果你不想用云端服务，可以安装免费的本地 AI 工具 [Ollama](https://ollama.com)：

1. 下载并安装 Ollama
2. 在终端运行 `ollama pull qwen2.5:7b` 下载一个模型（名字可换成任意支持的模型）
3. 回到设置页，选择「Ollama 本地」，填入地址（一般保持默认）和模型名称
4. 点击「测试连接」验证

### 3.3 主备切换（可选）

如果你同时配置了云端和本地两个模型，当其中一个出问题时，游戏会自动切换到另一个，对话不会中断。

## 五、会话大厅：开始游戏

点击左侧「🏛️ 会话大厅」进入游戏主菜单。**会话**就是你的游戏存档——每个会话保存一段独立的故事和进度。

![会话大厅](images/02-sessions.jpg)

### 5.1 新建会话

1. 点击右上角「新建会话」
2. 选择模式：**剧情模式**（体验完整故事线）或**自由模式**（和角色自由聊天）
3. 可选：绑定一本世界书、挑选出场的角色
4. 点击创建，进入对话页开始游戏

### 5.2 管理会话

- **切换**：点击列表中的会话卡片即可切换，游戏进度自动保存
- **重命名**：双击会话名称修改
- **删除**：点击卡片上的 ✕，或勾选多条后批量删除
- **导入/导出**：右上角支持导入或导出存档，方便换电脑或备份

## 六、剧情模式

剧情模式下，AI 会像说书人一样自动推进故事：生成场景叙述、扮演角色说话，并在关键时刻给出行动选项。

### 6.1 基本操作

- **做出选择**：叙述结束后，点击下方出现的选项即可让故事继续
- **输入指令**：也可以直接在输入框打字，告诉 AI 你想做什么
- **发送**：按回车或点击「发送」按钮

### 6.2 剧情回忆

对话进行中，左侧面板会出现「回忆」卡片——AI 每隔几轮会自动把剧情进展总结成摘要，方便你回顾发生过什么：

- 点击回忆条目展开/收起摘要
- 点击「重新生成」可让 AI 重新总结
- 回忆间隔可以在设置页调整

### 6.3 回退与重来

后悔了？剧情模式支持多种"后悔药"：

- **回退**：对话中每两个轮次之间有一个「↩ 回退」按钮，点击并确认即可回到那一轮重新选择
- **编辑消息**：鼠标悬停自己发过的消息，点击右上角 ✎，修改后点「保存并继续」，AI 会从修改处重新生成
- **删除消息**：悬停任意消息，点击左上角 × 删除单条

### 6.4 叙述变体

每条 AI 叙述右下角的 `◂ 1/1 ▸` 是版本切换器：

- 点击 ◂ / ▸ 查看同一段叙述的不同生成版本
- 在最后一个版本上再点 ▸，可以输入提示词让 AI 重新生成新版本
- 之后的故事会基于你选中的版本继续

## 七、自由模式

自由模式没有固定剧情，像一个"角色聊天室"：

### 7.1 加载角色

- 点击场景面板中「场景角色」卡片的「+ 添加」，从角色库选择要聊天的角色
- 点击角色旁的「对话」按钮切换当前聊天对象
- 多个角色在场时可以发起群聊

### 7.2 管理物品

同样通过「场景物品」卡片「+ 添加」把物品放进场景。悬停角色或物品可预览详情；点击 📌 可固定详情卡片，固定后还能直接编辑（只影响当前会话）。

### 7.3 编辑环境

点击环境面板的「编辑」，可以从预设列表中选择地点、天气、时间，也可以选「✏️ 自定义...」输入任意值。

---

## 八、资产：查看与编辑设定

点击左侧「📄 资产」可以浏览游戏内置的所有设定资料，包括角色、物品、职业、种族、剧情等文档：

![资产页面](images/04-documents.jpg)

- 左侧是文档目录树，点击展开分类，选择文档
- 右侧是文档内容，可以直接**在线编辑**并保存
- 顶部可切换「文档 / 图像 / 卡牌」三类内容

想自己创作新角色？在对应分类下新建文档，写好描述保存即可——游戏中的角色库会直接读到它。

---

## 九、世界书：AI 的背景资料库

世界书（Lorebook）是酒馆（SillyTavern）玩家社区的通用设定格式，用来告诉 AI"这个世界是什么样的"。

![世界书页面](images/05-worldbook.jpg)

### 9.1 导入世界书

点击「导入」，支持：

- 酒馆世界书导出文件（.json）
- 角色卡内嵌的世界书
- 聊天记录备份（.jsonl）

选择文件或粘贴内容即可，程序会自动识别格式并告诉你哪些条目导入成功。

### 9.2 触发机制

世界书条目通过**关键词**自动触发：当对话中出现某个关键词时，对应的设定会自动注入给 AI。例如设定"龙门——移动城市，位于炎国东部"，那么对话中提到"龙门"时，AI 就会想起这条设定。

### 9.3 绑定会话

每本世界书可以绑定到指定会话（在会话大厅新建时选择），没绑定时使用全局默认书。

## 十、战斗

剧情中遭遇敌人时，游戏会自动进入战斗场景；也可以点击左侧「⚔️ 战斗」手动配置和测试战斗。

![战斗配置页](images/07-combat.jpg)

### 10.1 战斗操作

| 操作 | 方法 |
| ---- | ---- |
| 选择卡牌 | 点击手牌中的卡牌，或按数字键 1-5 |
| 打出卡牌 | 选中后点击敌方区域格子，或拖拽到目标格子 |
| 移动角色 | 点击我方角色选中，再点击蓝色高亮格子 |
| 查看属性 | 点击角色或悬停查看属性浮窗 |
| 结束回合 | 点击「结束回合」或按 F 键 |
| 取消操作 | 按 Esc 键 |

### 10.2 战斗界面

- 左侧：我方角色状态（HP、AP、头像）
- 中央：7×7 战场网格，角色小人和特效动画
- 右侧：敌方角色状态
- 底部：手牌区、操作栏、事件日志

战斗结束后，角色的伤势和状态变化会自动记录到当前会话，影响后续剧情。

## 十一、设置

点击左侧「⚙️ 设置」：

- **外观** — 深色/浅色主题切换
- **LLM 后端** — 查看和切换主备 AI 模型（见「配置 AI 模型」）
- **LLM 配置** — 填写 API Key、模型名称，测试连接
- **剧情选项** — 「选项填充到输入框」：开启后，点击选项会把文字填进输入框，你可以修改后再发送；关闭则点击直接发送

## 十二、常见问题

**Q：界面提示后端离线/未连接？**
A：检查启动程序的终端窗口是否还开着，两个窗口都要保持运行。

**Q：对话没有回复？**
A：到「设置」里点击「测试连接」，确认 AI 模型配置正确且可用。

**Q：怎么备份我的游戏进度？**
A：整个 `data` 文件夹就是你的游戏数据（会话、记忆、世界书等），拷贝它即可完成备份。

**Q：浏览器没有自动打开界面？**
A：手动在浏览器地址栏输入 http://localhost:5173。
