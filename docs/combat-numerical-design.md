## 1. 概述

### 1.1 设计目标

本战斗系统采用**属性驱动 + 卡牌执行**的混合模型：

- **属性驱动**：角色通过 8 项中文属性的 1-10 评分自动转换为战斗数值
- **卡牌执行**：战斗中的具体行动由卡牌决定（伤害范围、倍率、目标模式）
- **骰子检定**：命中判定使用 d20 系统，增加战术不确定性
- **共享 AP**：玩家方使用共享 AP 资源池，强调团队配合

### 1.2 核心设计约束

| 约束项 | 值 | 说明 |
|--------|-----|------|
| 属性等级范围 | 1-10 | 6 项战斗属性 + 2 项叙事属性 |
| 稀有度分级 | 1-6 星 | 决定属性总量和分配 |
| 卡牌稀有度 | basic / elite | elite 为一次性消耗 |
| 网格尺寸 | 9×8 | 玩家区 3 列，敌方区 5 列 |
| 共享 AP/回合 | 2 | 玩家方整队共享 |
| 手牌上限 | 7 | 每回合抽满 |
| d20 命中系统 | 1=必失, 20=必中暴击 | DC = 10 + 闪避 |

## 2. 数值框架总览

### 2.1 数值流转图

```
角色属性(1-10)              卡牌数据
     │                         │
     ▼                         ▼
战斗数值(PATK/DEF/HP等)  +  伤害范围/倍率/AP消耗
     │                         │
     └─────────┬───────────────┘
               ▼
         命中判定 (d20 + HIT vs 10 + EVA)
               │
               ▼
         伤害计算 (基础伤害 + ATK×倍率 - 防御)
               │
               ▼
         最终伤害 (最小 1，暴击 ×2)
```

### 2.2 关键数值维度

| 维度 | 符号 | 取值范围 | 说明 |
|------|------|---------|------|
| 生命值 | HP | 39 ~ 150 | 角色；敌人 70 ~ 140 |
| 物理攻击 | PATK | 8 ~ 40 | 影响物理卡牌伤害 |
| 法术攻击 | MATK | 8 ~ 40 | 影响法术卡牌伤害 |
| 治疗力 | HEAL | 8 ~ 40 | 影响治疗卡牌 |
| 物理防御 | DEF | 2 ~ 20 | 减免物理伤害 |
| 法术抗性 | RES | 2 ~ 20 | 减免法术伤害 |
| 速度 | SPD | 7 ~ 25 | 决定行动顺序 |
| 命中 | HIT | 2 ~ 20 | d20 检定加值 |
| 闪避 | EVA | 2 ~ 15 | 命中 DC 组成部分 |

## 3. 属性系统与战斗数值转换

### 3.1 八项属性定义

| 属性 | 英文键 | 战斗影响 | 权重 |
|------|--------|---------|------|
| 物理强度 | physical_strength | HP, PATK, DEF | 物理核心 |
| 战场机动 | battlefield_mobility | SPD, HIT, EVA, AP, 移动力 | 速度核心 |
| 生理耐受 | physiological_tolerance | HP(主), DEF | 生存核心 |
| 战术规划 | tactical_planning | MATK, HEAL, SPD | 智力辅助 |
| 战斗技巧 | combat_skill | PATK, HIT | 物理命中 |
| 源石技艺 | originium_arts | MATK, HEAL, RES | 法术核心 |
| 情绪稳定 | emotional_stability | RES | 法术防御 |
| 魅力 | charisma | — | 叙事属性，无直接战斗影响 |

### 3.2 属性→战斗数值转换公式

```
HP   = END × 12 + STR × 3      （生存核心）
PATK = (STR + CBT) × 2         （物理强度 + 战斗技巧）
MATK = (ORG + INT) × 2         （源石技艺 + 战术规划）
HEAL = (ORG + INT) × 2         （同 MATK）
DEF  = round(END × 1.5 + STR × 0.5)   （生理耐受为主）
RES  = round(EMO × 1.5 + ORG × 0.5)   （情绪稳定为主）
SPD  = MOB × 2 + INT × 0.5     （战场机动为主）
HIT  = CBT + MOB               （战斗技巧 + 战场机动）
EVA  = round(MOB × 1.5)        （战场机动决定）
pAP  = 1 + floor((MOB - 3) / 3), 钳制 [1, 3]  （个人 AP，敌方使用）
共享 AP = 2/回合（玩家方）
```

## 7. 战斗公式与概率分析

### 7.1 命中判定

```
命中骰：d20 + HIT_attacker
难度值：DC = 10 + EVA_defender
命中条件：roll + HIT ≥ 10 + EVA
自然 1：自动未命中（大失败）
自然 20：自动命中 + 暴击（伤害 ×2）
```

### 7.2 命中概率矩阵

| 攻击方 HIT →<br>防御方 EVA ↓ | HIT=5 | HIT=8 | HIT=10 | HIT=12 | HIT=15 | HIT=18 |
|------------------------------|-------|-------|--------|--------|--------|--------|
| EVA=3 (DC=13) | 60% | 75% | 85% | 95% | 95% | 95% |
| EVA=5 (DC=15) | 50% | 65% | 75% | 85% | 95% | 95% |
| EVA=8 (DC=18) | 35% | 50% | 60% | 70% | 85% | 95% |
| EVA=10 (DC=20) | 25% | 40% | 50% | 60% | 75% | 90% |
| EVA=12 (DC=22) | 15% | 30% | 40% | 50% | 65% | 80% |
| EVA=15 (DC=25) | 5% | 15% | 25% | 35% | 50% | 65% |

*注：概率受自然 1 (5%) 和自然 20 (5%) 钳制，实际命中率在 5%-95% 之间。*

### 7.3 暴击分析

- 暴击率：5%（仅自然 20）
- 暴击收益：伤害 ×2
- 暴击对期望伤害的贡献：5% × (2x-1x) = 基础期望的 +5%
- 等效期望伤害提升：1.05×

### 7.4 伤害计算公式

```
base = random(card.min_damage, card.max_damage)  // 均匀分布
atk_stat = PATK (物理) / MATK (法术) / HEAL (治疗) / (PATK+MATK)/2 (混合)
resist = DEF (物理) / RES (法术) / min(DEF, RES) (混合/治疗)
atk_bonus = atk_stat × card.atk_scale

raw_damage = base + atk_bonus - resist
if crit: raw_damage *= 2
final_damage = max(1, round(raw_damage))  // 非治疗最低 1 伤害
healing = max(0, round(base + atk_bonus))  // 治疗不受防御影响
```

## 8. 拉表计算：伤害输出分析

### 8.1 各职业单卡期望伤害（3★ 标准配置）

**计算参数**：ATK=22, 对 EVA=5 敌人 (命中 55%), DEF=5, 不含暴击（+5%微调忽略）

### 9.2 标准战斗时间估算

首场遭遇战（4v4 初遇整合运动）：
- 敌方总 HP：375（90+70+75+140）
- 我方 DPR：约 7 伤害/AP × 2 AP/回合 = 14/回合（保守估计，仅用单目标卡）
- 理想击杀回合：375 ÷ 14 ≈ 27 回合

- 理想击杀回合：300 ÷ 13 ≈ 23 回合

**结论**：在仅使用基础卡牌的情况下，双方势均力敌（22 vs 23 回合），战斗结果取决于策略选择。

## 10. AP 经济与行动效率

### 10.1 共享 AP 模型分析

玩家方每回合 2 点共享 AP，可执行的操作组合：

| 操作组合 | AP使用 | 典型场景 |
|---------|--------|---------|
| 2× AP=1 单目标攻击 | 2 | 常规输出回合 |
| 1× AP=2 重击 + 移动 | 1+1 | 调整位置 + 输出 |
| 1× AP=2 AOE 攻击 | 2 | 多目标回合 |
| 1× AP=2 治疗 + 0 | 2 | 急救回合 |
| 1× AP=3 Elite 大招 | 3（不可行） | 共享 AP 不够！ |
| 移动 + 移动 | 1+1 | 纯调整回合 |

**关键约束**：共享 AP=2 意味着 AP=3 的 Elite 卡牌无法打出——除非系统允许 AP 透传或精英卡牌豁免。

**数值建议**：AP=3 的 elite 卡牌降低至 AP=2，或将共享 AP 上限提升至 3。

### 12.1 伤害-生存平衡验证

| 稀有度对比 | 我方击杀回合 | 敌方击杀回合 | 公平性指数 | 评估 |
|-----------|------------|------------|-----------|------|

| 4★ vs Lv1-2 | 16 | 30 | 0.53 | 我方优势 |
| 5★ vs Lv1-2 | 11 | 40 | 0.28 | 碾压 |
| 3★ vs Lv3-4 | 38 | 14 | 2.71 | 苦战，需策略 |

**合理性**：3★ vs Lv1-2 的公平性指数接近 1.0，表明基础数值设置合理。4★ 以上明显优势，符合玩家成长预期。

### 12.2 命中率合理性

当前 d20 系统的命中率在 5%-95% 之间，受到自然 1 和自然 20 钳制：

- 同等级对抗（HIT≈10 vs EVA≈5→DC=15）：命中率 75%
- 高命中打低闪避（HIT≈15 vs EVA≈3→DC=13）：命中率 95%
- 低命中打高闪避（HIT≈5 vs EVA≈12→DC=22）：命中率 15%

**评估**：75% 的同级命中率是合理的。d20 系统提供了适当的方差（25% 的 miss 率），使得战斗有足够的戏剧性但不会令人沮丧。

### 12.3 卡牌消耗与稀有度平衡

## 13. 附录：完整数值参考表

### A. 属性→数值计算速查表

```
HP  = end × 12 + str × 3        DEF = round(end × 1.5 + str × 0.5)
PATK = (str + cbt) × 2           RES = round(emo × 1.5 + org × 0.5)
MATK = (org + int) × 2           SPD = mob × 2 + int × 0.5
HEAL = (org + int) × 2           HIT = cbt + mob
pAP = 1 + floor((mob - 3) / 3)   EVA = round(mob × 1.5)
共享 AP = 2/回合
```

### B. 命中公式速查

```
命中 DC = 10 + EVA_defender
命中判定 = d20 + HIT_attacker ≥ DC
自然 1: 自动失败（5%）
自然 20: 自动成功 + 暴击（5%, 伤害×2）
命中率 = max(5%, min(95%, (HIT + 20 - 10 - EVA) × 5%))
```

### C. 伤害公式速查

```
基础伤害 = random(min_damage, max_damage)  [均匀分布]
ATK 加成 = atk_stat × card.atk_scale
防御减免 = DEF (物理) / RES (法术) / min(DEF,RES) (混合)
治疗 = max(0, round(base + HEAL × scale))
伤害 = max(1, round(base + ATK × scale - 防御))
暴击伤害 = 伤害 × 2
```
