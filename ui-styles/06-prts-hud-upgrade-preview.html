PRTS 全息终端 · 皮肤升级预览明日方舟式机甲 HUD 语言

这是一份预览稿，不接入项目构建（与 ui-styles/index.html:87 口径一致）。 用于在真正改动项目前，直观确认「优化后的 PRTS 皮肤长什么样」。页面 before 态忠实还原当前生效皮肤 frontend/src/styles/skin-prts.css 的观感； after 态应用本波次调研（R1 按钮手法 / R4 设计语言 / R2 图标 / R3 字体）落地的新素材与新手法。 两态共用同一套 DOM，仅靠 CSS 变量 / 属性选择器区分。

用法：点击页面右上角固定切换控件，或直接改 <body data-mode="before"|"after"> 属性。 before ＝ 当前皮肤真实观感；after ＝ 应用新素材/新手法后的观感。每个组件画廊项都会随切换同时变化。
⚠ 图标一律内联 SVG（几何自绘，24×24 viewBox / 1.5–2px 描边 / 45°·90° 斜线 / currentColor 驱动），不依赖任何图标字体 CDN，无第三方图标库。 字体仅预览临时走 CDN；生产环境应由 Electron 本地打包字体，不走 CDN；未使用任何日文子集字体排简体中文。

风险与边界

落地红线
  1. 生成区禁止手改：gen_skin_utils.py 生成的工具类覆盖块位于 skin-prts.css:125-398（BEGIN/END 由 gen_skin_utils.py:143-144 常量界定）。改配色 = 改脚本色板（gen_skin_utils.py:69-133）后重跑 python scripts/gen_skin_utils.py，手改会在下次运行被覆盖。
  2. @scope 边界不可破坏：@scope (html.skin-prts) to (.bg-combat-bg)（skin-prts.css:70）——战斗页根节点（CombatView.tsx:1179,1332 带 .bg-combat-bg）及其子树不换肤。任何新增规则都不得让战斗页被换肤；生成器也已排除 components/combat（gen_skin_utils.py:202-203）。
  3. 氛围层疑似泄漏到战斗页 未实测：body::before（网格，skin-prts.css:71-82）与 body::after（扫描线，skin-prts.css:83-94，z-index 9999）写在 @scope 内部但挂在 body 上；body 是 .bg-combat-bg 的祖先，to 边界不排除祖先。故这两层全屏 fixed 氛围层在战斗页依然渲染（推断，未经运行画面验证）。
  4. 对话气泡行内样式优先级限制：DialogueBubble.tsx:43,49,50-52 的姓名色与气泡底色/描边是「按角色色号计算的行内样式」，优先级高于任何类选择器；皮肤只能改圆角/阴影/字体/光环，保留每位说话人的色彩标识（skin-prts.css:581-586 注释原文）。
  5. 本次未改动任何项目文件：仅新增交付预览稿 ui-styles/06-prts-hud-upgrade-preview.html；skin-prts.css/skin-tavern.css/style.css/tailwind.config.js/index.html/gen_skin_utils.py 均未触碰。
