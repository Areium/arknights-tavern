# 描述
控制中枢是罗德岛舰船的神经中枢，一个充满全息投影和透明数据屏的环形空间。这里是所有战略决策和行动指令的发出地，充满了紧张而高效的氛围。

## 环境提示

### 视觉
中央主屏幕展示着泰拉大陆的动态地图，实时标记着天灾的移动路径和罗德岛的预定航线。周围环绕着稍显凌乱的办公桌，上面散落着战术平板、喝了一半的咖啡杯和一些古老的纸质文件。墙壁由冷灰色的金属构成，嵌有发出微弱蓝光的复杂线路，为整个空间增添了科技感。

### 氛围
空气中弥漫着微弱的臭氧味和电子设备持续工作散发的热量。虽然安静，但能清晰地感受到一种无形的紧迫感和决策的沉重分量。这里是舰船的大脑，每一个指令都关系到无数人的命运。

### 声音
背景音由多种声音交织而成：PRTS系统冷静的合成语音持续播报着舰船的各项状态数据，干员们在键盘上快速敲击的声音此起彼伏，全息界面交互时发出轻微的嗡鸣和提示音。

### 细节
- 一张不起眼的椅子上随意搭着博士的制服外套。
- 某个战术屏幕的一角，贴着一张阿米娅亲手写的鼓励便签，字迹娟秀。
- 桌面上除了高科技设备，还放着一个老式的沙漏，似乎在提醒着时间的流逝。
