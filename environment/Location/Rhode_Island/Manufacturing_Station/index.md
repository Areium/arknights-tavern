# 描述

制造站是罗德岛上充满工业气息的巨大车间，负责生产赤金、作战记录以及其他关键物资。这里是罗德岛持续运作的动力源泉，充满了喧闹、火热和高效的生产力。

## 环境提示

### 视觉
一个繁忙且充满工业感的巨大车间。自动化的机械臂在导轨上精确地滑动，进行着焊接和组装，不时迸发出耀眼的火花。传送带上源源不断地运送着闪亮的赤金锭和新鲜出炉的作战记录装置。加固的货架上堆满了各种原料和半成品。

### 氛围
空气中弥漫着金属切割的灼热感、机油和润滑剂的混合味道。整个环境喧闹、火热，充满了创造与生产的能量。

### 声音
巨大的工业风扇发出持续的轰鸣声，与机械运转的铿锵声、压缩气体释放时的嘶嘶声交织在一起，形成了一首工业交响曲。在这里，干员们需要通过内置通讯耳机才能清晰地进行交流。

### 细节
- 墙壁上挂满了各种型号的工具和复杂的设计蓝图。
- 一个机械臂正在自动更换作业工具，动作流畅而精准。
- 在车间的一个角落，设有一个为轮班干员准备的简易休息区，桌上放着一杯还没喝完的饮用水和一本翻开的漫画书。
