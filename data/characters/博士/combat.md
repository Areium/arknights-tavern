# 卡牌

  其卡牌不参与直接战斗，而是通过战术支援、战场调度和全局指挥来影响战斗走向。

## 专属卡牌

### 战术指令·前进 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 辅助 / 战术 / 移动 |
| **消耗** | 1 SP |
| **基础数值** | **10**（公式：`战术规划`） |
| **效果** | 博士对一名友方单位下达最简单的战术指令："前进。"目标友方单位可以立即移动 5m（不计入其本回合的移动限制）。如果目标位于掩体后方，此移动不会触发敌方的借机攻击——"博士已经算好了时机"。每回合最多使用 1 次。 |
| **判定** | 无需判定 |

### 战场评估 ★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 2 星 |
| **类型** | 辅助 / 战术 / 分析 |
| **消耗** | 1 SP |
| **基础数值** | **18**（公式：`战术规划 + 情绪稳定性`） |
| **效果** | 博士在战斗开始前的本能反应——不是思考，而是已经看到的东西。在战斗第一轮开始时（或进入新遭遇时），博士可以快速评估战场。GM 必须揭示以下信息中的两项：① 当前场上最危险的敌方单位及其主要攻击类型；② 敌方的阵型弱点（一个可以突破的位置）；③ 当前地形中最有利的防守位置；④ 一个敌人隐藏的能力或意图。此评估是非侵入性的——不会触发敌方的警觉。 |
| **判定** | 无需判定（GM 提供信息） |

### 博士的计策 ★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 3 星 |
| **类型** | 辅助 / 战术 / 干扰 |
| **消耗** | 2 SP |
| **基础数值** | **17**（公式：`战术规划 + 魅力`） |
| **效果** | 博士在关键时刻做出一个微小的战术调整——敌人刚好在错误的位置上做出了正确的攻击。指定上一轮内发生的一次敌方成功攻击（造成了伤害或负面效果），强制敌方重投该次攻击的命中判定。若新结果导致攻击失败，该攻击的所有效果被撤销（伤害取消、状态恢复等）。博士可以在 GM 揭示攻击结果后、伤害结算前使用此能力。每场遭遇战可使用 1 次。 |
| **判定** | 敌方重新投掷命中判定（使用原始 DC 和修正值） |

### 石棺的记忆 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 辅助 / 战术 / 觉醒 / 终结 |
| **消耗** | 12 SP（仅可在战场上至少有 3 名友方单位生命值 < 30% 时触发——"当所有人都在倒下时，他的手开始自己动了起来"） |
| **基础数值** | **30**（公式：`战术规划 × 3`） |
| **效果** | 博士的战术终端屏幕碎裂了一角——但他甚至没有低头。在那一瞬间，他的手指在触屏上划过的轨迹与任何一个罗德岛干员见过的都不同。这些指令太快、太精确、太——古老。进入「石棺的低语」状态，持续 1 回合（一次性效果）：① 所有友方单位立即获得一次免费移动（最大移动距离翻倍）和一次免费基础攻击（使用各角色的 1★ 卡牌，不消耗 SP）；② 所有友方单位的下一次判定获得 +5 修正；③ 所有敌方单位的当前动作被打断（博士的指令总是在敌人的动作完成之前到达）；④ 状态结束后，博士立即陷入「昏迷」——失去行动能力 2 回合。在此期间他无法使用任何卡牌，无法下达任何指令，甚至无法说话。 |
| **剧情影响** | ① 博士在此状态下使用的战术手语——所有在场干员都认不出——在事件后成为罗德岛内部讨论的焦点。凯尔希会对此保持沉默，但她的沉默本身就是一种确认；② 博士醒来后不记得那 2 回合中发生了什么。他会看到自己战术终端上残留的指令轨迹——那些他不记得自己写下的东西——然后他会一个人坐很久；③ 解锁一段博士失忆前的记忆碎片（GM 从预设的记忆碎片列表中抽取或即兴创造——这段记忆是模糊的、不完全的，但足够让博士感知到"在他沉睡之前，他曾经指挥过远比这更大的战斗"）；④ 如果阿米娅在场，她会在此事件后用一种博士从未见过的表情看着他——那不是恐惧，而是某种更深层的确认——"我的博士确实还在那里面"。她会在私下问博士一个问题，这个问题会成为后续剧情的关键节点。 |
| **判定** | 效果自动生效（无需判定）；战术指令的执行由各友方单位自行判定 |

### PRTS 辅助系统 ★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 3 星 |
| **类型** | 辅助 / 情报 |
| **消耗** | 被动（无消耗，始终生效） |
| **基础数值** | **17**（公式：`战术规划 + 魅力`） |
| **效果** | 通过 PRTS 系统实时获取战场数据。在每回合开始时，GM 必须额外提供一项战术情报：敌方单位状态变化、即将到来的威胁预警、或可用的战场资源位置。战斗中所有友方单位的先攻判定获得 +1 修正。 |
| **备注** | PRTS 是博士最核心的辅助系统。若通讯被切断或场景中存在强电磁干扰，此卡牌效果减半。 |

### 战术部署 ★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 4 星 |
| **类型** | 辅助 / 全局指挥 |
| **消耗** | 3 SP |
| **基础数值** | **10**（公式：`战术规划`） |
| **效果** | 重新调整一名友方干员的战术位置：① 该干员可立即进行一次免费移动（15m）；② 移动后该干员的下一次攻击获得 +3 修正；③ 回复 2 点部署费用。此卡牌可在任意友方回合中使用（响应型）。 |
| **判定** | 无需判定 |

### 紧急撤退 ★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 4 星 |
| **类型** | 辅助 / 救命 |
| **消耗** | 4 SP |
| **基础数值** | **14**（公式：`战术规划 + 战场机动`） |
| **效果** | 命令一名生命值低于 30% 的友方干员立即撤退至安全位置（射程 30m）：① 该干员脱离战斗，本回合不受任何攻击；② 撤退路径上的借机攻击自动被最近的友方重装干员拦截（若存在）；③ 回复 3 点部署费用。 |
| **判定** | 无需判定 |

### 指挥官的决断 ★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 4 星 |
| **类型** | 辅助 / 全局增益 |
| **消耗** | 4 SP |
| **基础数值** | **17**（公式：`战术规划 + 魅力`） |
| **效果** | 对全场友方单位下达一道明确的战术指令。选择一个效果：① 全军突击——所有友方单位攻击力 +3，持续 2 回合；② 坚守阵地——所有友方单位防御力 +3，持续 2 回合；③ 重组阵型——所有友方单位恢复 3 点生命值并解除一个负面状态。 |
| **判定** | 无需判定 |

### 最后的指令 ★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 5 星 |
| **类型** | 特殊 / 终极指挥 |
| **消耗** | 6 SP（仅可在己方有干员生命值低于 10% 或已倒下时触发） |
| **基础数值** | **30**（公式：`战术规划 × 3`） |
| **效果** | 在绝境中发出一道逆转战局的指令：① 选择一名已倒下的干员——该干员以 50% 生命值重返战场，并获得「背水一战」状态（攻击力 ×2，持续 2 回合）；② 所有存活的友方干员获得「不屈」——本回合不会因伤害而倒下（最低保留 1 点生命值）；③ 博士自身陷入「力竭」——下 2 回合无法使用任何卡牌。 |
| **剧情影响** | ① 这声指令中包含着博士对每一位干员生命的执着——在场的所有干员对博士的信赖永久提升；② 「力竭」状态在叙事中体现为博士声音沙哑、手指颤抖、需要阿米娅或凯尔希搀扶；③ 如果连续在短时间内使用此卡牌，凯尔希会强制博士进行体检并可能在后续剧情中限制博士的指挥时长。 |
| **判定** | 无需判定 |
