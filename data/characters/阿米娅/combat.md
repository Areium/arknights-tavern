## 专属卡牌

### 源石技艺·弹 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 攻击 / 法术 / 单体 |
| **消耗** | 1 SP |
| **基础数值** | **9**（公式：`源石技艺适应性`） |
| **效果** | 将最基础的源石能量凝聚于指尖，向单个目标发射一颗小型法术弹。这是阿米娅在凯尔希指导下学会的第一个攻击性源石技艺——简单、稳定、不需要任何戒指的辅助。射程 20m，可被源石技艺感知设备检测到。 |
| **判定** | d20 + 基础数值 vs 目标法术防御 DC |

### 领导者的鼓舞 ★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 2 星 |
| **类型** | 辅助 / 增益 / 光环 |
| **消耗** | 2 SP |
| **基础数值** | **15**（公式：`魅力 + 情绪稳定性`） |
| **效果** | 阿米娅以罗德岛领袖的身份向一名友方单位说出鼓励的话语。目标获得「被信任的力量」——下一次判定获得 +2 修正。若目标当前处于「恐惧」或「动摇」状态，改为消除该状态并恢复正常。此能力每场遭遇战可使用 2 次。 |
| **判定** | 无需判定 |

### 罗德岛的战术 ★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 3 星 |
| **类型** | 辅助 / 战术 / 分析 |
| **消耗** | 2 SP |
| **基础数值** | **18**（公式：`战术规划 × 2`） |
| **效果** | 阿米娅快速分析当前战场形势——这是她从博士那里学到的战术思维。GM 必须提供一条关于当前遭遇的战术洞察（敌方阵型弱点、地形优势、时机窗口等）。同时，所有友方单位的下一次判定获得 +1 修正（"阿米娅已经算好了"）。此能力每场遭遇战可使用 1 次。 |
| **判定** | 无需判定（GM 提供洞察）；队友增益自动生效 |

### 情绪感知 ★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 3 星 |
| **类型** | 辅助 / 感知 |
| **消耗** | 被动（无消耗，始终生效） |
| **基础数值** | **15**（公式：`情绪稳定性 + 魅力`） |
| **效果** | 感知周围人物的情绪状态（尤其是负面情绪）。在社交场景中，GM 必须额外提供目标的情绪线索（"ta 在紧张""ta 在说谎""ta 发自内心地感激"）。战斗中可感知敌人的恐惧/杀意，获得先制判定 +2 修正。 |
| **备注** | 此卡牌为被动能力，无需主动使用。情绪感知的结果受距离和目标的情绪强度影响——强烈情绪可在更远距离被感知。 |

### 精神爆发 ★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 4 星 |
| **类型** | 攻击 / 法术 / 单体 |
| **消耗** | 3 SP |
| **基础数值** | **11**（公式：`(源石技艺适应性 × 2 + 情绪稳定性) / 3`，向上取整） |
| **效果** | 对单个目标释放情感冲击类法术。目标情绪越负面（愤怒、恐惧、绝望），伤害越高——GM 根据目标当前情绪状态给予额外 +1~+5 修正。命中后目标需通过情绪稳定性判定（DC = 基础数值），失败则陷入「震慑」状态 1 回合。 |
| **判定** | d20 + 基础数值 vs 目标法术防御 DC |

### 影霄 ★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 5 星 |
| **类型** | 攻击 / 法术 / 范围 |
| **消耗** | 5 SP |
| **基础数值** | **12**（公式：`(源石技艺适应性 × 3 + 战术规划) / 3`，向上取整） |
| **效果** | 解放魔王之力的进阶形态。对指定区域内的所有敌人造成巨额法术伤害（范围：半径 15m）。区域内普通敌人直接失去战斗能力（无需判定），精英敌人需通过生理耐受判定（DC = 基础数值 + 5），失败则重伤。 |
| **剧情影响** | 使用后触发以下环境/剧情变化：① 周围 50m 内源石活性大幅提升，源石技艺相关判定获得 +3 修正（持续至场景结束）；② 所有在场的源石技艺使用者感知到"异常的力量波动"，可能引起第三方势力的注意；③ 阿米娅右手的抑制戒指出现细微裂痕——累计使用 3 次后将触发「戒指碎裂」事件，必须在后续剧情中修复。 |

### 奇美拉觉醒 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 特殊 / 变身 |
| **消耗** | 10 SP（仅可在「情绪稳定性」判定失败后触发，即阿米娅情绪失控时） |
| **基础数值** | **21**（公式：`(源石技艺适应性 + 情绪稳定性 + 生理耐受) / 3 × 3.0`，向上取整） |
| **效果** | 卡特斯与萨卡兹的双重血脉完全觉醒。进入「奇美拉觉醒」状态，持续 3 回合：① 全属性 +2；② 所有术师卡牌效果翻倍；③ 每回合自动对最近敌人释放一次无需消耗的「精神爆发」；④ 状态结束后，全属性 -2（持续至该场景结束）。 |
| **剧情影响** | ① 使用后矿石病立即恶化——颈部源石结晶扩大 1cm，在后续所有场景中生理耐受 -1（永久，不可恢复）；② 在场的所有萨卡兹族人感知到"魔王"的气息，他们对阿米娅的态度永久改变（敬畏/敌意/追随，取决于个体立场）；③ 罗德岛内部凯尔希会强制要求阿米娅进行全面体检，可能在后续剧情中限制其出战；④ 如果使用场景在公开场合，各方势力（整合运动、维多利亚、乌萨斯等）都会获得关于"魔王继承者"的情报。 |

## 职业通用卡牌（术师）

以下卡牌可供所有术师职业角色使用。当前基础数值基于阿米娅的属性计算，其他术师角色使用时按各自的属性重新计算。

### 源石技艺·凝 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 攻击 / 法术 / 单体 |
| **消耗** | 1 SP |
| **基础数值** | **9**（公式：`源石技艺适应性`） |
| **效果** | 将源石能量凝聚于一点，对单个目标发动基础法术攻击。所有术师最基础的法术手段。 |
| **判定** | d20 + 基础数值 vs 目标法术防御 DC |

### 法术增幅 ★★

| **类型** | 辅助 / 增益 |
| **消耗** | 2 SP |
| **基础数值** | **18**（公式：`源石技艺适应性 + 战术规划`） |
| **效果** | 短暂提升自身或一名友方法术使用者的源石技艺输出。目标的下一次法术攻击伤害 ×1.5（乘算）。效果持续至目标使用一次法术后消失，或 2 回合后自然消散。 |

|------|------|
| **稀有度** | 3 星 |
| **类型** | 防御 / 法术 |
