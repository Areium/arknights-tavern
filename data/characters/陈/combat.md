# 卡牌

## 专属卡牌

### 拔刀斩 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 攻击 / 物理 / 单体 |
| **消耗** | 1 SP |
| **基础数值** | **9**（公式：`战斗技巧`） |
| **效果** | 以龙门近卫局标准拔刀术发动一次快速斩击。作为近卫局特别督察组组长，陈的拔刀速度在同僚中首屈一指。若本回合陈是先手攻击（先攻），命中判定获得 +1 修正——"先拔刀的人活下来"是她在街头学会的第一课。 |
| **判定** | d20 + 基础数值 vs 目标物理防御 DC |

### 警官的直觉 ★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 2 星 |
| **类型** | 辅助 / 感知 / 调查 |
| **消耗** | 1 SP |
| **基础数值** | **15**（公式：`战术规划 + 情绪稳定性`） |
| **效果** | 陈在龙门近卫局多年办案历练出的直觉。当与某人交谈时，陈可以感知对方是否在刻意隐瞒信息。GM 必须揭示对方当前陈述是否为有意欺骗（但不需要揭示真相是什么）。此能力在一次社交场景中可使用 2 次。对习惯性说谎者（魅力 ≥ 8 且情绪稳定性 ≥ 7）效果减半——GM 仅需暗示"ta 的话里有东西"。 |
| **判定** | d20 + 基础数值 vs 目标情绪稳定性 DC（对手试图隐瞒时） |

| 字段 | 内容 |
|------|------|
| **稀有度** | 5 星 |
| **类型** | 攻击 / 物理 / 穿透 |
| **消耗** | 5 SP |
| **基础数值** | **9**（公式：`(战斗技巧 × 2 + 战场机动) / 3`，向上取整） |

| **剧情影响** | ① 赤霄绝影的剑速会在空气中留下一道短暂的金色剑痕——在场所有剑士自动注意到这一击的威力；② 龙门的敌人（尤其是与近卫局有过节的组织）会因这一击而确认"陈警官在场"——他们的态度可能从对抗变为战略性撤退。 |
| **判定** | d20 + 基础数值 vs 目标物理防御 DC（减半计算） |

### 赤霄·鞘击 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 特殊 / 封印解除 |
| **消耗** | 10 SP（仅可在自身生命值低于 30% 或目睹同伴倒下时触发） |
| **基础数值** | **25**（公式：`(战斗技巧 + 物理强度 + 情绪稳定性) / 3 × 3.0`，向上取整） |
| **效果** | 解除赤霄刀鞘上的封印——这柄刀远不止一把制式武器。进入「真剑模式」，持续 3 回合：① 全属性 +2；② 所有近卫卡牌和专属卡牌的基础数值 ×1.5；③ 每回合自动对最近敌人发动一次免费「拔刀」；④ 状态结束后，赤霄重新封印——陈在接下来的 2 个场景中战斗技巧 -2（刀身封印的反噬需要时间恢复）。 |
| **剧情影响** | ① 赤霄刀鞘上的金线纹路会在封印解除时发出炽热的光芒——在场的龙族和萨卡兹族人会感知到刀中蕴含的不属于这个时代的力量；② 魏彦吾——无论他身在何处——都会感知到赤霄的封印被解开；③ 陈在封印反噬期间会变得比平时更沉默和易怒——她讨厌依赖赤霄的真正力量；④ 关于"赤霄的真实来历"可能作为后续剧情的伏笔。 |
| **判定** | 无需判定 |
