# 角色背景

玛嘉烈·临光，卡西米尔临光家族的长女，第23届骑士特别锦标赛冠军——"耀骑士"。在夺冠后，临光没有选择留在卡西米尔享受冠军的商业价值，而是离开了这个被资本腐蚀的骑士竞技体系，加入了罗德岛。

在罗德岛，临光放下了"耀骑士"的头衔，成为一名重装干员。她用骑士的枪和盾在战场上保护队友，用沉默和行动赢回了尊重——不是作为冠军，而是作为一名可靠的战士。但当商业联合会威胁要让她妹妹瑕光代替她参赛时，临光做出了一个决定：以外卡选手的身份回归第24届特锦赛。不是为荣耀——是为妹妹。

临光的回归瞬间点燃了卡西米尔的多重暗流。商业联合会视她为威胁，监证会视她为棋子，红松骑士团视她为盟友。而临光自己——她只想打完比赛，保护妹妹，然后回到罗德岛继续做一名干员。但卡西米尔不会让她这么简单就离开。

# 外貌描写

## 整体印象
一位身材高挑的金发骑士，身姿挺拔如枪。她的美貌在卡西米尔骑士中是公认的，但更让人记忆深刻的是她的眼神——坚定但不凌厉，温柔但不软弱。当她穿上铠甲时，她不是耀骑士，她是玛嘉烈·临光——一个知道自己为何而战的人。

## 头部
- **种族特征**：一对库兰塔族的马耳，位于头顶，外部金色、内侧浅粉色。耳朵灵活且灵敏——在战斗中会随声音来源转动，在紧张时会竖起。一条金色的长马尾从后颈延伸到腰际，在情绪激动时会轻微甩动。
- **发色发型**：金色长发，高束马尾。额前有少量碎发——不是发型设计，是没时间修剪。
- **瞳色眼型**：深蓝色眼睛，眼型偏长但不过分锐利。在注视对手时有穿透力，在看向妹妹时柔和。
- **面部**：脸型端正，鼻梁高挺。脸侧有一道细长的旧伤疤——上一届特锦赛决赛时留下的。她不遮掩它。
- **表情常态**：平静而专注。不轻易笑——不是因为冷漠，而是因为她习惯承担。

## 身体
- **肩宽体态**：肩宽适中，身高约172cm。体态挺拔——这是长期穿重甲和持枪训练的结果。
- **手部**：手掌内侧有厚茧——常年握枪和握盾的位置。指甲修剪得极短（实用主义）。
- **躯干**：腰身被重甲训练塑造得紧凑有力。背部笔直——她父母教她的第一课："骑士的背不能弯。"

## 通用卡牌池

### 重装 通用卡牌（6张）

1. **架盾** ★（防御）：1 SP，基础数值 = 生理耐受 + 5。本回合内物理防御 DC +3，可代替相邻友方承受一次攻击。判定：无需判定。

2. **盾击** ★★（控制）：2 SP，基础数值 = 物理强度 + 生理耐受。用盾牌撞击目标，造成物理伤害并使目标进行生理耐受判定（DC 14），失败则被击退 3m 并陷入「失衡」。判定：d20 + 基础数值 vs 目标物理防御 DC。

3. **嘲讽** ★★（控制）：1 SP，基础数值 = 魅力 + 情绪稳定性。强制一个敌方目标在下一回合攻击自己（而非其他目标）。若目标为「生物」或「士兵」级，无需判定自动成功。判定：d20 + 基础数值 vs 目标情绪稳定性 DC。

4. **稳固阵型** ★★★（被动）：无需消耗。重装干员在受到物理攻击时，可将生理耐受的一半（向上取整）加到防御值上。此被动在移动的回合失效。

5. **牺牲掩护** ★★★★（防御/牺牲）：4 SP，基础数值 = 生理耐受 + 情绪稳定性。本回合内，重装干员可代替 15m 内任意一个友方目标承受一次攻击。此次攻击的伤害减半（对重装干员）。判定：无需判定。

6. **最后的阵地** ★★★★★（防御/光环）：5 SP，基础数值 = 生理耐受 × 2 + 情绪稳定性。展开 5m 范围的不可穿越的防御阵地，持续 2 回合。阵地内友方获得全伤害 -4，阵地外敌方无法进入。判定：敌方进入需通过 DC = 基础数值 的战场机动判定。
