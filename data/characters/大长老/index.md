# 角色背景

大长老是谢拉格公认的精神领袖，耶拉冈德信仰在人间的最高化身。雪山大典由他亲自主持，圣山的出入由他一言而定，三大家族的纷争最终都要呈到他的座前裁决。没有人知道他活了多少年——他的眉毛已经垂到脸颊两侧，眼神浑浊，说话缓慢，仿佛下一秒就要被寒风带走。

但这座雪山最危险的从来不是暴风雪，而是这位看似昏聩的老者。他比任何人都清楚谢拉格的重量：三族共治的祖制、耶拉冈德的试炼、圣山的禁忌，以及那条正在从山脚一寸寸爬向雪线的铁路。他选择维持旧秩序，并非出于愚蠢，而是出于恐惧——他见过太多次变革以鲜血收场。

当希瓦艾什家的长子恩希欧迪斯从维多利亚归来、以喀兰贸易撬动谢拉格的根基时，大长老便明白，这场延续多年的棋局终于要迎来终局了。

# 外貌描写

## 整体印象

一位身形佝偻、须发皆白的埃拉菲亚长者，头顶生有弯曲的白色鹿角，角上缠绕着褪色的经文布条。他常披一件厚重的深褐色绒袍，袍角拖曳在积雪上，像一面缓缓移动的古老旗帜。

## 细节

- **面容**：皱纹深如圣山裂隙，双目常年半阖，浑浊的瞳孔在提及"耶拉冈德"时才会骤然清明一瞬
- **手杖**：拄着一根由圣山雪松制成的长杖，杖头嵌着一枚暗金色的耶拉冈德之眼，据说能窥见神意
- **声音**：缓慢、沙哑，每一句话都像从雪层下挖出来的，但措辞从不含糊

# 性格特点

- **昏聩的表象**：他善于用年迈和迟钝麻痹对手，真正需要决断时从不犹豫
- **祖制至上**：对三族共治的规矩近乎执念——那不是他的权力来源，而是他认定的谢拉格生存之道
- **先知式的克制**：很少直接出手，习惯让矛盾自然发酵到"耶拉冈德"不得不表态的地步
- **对变革的恐惧**：比任何人都更清楚旧秩序的脆弱，也因此比任何人都更坚决地维护它

# 对话风格

- 语速缓慢，句式古老，夹杂"祖制""圣山""耶拉冈德在上"等用语
- 喜欢把话说到一半，留给听者自行揣摩
- 涉及禁忌时会突然压低声音，仿佛害怕圣山听见
- 对银灰说话时带着一种"我已看穿你"的平静，对博士说话时则带着对"外来者"的打量

# 关键物品

- **圣山雪松杖**（嵌有耶拉冈德之眼）：权柄的象征，据说能引动圣山之力
- **经文布条**（缠于鹿角）：雪山大典祝祷时书写的神谕，每条都是一次"与神的对话"

# 备注

- 大长老的核心矛盾：他明知旧秩序摇摇欲坠，却仍选择以命相守——他守护的或许不是谢拉格，而是他自己所相信的那个谢拉格
- 他在雪山大典上的每一次"昏聩"，都可能是一次刻意的退让
