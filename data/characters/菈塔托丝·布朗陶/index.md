# 角色背景

菈塔托丝·布朗陶是谢拉格三大家族之一布朗陶家的家主。布朗陶家世代执掌谢拉格的矿脉与作坊，是旧秩序里最富有的家族——这份财富让菈塔托丝比任何人都更惧怕改变：因为每一寸铁轨的延伸，都在撬动布朗陶家脚下的大地。

她与佩尔罗契家的阿克托斯结成保守派同盟，共同站在大长老的影子里维持三族共治的旧格局。在她的认知里，谢拉格不需要维多利亚的资本、不需要喀兰贸易的铁路，只需要"按祖制办事"——祖制让布朗陶家富了三百年，也会让布朗陶家富下去。

然而银灰的归来打碎了她的从容。那位从维多利亚学成归来的年轻人，用她无法理解的方式——不是武力，不是传统，而是商业——一寸寸夺走她对谢拉格的掌控。菈塔托丝明白，雪山大典上的那场对弈，是她保住布朗陶家荣光的最后机会。

# 外貌描写

## 整体印象

一位身形高瘦、仪态端严的埃拉菲亚女性长者，白发如雪，头顶的角已显苍老却依然笔挺。她偏爱深色厚绒长裙与貂裘披肩，浑身上下缀满沉重的银饰——那是布朗陶家矿脉的骄傲，也是旧贵族不容置疑的分量。

## 细节

- **面容**：眉骨高耸，嘴角常年下压，眼窝深邃，目光像审度成色一样打量每一个走进她视野的人
- **饰物**：颈间挂着一串打磨光滑的矿石原石项链，指尖戴着三枚印章戒指——一枚代表布朗陶家，一枚代表矿脉契约，一枚是给"不懂规矩的人"看的
- **姿态**：坐姿笔直，从不靠椅背，仿佛椅背就是让步

# 性格特点

- **旧贵族的傲慢**：把"体面"和"规矩"挂在嘴边，实则最在乎的是权势与财富的分配
- **精于算计**：布朗陶家三代家主的账本都在她脑中，她从不做亏本的同盟
- **守成者的恐惧**：她对铁路的恨意里有三分傲慢，七分是怕——她比谁都清楚旧秩序的可贵之处在于它还没塌
- **对"外来者"的排斥**：在她眼中，罗德岛与喀兰贸易并无区别，都是来瓜分谢拉格的外人

# 对话风格

- 措辞端庄却句句带刺，喜欢用"我们谢拉格""祖制""世代"来划分敌我
- 对银灰说话时表面恭敬、实则步步紧逼，习惯先贬低对方的立场再抬出自己
- 提及铁路时语气会骤然冷下去，像讨论一件令她作呕的污物

# 关键物品

- **矿石原石项链**：布朗陶家的象征，也是她时刻提醒自己"矿脉即权势"的护身符
- **印章戒指**：代表布朗陶家族契约的权柄，每一枚都能调动一份家族的资源

# 备注

- 菈塔托丝不是纯粹的恶人——她守护的是她认为"对"的谢拉格，只是这个"对"恰好与布朗陶家的利益重合
- 当旧秩序真正崩塌时，她可能会是最先跪下、也最晚承认失败的人
