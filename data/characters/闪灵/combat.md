# 卡牌

## 专属卡牌

### 基础包扎 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 治疗 / 单体 |
| **消耗** | 1 SP |
| **基础数值** | **9**（公式：`源石技艺适应性`） |
| **效果** | 闪灵以最基础的源石技艺加速伤口愈合。治疗一名相邻或 5m 内的友方单位 2 HP。此卡牌可作为附加动作使用（不计入本回合的主要行动），每回合最多使用 1 次作为附加动作。对于简单的伤口（擦伤、淤青），此卡牌可在战斗外无限使用。 |
| **判定** | 无需判定 |

### 安眠之触 ★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 2 星 |
| **类型** | 辅助 / 治疗 / 安抚 |
| **消耗** | 2 SP |
| **基础数值** | **18**（公式：`情绪稳定性 + 源石技艺适应性`） |
| **效果** | 闪灵将手掌轻轻放在目标的额头——她的源石技艺不是治愈肉体，而是安抚心灵。移除目标身上的「恐惧」「恐慌」「混乱」状态。若目标处于「重伤」状态（HP < 30%），获得「安眠」——获得临时 1 HP（不会因失血而恶化）并在当前场景内免疫恐惧。在战斗外，此卡牌可帮助一个自愿目标入睡（无视失眠、噩梦等）。 |
| **判定** | 无需判定 |

### 罪与赦 ★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 3 星 |
| **类型** | 特殊 / 叙事 / 心理 |
| **消耗** | 2 SP |
| **基础数值** | **18**（公式：`战术规划 + 情绪稳定性`） |
| **效果** | 闪灵以赦罪师的传统——一种不为外人所知的仪式——倾听一个人的忏悔。当一名角色对闪灵坦白内心的罪责、愧疚或隐藏的过往时，她可以给予真正的赦免。不是魔法，而是某种更深邃的东西。忏悔者永久移除一项自该罪责衍生的心理减益（如「负罪感」「自我厌恶」「羞愧」）。每名角色在整个战役中只能受益于此卡牌一次。闪灵无法对自身使用。 |
| **判定** | 无需判定（但 GM 判断忏悔是否真诚——虚假的忏悔不产生效果） |

### 沉默守护 ★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 3 星 |
| **类型** | 辅助 / 被动 |
| **消耗** | 被动（无消耗，始终生效） |
| **基础数值** | **18**（公式：`情绪稳定性 + 战术规划`） |
| **效果** | 闪灵的存在本身就是一种安抚。半径 15m 内的友方单位获得「镇静」：免疫「恐惧」和「混乱」状态，情绪稳定性判定获得 +2 修正。在非战斗场景中，她周围的伤者疼痛感减轻，急救成功率提升。 |
| **备注** | 此被动对萨卡兹族友方效果翻倍——她的血脉与同类产生共鸣。 |

### 赦罪之触 ★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 4 星 |
| **类型** | 治疗 / 单体 / 赦罪师秘术 |
| **消耗** | 4 SP |
| **基础数值** | **9**（公式：`(源石技艺适应性 × 2 + 情绪稳定性) / 3`，向上取整） |
| **效果** | 以赦罪师的秘术触碰一名友方单位。回复生命值 = 基础数值，并解除所有负面状态（不限种类和数量）。若目标生命值低于 30%，回复量 ×2。此卡牌每场战斗仅可使用一次——赦罪师的秘术不可滥用。 |
| **判定** | 无需判定 |

### 夜莺的守护者 ★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 4 星 |
| **类型** | 防御 / 守护 |
| **消耗** | 3 SP |
| **基础数值** | **18**（公式：`源石技艺适应性 + 情绪稳定性`） |
| **效果** | 闪灵指定一名友方单位作为「守护对象」。守护持续 3 回合：① 守护对象受到的所有伤害 -3（最低 1 点）；② 当守护对象即将受到致命伤害时，闪灵可立即移动到其身边并代为承受该伤害；③ 闪灵在守护对象 10m 范围内时，自身战场机动 +3。同一时间只能守护一个目标。 |
| **判定** | 无需判定 |

### 拔剑 ★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 5 星 |
| **类型** | 攻击 / 物理 / 形态转换 |
| **消耗** | 5 SP（额外条件：必须有友方单位生命值低于 30%，或闪灵自身受到直接攻击） |
| **基础数值** | **8**（公式：`(战斗技巧 × 2 + 源石技艺适应性) / 3`，向上取整） |
| **效果** | 闪灵解开法杖上的白色布条，露出其下真正的剑身——一把细长的萨卡兹赦罪师之剑。进入「剑士模式」，持续至战斗结束或主动收剑：① 可使用近卫通用卡牌（以闪灵的物理强度:5、战斗技巧:7、生理耐受:6 计算基础数值）；② 每回合可额外进行一次近战攻击（不消耗 SP）；③ 医疗卡牌效果减半（她的注意力被分散了）。收剑后，「剑士模式」的所有增益消失，且闪灵在接下来的 1 个场景中情绪稳定性 -2。 |
| **剧情影响** | ① 剑身上的萨卡兹赦罪师符文会在出鞘瞬间发出暗紫色的光芒——在场所有萨卡兹族人会本能地感知到一股来自古老血脉的压迫感；② 临光若在场，会露出复杂的表情——她见过闪灵拔剑的后果；③ 夜莺若在场，会不自觉地后退半步——她比任何人都清楚闪灵为何不愿拔剑。 |
| **判定** | 形态转换为无需判定；近战攻击 d20 + 基础数值 vs 目标物理防御 DC |

### 赦罪师的终章 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 特殊 / 终结 / 双刃 |
| **消耗** | 10 SP（仅可在有友方单位倒下或闪灵自身生命值低于 20% 时触发） |
| **基础数值** | **25**（公式：`(源石技艺适应性 + 战斗技巧 + 情绪稳定性) / 3 × 3.0`，向上取整） |
| **效果** | 闪灵以赦罪师之名，同时释放治愈与毁灭的终极秘术。选择以下两个效果同时执行：① **赦免**——指定一名已倒下的友方单位，该单位以满生命值重返战场并获得「赦罪之印」（全属性 +2，持续至战斗结束）；② **终章**——对一名敌方单位发动一次不可闪避、不可格挡的灵魂斩击。此攻击无视一切防御，直接结算伤害 = 基础数值。使用后闪灵陷入「透支」状态：接下来 3 个场景中，源石技艺适应性 -3，且无法使用任何消耗 SP ≥ 3 的卡牌。此卡牌在整场战役中仅可使用一次。 |
| **剧情影响** | ① 赦罪师的秘术本质是「等价交换」——每拯救一个生命，施术者就必须付出同等的代价。这一击之后，闪灵的银白色长发中会出现一缕永久的黑色——那是秘术反噬的印记；② 在场所有萨卡兹族人会感应到「赦罪师的血脉在燃烧」——闪灵的真实身份将在萨卡兹社群中扩散；③ 罗德岛的医疗部会对闪灵进行强制体检，凯尔希可能在后续剧情中就此事与闪灵进行秘密谈话；④ 夜莺的反应最为关键——她会在战后沉默地坐在闪灵身边，不做任何治疗，只是陪着。 |
| **判定** | ① 赦免：无需判定；② 终章：无需判定（不可闪避、不可格挡），直接结算 |

以下卡牌为医疗职业通用卡牌池，基础数值基于闪灵的属性计算。

### 治疗术 ★
| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 治疗 / 单体 |
| **消耗** | 1 SP |
