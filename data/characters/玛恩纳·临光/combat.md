# 角色能力

## 专属卡牌

### 公文包格挡 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 防御 / 物理 |
| **消耗** | 1 SP |
| **基础数值** | **9**（公式：`战斗技巧`） |
| **效果** | 玛恩纳用公文包——是的，那个他每天带去公司的公文包——精准地挡开了一次攻击。这不是什么高深的剑术，只是一个上班族在卡西米尔安保条件最差的街区学会的生存本能。玛恩纳借此格挡一次物理攻击（近战或远程均可），攻击伤害 -3。格挡成功后，玛恩纳会面无表情地推一下眼镜——仿佛刚才只是在公交车上被挤了一下。 |
| **判定** | d20 + 基础数值 vs 攻击方的命中判定结果 |

### 上班族的直觉 ★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 2 星 |
| **类型** | 辅助 / 感知 / 调查 |
| **消耗** | 1 SP |
| **基础数值** | **17**（公式：`战术规划 + 情绪稳定性`） |
| **效果** | 多年的办公室生活——尤其是卡西米尔的企业办公室——让玛恩纳拥有了一种特殊的感知力。他可以在看似普通的日常场景中察觉到不对劲的地方：一份"普通"的文件为何有不正常的签署日期、一个"友好"的商业伙伴为何站位如此奇怪、一个"例行"的会议为何安排在奇怪的时间。GM 必须揭示当前场景中一个被隐藏的异常——"不正常的东西"（如果有的话）。此能力与银灰的「谈判的艺术」不同——银灰读人的底线，玛恩纳读事情的裂缝。 |
| **判定** | d20 + 基础数值 vs GM 设定的异常隐藏 DC |

### 十三年前的那一剑 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 攻击 / 物理 / 单体终结 |
| **消耗** | 10 SP（不可与「沉默的观察」同时生效——使用此卡牌后，「沉默的观察」在本场战斗剩余时间内失效。触发条件：场上至少有 2 名临光家族成员或玛恩纳本人生命值 < 30%） |
| **基础数值** | **32**（公式：`(物理强度 + 战斗技巧 + 情绪稳定性) / 3 × 3.5`，向上取整） |
| **效果** | 玛恩纳把公文包放在地上。他解开领带。他脱掉西装外套。当他握住剑的时候——那把被他放在办公桌下面积了十三年灰的剑——他的整个身体都在说同一句话：他不是第一天拿剑。对单个目标发动一次不可闪避的毁灭性斩击。此攻击无视物理防御。伤害 = 基础数值 × 2.0。使用后进入「十三年的重量」状态 3 个场景：① 物理强度 -2，战场机动 -2（十三年的空白期不能在一瞬间填满）；② 无法再进行「沉默的观察」——他已经不再观察了；③ 玛恩纳会开始回应别人对他过去的提问——不是全部，但比之前多了很多。 |
| **剧情影响** | ① 所有在场的人——尤其是临光家族的成员——第一次看到玛恩纳握剑。不是作为"那个上班族叔叔"，而是作为十三年前那个在卡西米尔竞技场上击败过冠军的骑士。玛嘉烈（临光）会在这一幕中看到她从未在叔叔身上看到过的东西——不是力量，而是放弃了力量之后的重量；② 玛莉娅（瑕光）会第一次真正理解为什么叔叔从来不愿提起他的过去——不是因为羞耻，而是因为那是他曾经拥有、然后亲手放弃的一切；③ 关于"十三年前发生了什么"——为什么玛恩纳放下了剑——会成为后续剧情的核心线索之一。GM 应该为此准备一个至少包含 3 个场景的故事线；④ 玛恩纳在这之后不会再尝试隐藏他的过去。这并不意味着他会主动谈论——而是如果有人问，他会回答。这种微妙的变化会在后续所有社交场景中体现。 |
| **判定** | d20 + 基础数值 vs 目标物理防御 DC（无视防御） |

| **效果** | 玛恩纳在战斗开始时不会主动出手。每经过一个回合，他对所有敌方目标的「洞察」等级 +1——GM 记录玛恩纳对每个敌人的弱点了解程度。当玛恩纳最终出手时，每次攻击获得（洞察等级 × 2）的修正。最高累计 3 级（+6 修正）。玛恩纳不需要三个回合来观察——但他需要三个回合来决定出手是值得的。 |
| **判定** | 无需判定（自动累计） |

## 通用卡牌池

### 近卫 通用卡牌（6张）

1. **普通斩击** ★：1 SP，基础数值 = 战斗技巧 + 物理强度。标准近战攻击。判定：d20 + 基础数值 vs 目标物理防御 DC。

2. **快速拔刀** ★★：1 SP，基础数值 = 战场机动 + 战斗技巧。在第一回合使用时获得先攻优先权（先攻 +3）。判定：d20 + 基础数值 vs 目标物理防御 DC。

3. **居合斩** ★★★：2 SP，基础数值 = 战斗技巧 × 2。蓄力后的强力拔刀斩。若本回合未移动，伤害 +3。判定：d20 + 基础数值 vs 目标物理防御 DC。

4. **反击架势** ★★★：2 SP，进入反击架势。本回合内不主动攻击——但当受到近战攻击时，自动进行一次借机攻击（伤害 = 战斗技巧）。判定：借机攻击自动触发，d20 + 战斗技巧 vs 目标物理防御 DC。

5. **破甲斩** ★★★★：3 SP，基础数值 = 物理强度 + 战斗技巧。对目标的护甲进行定点打击——伤害 +2 且目标下回合物理防御 DC -3。判定：d20 + 基础数值 vs 目标物理防御 DC。

6. **无双连斩** ★★★★★：5 SP，基础数值 = (战斗技巧 + 物理强度 + 战场机动) / 2。对单个目标连续发动 3 次攻击，每次独立判定。每命中一次，下一次攻击获得 +1 修正（连续压制）。判定：每次攻击 d20 + 基础数值 vs 目标物理防御 DC。
