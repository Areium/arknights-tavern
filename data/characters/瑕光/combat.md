# 角色能力

## 专属卡牌

### 扳手敲击 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 攻击 / 物理 / 单体 |
| **消耗** | 1 SP |
| **基础数值** | **9**（公式：`物理强度 + 战斗技巧`） |
| **效果** | 瑕光抡起她的维修扳手朝目标砸下去——这本来是敲装甲板的工具，但砸在人身上效果也不错。对机械或重甲目标（装甲/盾牌/自律兵器），命中判定获得 +2 修正——她知道该敲哪里。瑕光自己会为此不好意思地笑一下："姐姐说她以前也用过这招。" |
| **判定** | d20 + 基础数值 vs 目标物理防御 DC |

### 装备评估 ★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 2 星 |
| **类型** | 辅助 / 鉴定 / 技术 |
| **消耗** | 1 SP |
| **基础数值** | **14**（公式：`战术规划 + 源石技艺适应性`） |
| **效果** | 瑕光的工匠眼光可以评估任何装备的真实价值。检查一件武器、防具或机械装置，GM 需揭示：① 物品的品质等级和基本属性；② 任何隐藏功能或缺陷（"这个护盾发生器里面有一个备用能源——但看起来被改装过"）；③ 是否可以修复/改进以及大致难度。对源石技艺相关的装备（法杖、抑制器等），瑕光额外获得 +2 判定——她的源石技艺适应性让普通工匠望尘莫及。 |
| **判定** | d20 + 基础数值 vs 物品复杂度 DC |

### 大师之作 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 辅助 / 制造 / 特殊 |
| **消耗** | 10 SP（需满足条件：瑕光使用了「工匠之眼」或「装备评估」成功评估了该类型的装备，且拥有合适的材料） |
| **基础数值** | **19**（公式：`(战术规划 + 源石技艺适应性 + 战斗技巧) / 3 × 3.0`，向上取整） |
| **效果** | 瑕光全身心投入——通宵达旦地工作——打造出一件独一无二的装备。为指定的一名友方单位创造一件定制的装备/武器/饰品，在限定的场景数内为特定类型的判定提供 +3 修正（例如："对重甲敌人 +3"、"抵抗源石技艺 +3"、"移动判定 +3"）。装备在创作时由瑕光指定其增益类型。每件装备附带瑕光留下的小标记——一个极小的太阳印章（临光家族的家徽），她不声张这件事，但被标记的人在仔细检查装备时总会找到。 |
| **剧情影响** | ① 这件装备是永久物品——不会在场景结束后消失。它将伴随持有者进入未来的冒险，成为一个真正属于他们的物品；② 瑕光的「工匠」声望在罗德岛内部大幅提升——从此以后会有干员在休息时间带着破损的装备来找她（"瑕光小姐，听说你..."）；③ 临光（玛嘉烈）如果得知此事，会沉默片刻——她的妹妹终于不再只是"骑士的妹妹"，而是用自己的方式成为了别人的依靠；④ 瑕光连续使用此卡牌（一个战役中使用 2 次及以上）会导致她进入「过度工作」状态——生理耐受 -1，持续 3 个场景。GM 提醒：她的身体还在恢复期。 |
| **判定** | 装备效果自动生效（不受判定的限制）；制造过程本身需要瑕光通过 d20 + 基础数值 vs 装备复杂度 DC |

### 工匠之眼 ★★★（被动）

| 字段 | 内容 |
|------|------|
| **类型** | 被动 / 辅助 |
| **基础数值** | 13（公式：`战术规划 + 源石技艺适应性`） |
| **效果** | 瑕光可以一眼判断任何装备的品质、弱点和使用痕迹。在战斗中对敌方装备进行观察时，可暗投战术规划判定（DC 12），成功则发现装备弱点——GM 提供该敌人的一个防御弱点（如"护甲左侧有裂痕"、"武器过热时会卡壳"），我方对该敌人的第一次攻击获得 +2 修正。此被动在长夜临光中可应用于调查场景——瑕光能从装备残骸中发现不被注意的证据。 |
| **判定** | 观察判定：d20 + 战术规划 vs DC 12 |

### 应急修复 ★★★（辅助）

| 字段 | 内容 |
|------|------|
| **类型** | 辅助 / 装备 |
| **消耗** | 2 SP |
| **基础数值** | 12（公式：`战术规划 + 战斗技巧`） |
| **效果** | 瑕光用一个回合修复一件友方受损的装备或护甲。效果：① 目标友方的物理防御 DC 恢复至原始值（如果因破损降低了）；② 修复一件关键物品的损坏状态（剧情判定）。瑕光修装备的速度比大多数人拆装备的速度还快——在工坊里她可以花一整个通宵，在战场上她只有六十秒。如果六十秒不够，她就让五十九秒足够了。 |
| **判定** | 无需判定（修复自动成功——但品质取决于瑕光的属性和情境修正） |

### 姐姐的铠甲 ★★★★（装备/剧情）

| 字段 | 内容 |
|------|------|
| **类型** | 装备 / 剧情 |
| **消耗** | 3 SP（仅可在非战斗场景使用） |
| **基础数值** | 14（公式：`源石技艺适应性 + 战术规划`） |
| **效果** | 瑕光拿出她暗中修复的临光旧铠甲，亲手为临光穿上。效果：① 临光的生理耐受 +1（本场战斗）；② 临光获得「妹妹的守护」状态——每次受到伤害时，伤害 -1（"这是姐姐的铠甲。我不允许它被随便打坏。"）；③ 瑕光与临光的好感度同时 +1（如果还未满）。 |
| **剧情影响** | 这是长夜临光中瑕光从"被保护的妹妹"转向"能保护姐姐的工匠"的关键时刻。临光不会说谢谢——她会在穿上铠甲后安静地看了妹妹三秒，然后转身走向赛场。那三秒比任何话都重要。 |
| **判定** | 无需判定 |

## 通用卡牌池

### 重装 通用卡牌（6张）

1. **架盾** ★：1 SP，物理防御 DC +3，可代替相邻友方承受一次攻击。
2. **盾击** ★★：2 SP，盾牌撞击目标，造成物理伤害并可能击退（生理耐受判定 DC 14）。
3. **嘲讽** ★★：1 SP，强制敌方攻击自己。「士兵」/「生物」级无需判定自动成功。
4. **稳固阵型** ★★★（被动）：受到物理攻击时生理耐受的一半加到防御值。移动回合失效。
5. **牺牲掩护** ★★★★：4 SP，代替 15m 内友方承受攻击，伤害减半。
6. **最后的阵地** ★★★★★：5 SP，展开 5m 不可穿越的防御阵地，持续 2 回合，内部全伤害 -4。
