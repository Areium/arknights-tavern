| **类型** | 攻击 / 物理 / 单体 |

|------|------|
| **稀有度** | 3 星 |
| **类型** | 辅助 / 被动 |
| **消耗** | 被动（无消耗，始终生效） |
| **基础数值** | **18**（公式：`魅力 + 战术规划`） |
| **效果** | 银灰的商业帝国为罗德岛提供持续的资源支持。每场战斗开始前，己方额外获得 2 点部署费用。在非战斗场景中，银灰可以通过喀兰贸易的情报网络获取商业和政治情报——DC 由 GM 根据情报敏感度设定，判定使用基础数值。在交易或谈判场景中，银灰的议价判定获得 +2 修正（"喀兰贸易的名字本身就是筹码"）。 |
| **备注** | 此被动的情报获取功能受地域限制——在谢拉格及周边地区效果最佳，在偏远地区效果减半。 |

| **类型** | 召唤 / 物理 / 协同 |

### 谢拉格的雪原之主 ★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 5 星 |
| **类型** | 辅助 / 光环 / 战术 |
| **消耗** | 5 SP |
| **基础数值** | **14**（公式：`(魅力 × 2 + 战术规划) / 2`，向上取整） |
| **效果** | 银灰展现出谢拉格家主的真正气场——不是贵族的优雅，而是雪山之主的威严。进入「雪原之主」状态，持续 3 回合：① 半径 30m 内所有友方单位获得「希瓦艾什的庇护」——全属性判定 +2（这是谢拉格人对家主的信任投射到了战场上）；② 银灰的所有近卫卡牌基础数值 +3；③ 每回合结束时，银灰可重新部署一名友方单位的位置（免费移动 10m）——"在雪山上，地形是第二个敌人"；④ 敌方单位在进入此光环范围时，需通过 DC = 基础数值 的情绪稳定性判定，失败则陷入「敬畏」——本回合无法对银灰发动攻击。 |
| **剧情影响** | ① 银灰在此状态下会不自觉地使用谢拉格方言——这是他唯一不使用维多利亚腔调的时刻；② 在场所有谢拉格出身的人（无论敌友）都会感受到一种来自血脉深处的召唤——"家主在看着你"；③ 此状态的银灰会让博士想起一个事实：这个男人真正的身份不是一个商人，而是一个国家的实际统治者；④ 连续使用此卡牌（在 3 个场景内使用 2 次以上）会导致银灰在后续社交场景中气场过强——谈判对手会本能地采取防御姿态，降低外交成功率。 |
| **判定** | 敌方敬畏判定：d20 + 基础数值 vs 目标情绪稳定性 DC |

### 真银斩 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 攻击 / 物理 / 大范围终结 |
| **消耗** | 10 SP（仅可在银灰生命值低于 40% 或场上友方单位数量少于敌方时触发） |
| **基础数值** | **24**（公式：`(战斗技巧 + 物理强度 + 战术规划) / 3 × 3.0`，向上取整） |
| **效果** | 银灰将长剑高举——剑身上浮现出银白色的冰霜纹路——然后斩下雷霆万钧的一击。对前方锥形范围（半径 50m，角度 90°）内的所有敌人发动一次不可闪避的毁灭性斩击。此攻击无视物理防御，伤害 = 基础数值 ×1.5。使用后银灰陷入「力竭」状态，持续 2 个场景：① 物理强度 -3，战场机动 -3；② 无法使用任何消耗 SP ≥ 4 的卡牌；③ 雪豹"银灰"会自动守护在他身边，拒绝任何人的靠近——包括友方（除非银灰主动示意）；④ 如果战斗发生在雪地或高海拔环境，剑意会引发小范围的雪崩（GM 根据地形判断规模和影响）。 |
| **剧情影响** | ① 真银斩是希瓦艾什家族代代相传的剑技——不是维多利亚学来的，而是谢拉格雪山之巅的古老秘剑。这一剑斩下时，剑身上的冰霜纹路会映出谢拉格雪山的轮廓；② 在场所有来自谢拉格的人会不由自主地屏住呼吸——这一剑在他们的文化中是传说中的存在，许多人只在家人的床头故事里听过；③ 崖心若在场，会在战后第一次真正理解"哥哥为什么从不让我靠近他的战斗"——她会用前所未有的眼神看着银灰的力竭身姿；④ 博士若在场，银灰会在力竭期间对博士说出一次难得的真话——他太累了，累到连伪装都维持不住。这是他唯一可能暴露脆弱的窗口；⑤ 关于"真银斩"的秘密——为什么希瓦艾什家族能代代传承这一剑技——可能作为喀兰贸易后续剧情的伏笔。 |
| **判定** | d20 + 基础数值 ×1.5 vs 各目标物理防御 DC（无视防御） |
