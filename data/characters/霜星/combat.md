# 卡牌

## 专属卡牌

### 冰霜之触 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 攻击 / 法术 / 单体 / 减益 |
| **消耗** | 1 SP |
| **基础数值** | **9**（公式：`源石技艺适应性`） |
| **效果** | 以指尖凝聚寒冰源石技艺，对接触范围内的单个目标释放一次冰冻冲击。造成法术伤害，目标需通过生理耐受判定（DC = 基础数值），失败则「冻伤」——战场机动 -2，持续 1 回合。此卡牌是霜星最基础的冰冻攻击，无需准备动作。 |
| **判定** | d20 + 基础数值 vs 目标法术防御 DC（伤害）；目标 d20 + 生理耐受 vs DC 9（冻伤） |

| **类型** | 辅助 / 光环 / 情感 |
| **消耗** | 1 SP |

| **效果** | 霜星唤起对乌萨斯冻原的记忆——那片埋葬了她所有同伴的冰原。当她静默时，周围 20m 内的所有「感染者」标签的友方单位感受到一种深沉的被理解感。所有感染者队友的情绪稳定性判定获得 +1 修正（持续至场景结束，不叠加）。此卡牌为被动效果，无需主动使用——只要霜星在场且保持清醒，光环就会持续生效。 |
| **判定** | 无需判定 |

### 永冻之躯 ★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 3 星 |
| **类型** | 防御 / 被动 |
| **消耗** | 被动（无消耗，始终生效） |
| **基础数值** | **14**（公式：`源石技艺适应性 + 生理耐受`） |
| **效果** | 霜星的身体被冰霜源石技艺永久侵蚀，获得了异常的低温耐受能力。免疫「冻结」和「寒冷」效果。任何对霜星发动的近战攻击，攻击者需通过 DC = 12 的生理耐受判定，失败则受到 1 点冰霜反伤且战场机动 -1（持续 1 回合——寒冷使肌肉僵硬）。 |
| **备注** | 此被动的代价是霜星的体温永远无法恢复正常——这是矿石病与源石技艺交织的烙印。 |

### 暴风雪 ★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 5 星 |
| **类型** | 场地 / 法术 / 大范围 |
| **消耗** | 6 SP |
| **基础数值** | **12**（公式：`(源石技艺适应性 × 3 + 战术规划) / 3`，向上取整） |
| **效果** | 在战场上召唤一场半径 50m 的暴风雪，持续 3 回合：① 范围内所有非友方单位的战场机动和物理强度各 -2（寒冷使关节僵硬、肌肉迟缓）；② 每回合开始，范围内所有敌人受到 1 点冰霜伤害（无需判定）；③ 范围内所有友方单位获得「雪怪小队的庇护」——霜星在场时，雪怪小队成员在暴风雪中战场机动 +2；④ 霜星在暴风雪中施法的基础数值 +2。暴风雪期间远程物理攻击（弓箭、投掷）判定 -3（能见度极低）。使用后霜星的矿石病体征加重——源石结晶在当前基础上扩展一小块（GM 记录）。 |
| **剧情影响** | ① 暴风雪的降临会急剧改变战场环境——温度在 30 秒内降至冰点以下，空气中的水汽凝结成冰晶；② 方圆 500m 内的人都能看到这场异常的风雪——整合运动的敌人会意识到"雪怪小队在这里"；③ 霜星在暴风雪中站立的姿态——一个消瘦的少女在风雪中纹丝不动——会成为战场上所有目击者难以忘记的画面；④ 如果战斗发生在城区，暴风雪可能导致建筑结冰、管道冻裂，留下战后需要处理的后果。 |
| **判定** | d20 + 基础数值 vs 各目标法术防御 DC |

### 最后的冬日 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 攻击 / 法术 / 终结 / 牺牲 |
| **消耗** | 10 SP（仅可在霜星生命值低于 20% 或雪怪小队成员倒下时触发） |
| **基础数值** | **21**（公式：`(源石技艺适应性 + 情绪稳定性 + 生理耐受) / 3 × 3.0`，向上取整） |
| **效果** | 霜星将体内所有的源石能量一次性释放——她身体表面的源石结晶在瞬间爆发出刺眼的冰蓝色光芒。以自身为中心，半径 100m 内的一切陷入绝对零度：① 范围内所有敌人受到一次不可闪避的冰霜法术伤害，伤害 = 基础数值 ×2；② 所有敌方单位陷入「冻结」状态 2 回合（无法行动，但受到的物理伤害减半）；③ 范围内所有友方单位获得「最后的庇护」——本回合免疫一切伤害；④ 使用后霜星的生命值归零，源石结晶大面积扩散——她进入了矿石病的终末阶段。是否存活由 GM 根据剧情需要和 roll 判定决定：DC 18 的生理耐受判定，成功则保留 1 点生命值但永久陷入「衰竭」状态（所有属性 -3，直至接受罗德岛的全面治疗）。此卡牌在整场战役中仅可使用一次。 |
| **剧情影响** | ① 绝对零度的爆发会将周围的一切冻结在冰晶之中——建筑、地面、空气，甚至飘落的雪花都会静止在半空。这场面会让在场的所有人（无论敌友）暂停战斗——这是一种超越战斗的、令人窒息的壮绝；② 爱国者若在附近（500m 内），会感知到霜星生命力的急剧流失——他会停下手中的一切，沉默地望向暴风雪的中心；③ 博士若在场，会面临整个剧情中最艰难的抉择之一——是否冒着牺牲更多人的风险去救她；④ 战斗结束后，霜星身体表面的源石结晶覆盖率将从 15% 跃升至 30%+——她需要立即接受罗德岛的紧急治疗，否则存活时间不超过 72 小时；⑤ 如果霜星在此次战斗中存活，她对博士的信任将永久性地改变——"你看到了我最不堪的样子，却没有转身离开。" |
| **判定** | 伤害结算无需判定（不可闪避）；生存判定：d20 + 生理耐受(+5) vs DC 18 |
