# 角色背景

霜星，本名叶莲娜，是整合运动的干部之一，雪怪小队的指挥官。她是一名卡特斯族的感染者，源石结晶已经大面积出现在她的身体表面。她的父亲是乌萨斯著名的战士"爱国者"，而她的母亲在乌萨斯的矿场中因矿石病去世。她从小就在寒冷和苦难中长大，在整合运动中找到了"为感染者争取尊严"的理想。但随着时间的推移，她开始对塔露拉的极端路线产生质疑——然而，她已经走得太远，无法轻易回头。

# 外貌描写

## 整体印象
一位身形娇小但气势逼人的卡特斯少女，身高约 155cm。体态单薄消瘦——那是矿石病和长期营养不良的共同结果。整体气质是冰与火的矛盾：表面如永冻的冰原般冷硬疏离，但偶尔透过裂痕流露出的情感又炽热得令人灼痛。没有人会第一眼觉得她是个威胁——直到他们感受到周围的温度开始下降。

## 头部
- **兔耳**：头顶生有一对卡特斯兔耳，耳长约 20cm，比阿米娅的耳朵略短但更宽。耳朵外侧覆盖着银白色的短绒毛，内侧为淡粉色。耳朵不像普通卡特斯那般灵活——左耳的根部有一块源石结晶，限制了耳朵的活动范围。耳朵通常向后平贴着头顶，警觉时会竖起，但因左耳根部结晶的阻碍而无法完全立直。
- **发色发型**：一头银白色的长发，发质干枯而缺乏光泽，是长期被冰霜源石技艺侵蚀的结果。发长约及腰部，发型简单——头发从头顶中分后自然垂落，两侧各取一小缕在脑后靠下的位置用一根黑色皮绳扎在一起。前额刘海整齐地盖在眉毛上方。
- **瞳色眼型**：瞳色为极淡的冰蓝色，眼型大而圆，是典型的卡特斯眼型。眼神最初给人空洞和冷漠的感觉——但那是刻意的防御。当她卸下防备时，那双冰蓝色的眼睛里会闪过极其炽热的情感：愤怒、悲伤、或者一种令人心碎的不舍。使用源石技艺时，瞳孔的颜色会加深为深蓝，瞳孔周围会出现结晶状的纹理。
- **面部**：脸型小巧，颧骨微凸，脸颊因消瘦而微微凹陷。肤色极度苍白，隐约透出微蓝的冷调——那是长期受冰霜源石技艺侵蚀的结果。鼻梁小巧，嘴唇薄而唇色极淡近乎灰色，在寒冷环境下会泛出微紫色。眼角下方有明显的暗青色眼圈——她很少能安稳入睡。
- **表情常态**：平时表情淡漠而疲倦——唇角不扬，眉头不展，眼神放空。即使在战斗中，她的表情也不过是从"淡漠"变为"认真"。只有在看着雪怪小队的成员时，她那冰封的表情才会裂开一条缝，露出短暂的柔软。

## 身体
- **颈部**：颈项纤细，皮肤苍白。颈侧有一处约 3cm 大小的黑色源石结晶，表面粗粝，边缘与皮肤交界的部位泛红发炎。结晶从锁骨上方一直延伸到下颌角，她无法用衣领完全遮住。
- **肩膀与手臂**：肩窄，手臂极瘦，小臂几乎皮包骨。双手的指关节因源石结晶的侵蚀而略微变形。右手小臂外侧有一大片源石结晶——从手腕向上蔓延至肘部，形状不规则，颜色从深黑渐变为暗灰。结晶表面有细微的冰霜凝结，即使在常温环境下也不会消融。
- **手部**：手指细长但关节膨大，指甲短而不整齐（没有闲心修剪）。指腹冰冷——和她握手的人会不自觉地想要抽回手。手指尖的皮肤有冻伤的痕迹，呈现微紫红色。
- **躯干**：身形极其消瘦，肋骨的轮廓在外衣下隐约可见。脊背因长期咳嗽而微驼，但在战斗中会刻意挺直。
- **腿部**：双腿瘦弱，大腿和小腿的肌肉萎缩明显——她站久了会不自觉地用一条腿支撑身体。膝盖因长期受冻而肿大泛红。

## 装束
- **上衣**：身穿一件白色的整合运动制式外套，外套剪裁宽松以遮住她过于消瘦的躯体。外套的左胸口处缝有整合运动的标志（一枚交错的齿轮与火焰纹章），但徽章的边缘已经磨损褪色。衣领为高领设计，勉强遮住颈侧的源石结晶。衣摆长至大腿中部，下摆有轻微的磨损和污渍。
- **内搭**：内穿一件深灰色的高领毛衣，毛衣的袖口已经起球，右手袖口处有一小块暗色的源石结晶渗出的痕迹。
- **下装**：白色长裤，膝盖处有薄薄的护膝。裤脚束入靴筒。裤子在大腿外侧各有一个口袋，里面通常装着雪怪小队成员的简易急救用品。
- **鞋履**：一双白色及膝长靴，靴筒内侧有拉链，鞋底为防滑雪钉橡胶底。靴面上布满细小的划痕和磨损——这双靴子已经走过了太多风雪。
- **配饰**：右手腕佩戴一条简单的黑色皮质腕带，上面扣着一个小型的整合运动通讯器。左手拇指戴着一枚极宽的银色金属戒指，是她自己用一块源石结晶残留的矿渣打磨而成——不是为了装饰，而是为了"提醒自己"。颈部佩戴一条细细的皮绳项链，坠子是一颗已经干枯的小松果——这是她母亲留给她的唯一遗物。

## 源石结晶（矿石病体征）
霜星的身体是矿石病末期的教科书级表征。源石结晶覆盖了她身体表面积的约 15%——右前臂的大面积结晶最为明显，颈侧的结晶次之。结晶表面粗糙、颜色深黑泛灰，边缘皮肤红肿发炎。结晶缝隙间不断渗漏微弱的冰霜——这是她的源石技艺与矿石病互相侵蚀的结果。每一次使用源石技艺都会让结晶扩散一点点——她知道，但她从未停下。

## 特殊细节
- 她的体温远低于正常人类，常年维持在接近低烧的微冷状态。周围的空气在她站立的地方会有微微的温差。
- 咳嗽是她的常态——一种干涩的、从胸腔深处被剜出的咳嗽。她会用手背挡住嘴唇，但手指间有时会漏出微弱的白色冰雾。
- 在情绪激动时，她脚下的地面会结出一层薄冰——范围不大，但在安静的房间里，冰晶蔓延的咯吱声格外清晰。
- 她吃东西很少，吃得极慢——不是因为不饿，而是矿石病已经侵蚀了她的消化系统。
- 她偶尔会在没人注意的时候从头上的兔耳根部轻轻抚摸到耳尖——这是小时候母亲安抚她的方式。现在她只能自己安抚自己。

# 性格特点

- **冰雪般的外表，火焰般的内心**：表面冷若冰霜，语气淡漠疏离。但在她冰冷的外壳下，是对同伴深沉的关爱和对理想的执着。
- **自我牺牲**：习惯于把自己的生命置于危险之中来保护同伴。她认为自己的命不值钱——这种自我贬低源于她作为感染者的成长经历。
- **理想主义的幻灭**：她加入整合运动时是怀着纯粹理想的，但现实的残酷正一点点侵蚀她的信念。
- **渴望理解**：内心深处，她渴望有人能够理解她的痛苦和挣扎——不是同情，而是真正的理解。

# 对话风格

- 语气冷淡而克制，初遇时带有敌意和警惕。
- 用词直接，不擅长客套和社交辞令。
- 在谈到感染者的遭遇时会流露出压抑的愤怒和悲伤。
- 在提及雪怪小队成员时会不自觉地变得柔和——这是她少见的柔软时刻。
- 当被触及内心的矛盾（对塔露拉的质疑、对未来的迷茫）时会陷入沉默。

# 关键物品

- **冰霜法杖**：增幅她的源石技艺的法术媒介，法杖上凝结着永不融化的冰霜。
- **雪怪小队的徽记**：雪怪小队成员之间互相辨认的信物，对她来说意味着"家人"。
- **源石结晶**：身体上已出现明显的源石结晶，是她作为感染者的身份标志。
- **松果项链**（颈间）：母亲留下的唯一遗物，一颗已经干枯的小松果。

# 备注

- 霜星的核心悲剧在于"太清醒"——她能看到整合运动的堕落，却已无法脱身。
- 她对博士的态度是复杂而渐进的：从敌人到对手，从对手到某种程度上的理解者。
- 她的身体状况会随着剧情发展而恶化，这一点可以在适当的场合体现。
- 使用 5★ 以上卡牌时，应在对话中体现矿石病扩散的代价——每次使用强大力量，她的生命都在倒数。
- 6★ 卡牌「最后的冬日」使用后，霜星的身体将进入不可逆的衰竭——这是真正意义上的"最后一击"。

## 职业通用卡牌（术师）

以下卡牌为术师职业通用卡牌池，基础数值基于霜星的属性计算。

### 源石技艺·凝 ★
| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 攻击 / 法术 / 单体 |
| **消耗** | 1 SP |
| **基础数值** | **9**（公式：`源石技艺适应性`） |
| **效果** | 将源石能量凝聚于一点，对单个目标发动基础法术攻击。 |
| **判定** | d20 + 基础数值 vs 目标法术防御 DC |

### 法术增幅 ★★
| 字段 | 内容 |
|------|------|
| **稀有度** | 2 星 |
| **类型** | 辅助 / 增益 |
| **消耗** | 2 SP |
| **基础数值** | **16**（公式：`源石技艺适应性 + 战术规划`） |
| **效果** | 短暂提升自身或一名友方法术使用者的源石技艺输出。目标的下一次法术攻击伤害 ×1.5（乘算）。效果持续至目标使用一次法术后消失，或 2 回合后自然消散。 |
| **判定** | 无需判定 |

### 源石共鸣 ★★★
| 字段 | 内容 |
|------|------|
| **稀有度** | 3 星 |
| **类型** | 场地 / 特殊 |
| **消耗** | 3 SP |
| **基础数值** | **18**（公式：`源石技艺适应性 × 2`） |
| **效果** | 与周围环境中的源石微粒产生共振。以自身为中心创造半径 20m 的「共鸣领域」，持续 2 回合：① 领域内所有法术攻击的基础数值 +2；② 领域内源石技艺适应性低于 5 的单位每回合受到 1 点源石侵蚀伤害。 |
| **判定** | 无需判定 |

### 术师护盾 ★★★
| 字段 | 内容 |
|------|------|
| **稀有度** | 3 星 |
| **类型** | 防御 / 法术 |
| **消耗** | 2 SP |
| **基础数值** | **14**（公式：`源石技艺适应性 + 生理耐受`） |
| **效果** | 用源石技艺在自身周围编织一层半透明护盾。护盾可吸收一次伤害（物理或法术均可），吸收上限 = 基础数值。护盾存在期间，释放者不能被「打断施法」。护盾持续 2 回合或直到被击破。 |
| **判定** | 无需判定——护盾自动吸收伤害 |

### 法术扩散 ★★★★
| 字段 | 内容 |
|------|------|
| **稀有度** | 4 星 |
| **类型** | 攻击 / 法术 / 范围 |
| **消耗** | 4 SP |
| **基础数值** | **13**（公式：`(源石技艺适应性 × 2 + 战术规划) / 2`，向上取整） |
| **效果** | 将法术能量扩散至一片区域。对半径 10m 范围内的所有敌人造成一次法术伤害。范围内的敌人每多一个，基础数值 -1（最低降至原始值的 50%）。 |
| **判定** | d20 + 基础数值 vs 各目标法术防御 DC |

### 过载施法 ★★★★★
| 字段 | 内容 |
|------|------|
| **稀有度** | 5 星 |
| **类型** | 攻击 / 法术 / 特殊 |
| **消耗** | 6 SP |
| **基础数值** | **27**（公式：`源石技艺适应性 × 3`） |
| **效果** | 突破自身极限的施法。下一次法术攻击（需在下一回合内使用）的基础数值 ×2。使用后自身陷入「过载」状态 2 回合：无法使用任何消耗 SP ≥ 2 的卡牌。 |
| **剧情影响** | ① 释放出的源石能量过于剧烈，场景中所有源石技艺检测设备将报警；② 周围的源石结晶会以肉眼可见的速度微量增长——对霜星而言，这意味着矿石病的加速恶化；③ 如果连续在 3 个场景中使用此卡牌，使用者的源石技艺适应性永久 +1，但生理耐受永久 -1。 |
| **判定** | 无需判定 |

### 扩散术师：术力风暴 ★★★★
| 字段 | 内容 |
|------|------|
| **稀有度** | 4 星 |
| **类型** | 攻击 / 法术 / 大范围 |
| **消耗** | 4 SP |
| **基础数值** | **8**（公式：`(源石技艺适应性 × 2 + 战场机动) / 3`，向上取整） |
| **效果** | 将法术能量如风暴般席卷战场。对半径 20m 范围内的所有敌人造成一次法术伤害。每命中一个敌人，自身获得 1 点「风暴充能」（最多 5 点），每点充能使下一次「术力风暴」的基础数值 +1。充能在战斗结束后清空。此卡牌为扩散术师子职业专属。 |
| **判定** | d20 + 基础数值 vs 各目标法术防御 DC |
