# 角色能力

佐菲娅不是前线战士，但她受过临光家族的基础战斗训练。她的真正能力在于社交和情报——在卡西米尔的社交圈中，她是临光家族最有效的信息收集者。

## 专属卡牌

### 基础剑术 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 攻击 / 物理 / 单体 |
| **消耗** | 1 SP |
| **基础数值** | **6**（公式：`战斗技巧`） |
| **效果** | 佐菲娅用临光家族最基础的剑术进行一次斩击。她不是骑士——在姐姐玛嘉烈和妹妹玛莉娅的光芒下，佐菲娅的剑术显得普通——但她从家族训练场上继承的肌肉记忆足够应付大多数情况。若本回合佐菲娅处于防守姿态，命中判定 +1（"等对方犯错——这是临光家的剑术里我唯一学得不错的部分"）。 |
| **判定** | d20 + 基础数值 vs 目标物理防御 DC |

### 社交之眼 ★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 2 星 |
| **类型** | 辅助 / 社交 / 感知 |
| **消耗** | 1 SP |
| **基础数值** | **13**（公式：`魅力 + 战术规划`） |
| **效果** | 佐菲娅在卡西米尔社交圈多年练就的眼力——她能在觥筹交错中捕捉到最有用的信息。在社交场合中，佐菲娅可以自动感知到：① 当前房间中最有权力的人（不是名义上的主人，而是实际掌控局面的人）；② 正在发生的社交暗流（谁在拉拢谁、谁在孤立谁）；③ 一个值得注意的社交线索（GM 选择一项最相关的信息揭示）。此被动在佐菲娅进入任何有 5 人以上的社交场合时自动触发。 |
| **判定** | 无需判定（GM 提供信息） |

### 临光的家徽 ★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 5 星 |
| **类型** | 辅助 / 光环 / 家族 |
| **消耗** | 5 SP |
| **基础数值** | **11**（公式：`(魅力 × 2 + 情绪稳定性) / 2`，向上取整） |
| **效果** | 佐菲娅从怀中取出临光家族的家徽——不是作为装饰，而是作为宣告。当她把家徽举在身前时，光芒从徽记中涌出——这是临光家族每个人都能唤起的血脉之力，但佐菲娅的方式不同：它不是光照，而是一道温暖的金色屏障。进入「临光的庇护」状态，持续 3 回合：① 半径 25m 内所有临光家族成员（玛嘉烈、玛莉娅、玛恩纳）全判定 +3——"家徽回应了他们的血脉"；② 所有友方非临光单位获得 +1 物理防御——"临光的光芒庇护所有与她们并肩作战的人"；③ 佐菲娅本人本回合无法进行攻击——她的全部精力都在维持这道光。 |
| **剧情影响** | ① 在卡西米尔贵族或骑士面前展示家徽会引发强烈反应——敬畏、敌意、或某种复杂的沉默。临光家族在卡西米尔的名字带着太多历史和债务；② 玛嘉烈（临光）如果在场，会沉默片刻——她知道佐菲娅从不愿意依靠家徽的力量。"这是她的方式——她选择了站在家人前面，而不是站在家人背后"；③ 玛莉娅（瑕光）如果在场，会第一次意识到——在姐姐的光芒之外，还有一个女人的光芒在默默照着她；④ 连续使用（3 个场景内 2 次及以上）会导致佐菲娅进入「血脉透支」——生理耐受 -1，持续至战役下一章结束。家徽的力量不是免费使用的。 |
| **判定** | 光环自动生效（无需判定） |

### 家族的脊梁 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 辅助 / 家族 / 觉醒 / 终局 |
| **消耗** | 8 SP（仅可在至少一名临光家族成员生命值 < 25% 时触发——"当她们倒下的时候，必须有人站着"） |
| **基础数值** | **19**（公式：`(魅力 + 情绪稳定性 + 战术规划) / 3 × 3.0`，向上取整） |
| **效果** | 佐菲娅站了出来——不是作为"玛嘉烈的妹妹"或"玛莉娅的姐姐"或"玛恩纳的侄女"，而是作为佐菲娅·临光。当所有人都倒下时，她是那个扶起所有人的人。进入「脊梁」状态，持续 2 回合：① 所有临光家族成员立即恢复至最大 HP 的 50%（无论之前 HP 为多少）——"家徽回应了她的呼唤，以她的意志为通道"；② 所有临光家族成员移除所有负面状态；③ 佐菲娅在 2 回合内免疫所有伤害（"她站在风暴的正中心，但风暴无法触及她——因为她比风暴更坚定"）；④ 状态结束后，佐菲娅陷入「燃烧殆尽」——全属性 -2，持续至该战役结束。 |
| **剧情影响** | ① 这一幕中的所有临光家族成员——无论此前他们对佐菲娅有多少下意识的轻视（"她没有战斗力""她不是骑士"）——将永远改变看法。玛嘉烈会在此战后第一次对佐菲娅使用敬语；② 玛恩纳如果在场，会在战后对佐菲娅说一句话——这是他作为临光家族最长者给出的认可。这句话会成为佐菲娅角色弧线的关键节点；③ 卡西米尔的贵族圈中会传出消息："临光家族不只有骑士。那个'没有上过战场的那个'——才是临光家族真正的脊梁。"这些传言会以微妙但不可逆转的方式改变佐菲娅在社交圈中的地位；④ 佐菲娅本人会在战后一个人待着——不是虚弱，而是她终于明白了自己在家族中的位置。如果有人在这时找到她，她会说出一个她藏了十几年的秘密。 |
| **判定** | 效果自动生效。家族成员恢复无需判定；免疫伤害无需判定 |
