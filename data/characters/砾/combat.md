# 角色能力

## 专属卡牌

### 飞刀投掷 ★

| 字段 | 内容 |
|------|------|
| **稀有度** | 1 星 |
| **类型** | 攻击 / 物理 / 远程 |
| **消耗** | 1 SP |
| **基础数值** | **9**（公式：`战场机动`） |
| **效果** | 砾从袖口滑出一柄短飞刀，向 15m 内的单个目标投出。此攻击若从隐蔽状态（未被目标察觉）发起，命中判定获得 +2 修正——扎拉克的敏捷和特种训练让她的投掷几乎没有预兆。飞刀在使用后可以回收（除非投掷到无法接近的位置）。 |
| **判定** | d20 + 基础数值 vs 目标物理防御 DC |

### 反监视训练 ★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 2 星 |
| **类型** | 辅助 / 感知 / 反侦察 |
| **消耗** | 1 SP |
| **基础数值** | **14**（公式：`战术规划 + 情绪稳定性`） |
| **效果** | 常年作为博士的影子护卫，砾养成了"观察观察者"的习惯。在任何场景中，砾可以主动判断队伍是否被跟踪、监视或盯梢。GM 需揭示：① 是否有人正在监视队伍；② 若有，发现其中一名监视者的方位（如果监视者不止一人，发现最近的那一个）。此能力与银灰的「谈判的艺术」不同——银灰读人，砾读阴影。 |
| **判定** | d20 + 基础数值 vs 监视者的隐匿 DC |

### 无胄盟的遗产 ★★★★★★

| 字段 | 内容 |
|------|------|
| **稀有度** | 6 星 |
| **类型** | 攻击 / 物理 / 暗杀 / 终结 |
| **消耗** | 8 SP（仅可在博士或一名指定的保护对象面临即死威胁时触发） |
| **基础数值** | **24**（公式：`(战场机动 + 战斗技巧 + 情绪稳定性) / 3 × 3.0`，向上取整） |
| **效果** | 砾闭上眼睛——然后消失。在她睁开眼睛的那一瞬间，她不再是罗德岛的护卫干员，而是无胄盟培养出来的最致命的工具。砾对一个对保护对象构成直接威胁的目标发动一次不可闪避的致命一击。此攻击无视物理防御，伤害 ×2。使用后砾陷入「身份撕裂」状态 2 个场景：① 魅力 -3（她无法藏住眼睛里的空洞——那是无胄盟留下的）；② 无法使用「影卫」和「这是我能做的」——因为"影卫"是砾选择的身份，而此刻她短暂地放弃了她。 |
| **剧情影响** | ① 所有在场目击者——包括博士——第一次看到了砾从未展示过的一面。这不是那个随时随地跑到博士身边的热情扎拉克少女，而是一个杀人机器——致命的、高效的、面无表情的；② 白金（无胄盟成员）如果在场或之后得知此事，会以完全不同的眼光看待砾——不是轻视，而是某种复杂的同类认可；③ 砾在状态恢复后会主动找一个没有人的角落坐下来——不是疲惫，而是她需要确认自己还是"砾"。如果有其他角色在这时接近她，她可能会说出一句从未对任何人说过的话；④ 博士如果目睹了这一幕，将获得一个关于砾过去的记忆碎片——"无胄盟"，那个培养刺客的组织，是如何将一个女孩变成工具的。 |
| **判定** | d20 + 基础数值 vs 目标物理防御 DC（无视防御） |

### 影卫 ★★★（被动）

| 字段 | 内容 |
|------|------|
| **类型** | 被动 / 护卫 |
| **基础数值** | 16（公式：`战场机动 + 战术规划`） |
| **效果** | 砾始终在博士 10m 范围内保持警戒。博士受到任何先制攻击时，砾自动进行一次战场机动判定（DC 14），成功则代替博士承受该次攻击（伤害减半——砾知道怎么挨打）。此被动无需消耗，每回合可触发一次。 |
| **判定** | d20 + 战场机动 vs DC 14 |

### 暗面知识 ★★★（情报）

| 字段 | 内容 |
|------|------|
| **类型** | 辅助 / 情报 |
| **消耗** | 1 SP（非战斗场景） |
| **基础数值** | 14（公式：`战术规划 × 2`） |
| **效果** | 砾分享她对卡西米尔暗面的了解。博士在进行与卡西米尔暗面（无胄盟、商业联合会黑幕、地下情报网）相关的判定时，获得 +3 修正。此效果持续至场景结束。在长夜临光中，使用此卡牌可解锁砾对特定角色（白金、青金）的额外评论。 |
| **判定** | 无需判定（情报提供） |

### 短刀突袭 ★★★★（攻击）

| 字段 | 内容 |
|------|------|
| **类型** | 攻击 / 物理 / 突袭 |
| **消耗** | 2 SP |
| **基础数值** | 17（公式：`战场机动 + 战斗技巧`） |
| **效果** | 砾从侧面或背后发动一次快速的短刀攻击。若目标本回合未注意到砾（砾处于「隐蔽」或目标正在攻击他人），此攻击自动暴击（伤害 ×2）。砾不追求公平决斗——她追求目标在意识到发生了什么之前就已经倒下。 |
| **判定** | d20 + 基础数值 vs 目标物理防御 DC |

### 这是我能做的 ★★★★★（牺牲/护卫）

| 字段 | 内容 |
|------|------|
| **类型** | 牺牲 / 护卫 |
| **消耗** | 4 SP |
| **基础数值** | 17（公式：`战场机动 + 情绪稳定性`） |
| **效果** | 砾用自己的身体为博士挡下致命一击。效果：① 博士免除一次致命伤害（伤害全部由砾承受）；② 砾受到的实际伤害减半（她知道怎么在最后一刻调整身体角度）；③ 砾在承受伤害后仍然保持站立——但如果伤害超过她生命值的一半，她会在战斗结束后才允许自己倒下。 |
| **剧情影响** | 使用后，博士与砾的关系会质变。她不会再说是"职责"——她会沉默。那沉默比所有的话都更诚实。 |
| **判定** | 无需判定（自动替挡） |

## 通用卡牌池

### 特种 通用卡牌（6张）

1. **隐蔽移动** ★（移动）：1 SP，移动 15m 且不引发借机攻击。移动后进入「隐蔽」状态。

2. **弱点攻击** ★★（攻击）：2 SP，基础数值 = 战斗技巧 + 战场机动。攻击目标弱点——若上一轮有友方对该目标造成伤害，此次攻击获得 +2 修正。判定：d20 + 基础数值 vs 目标物理防御 DC。

3. **烟雾弹** ★★（辅助）：1 SP，投掷烟雾弹制造 5m 范围的重度遮蔽。持续 2 回合。范围内所有远程攻击判定 -4。

4. **侦察** ★★★（情报）：2 SP，基础数值 = 战场机动 + 战术规划。快速侦察一个区域，暗投感知判定。成功则 GM 提供隐藏信息（隐藏敌人、陷阱、秘密通道）。

5. **瘫痪打击** ★★★★（控制）：3 SP，基础数值 = 战场机动 + 战斗技巧。对目标发动一次精准攻击，若命中则目标下回合只能做一个行动（而非两个）。判定：d20 + 基础数值 vs 目标生理耐受 DC。

6. **无声清除** ★★★★★（暗杀）：5 SP，基础数值 = 战场机动 + 战斗技巧。仅在砾处于「隐蔽」状态且未被目标察觉时可用。对单个「士兵」或「精英」级目标发动暗杀攻击——伤害 ×3。若目标生命值低于 50%，此攻击即死。判定：d20 + 基础数值 vs 目标生理耐受 DC。
