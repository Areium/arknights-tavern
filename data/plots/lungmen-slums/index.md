# 龙门贫民窟危机

## 剧情概述

博士率领罗德岛小队抵达龙门，发现贫民窟区正处于暴乱边缘——一场嫁祸感染者的袭击事件激化了龙门近卫局与感染者社区之间的矛盾，而幕后黑手正试图利用这场混乱达成不可告人的目的。博士必须在多方势力之间做出抉择，每一个决定都将影响龙门未来的格局。

## 触发场景

**地点**：龙门贫民窟入口
**时间**：黄昏
**参与者**：陈（龙门近卫局警官）、林（感染者社区领袖）、？？？（幕后人物）
**触发方式**：主线剧情“博士的第一次任务简报”完成后，首次进入龙门时自动触发

## 章节大纲

### 章节 1：火药桶

**名称**：抵达龙门贫民窟
**概要**：博士抵达贫民窟即遭遇近卫局与感染者的对峙，必须阻止一场即将爆发的流血冲突

**场景设置**：
- 地点：龙门贫民窟入口——狭窄的巷道被临时路障分隔，两侧分别站着全副武装的近卫局警员和手持简陋武器的感染者居民
- 时间：黄昏，天色渐暗，巷道中只有几盏刺眼的白炽灯
- 氛围：一触即发的火药桶——双方都在等待对方先动手
- 出场角色：["陈", "林"]

#### 关键节拍（key_beats）

1. **beat_arrival**：目睹冲突现场
   - **内容**：博士的小队抵达贫民窟入口，看到陈率领近卫局警员与感染者群体对峙。一个感染者少年被铐在近卫局一侧，他的姐姐正在路障另一侧哭喊
   - **强制对话**：陈必须说出“博士，这不是罗德岛该插手的事。龙门有自己的法律”
   - **揭示信息**：昨晚，一辆近卫局补给车在贫民窟附近被劫，两名警员被杀。凶器被发现时上面沾满了感染者的血迹

2. **beat_lin_appears**：林出面

   - **内容**：局势即将失控——一个紧张的近卫局警员手指已经扣在扳机上。博士必须在几秒钟内做出选择
   - **强制对话**：陈：“博士，退后！” 林：“你们罗德岛不是说要保护感染者吗？那就证明给我们看！”

#### 对话方向

- **陈**：公事公办但内心矛盾——她知道贫民窟的感染者不是真正的敌人，但作为近卫局警官，她必须维护秩序。语气克制，但提到“上次切尔诺伯格的事”时会有微妙动摇
- **林**：外表强硬内心绝望——她知道自己面对的是整个龙门的执法机器，但不站出来就没人会站出来。对罗德岛既期待又怀疑

#### 玩家选项方向

1. 站在陈和近卫局一边，要求感染者交出嫌犯
2. 站在林一边，质疑近卫局的证据链
3. 提出罗德岛作为中立方进行调查——先让双方各退一步
4. 保持沉默，观察局势发展（默认：一场小规模冲突爆发，贫民窟好感度降低）

### 章节 2：裂缝之间

**名称**：深入贫民窟
**概要**：博士进入贫民窟内部展开调查，发现袭击事件背后的真相远比表面复杂

**场景设置**：
- 地点：龙门贫民窟内部——拥挤的棚屋、昏暗的巷子、墙上涂着整合运动的标语（有些是旧的，有些是新刷的）
- 时间：夜晚
- 氛围：压抑而紧张——居民用警惕的目光打量每一个外来者，但也能感受到他们内心的疲惫和恐惧
- 出场角色：["林", "陈"]

#### 关键节拍（key_beats）

1. **beat_search_scene**：勘察袭击现场
   - **内容**：博士获准进入近卫局补给车被劫的现场。通过调查可以发现关键线索——地上的弹壳不是近卫局制式弹药，而是来自黑市的外国军火
   - **强制对话**：陈必须承认“这种弹药……不在龙门的军备清单中”
   - **调查判定**：战术规划 ≥ 12 的干员可以发现现场有第三组脚印，指向贫民窟外的方向
   - keep_on_deviate: true

2. **beat_child_rescue**：拯救感染者少年
   - **内容**：被羁押的感染者少年（第一章中铐在近卫局一侧的那个）在转移途中被不明身份的武装人员劫持。博士的小队恰好在附近
   - **强制对话**：少年被救下后说出关键信息——“三天前，有几个穿黑斗篷的人来贫民窟找过我。他们给了我一封信，让我交给林大姐。但信被近卫局搜走了……”
   - **分支**：如果玩家之前救过少年（选项1），少年会额外提供袭击者的体貌特征
   - keep_on_deviate: false

3. **beat_discover_letter**：找到那封信
   - **内容**：博士需要从近卫局的证物室取回那封信。这可以通过正式渠道（与陈协商）、非正式渠道（潜入证物室）、或第三方渠道（通过林的人脉）完成
   - **强制对话**：信件内容揭示一个名为“灰狐”的军火商正在向双方出售武器，刻意加剧冲突
   - **揭示信息**：灰狐与整合运动的残余势力有关联，但不是整合运动的正式成员——他是一个投机者
   - keep_on_deviate: true

#### 对话方向

- **林**：如果第一章中博士站在感染者一边或保持中立，林的态度会明显软化。她会带博士参观贫民窟的诊所（由感染者自己运营），展示社区的真实面貌。如果博士选择了武力镇压，林将拒绝直接对话，只通过中间人传递信息
- **陈**：如果博士协助近卫局，陈会私下分享她对这起案件的疑虑——“证据太完整了，反而像是被人摆好的。”如果博士站在感染者一边，陈在正式场合态度冷淡，但不会阻碍调查

#### 玩家选项方向

1. 全面信任林和感染者社区，将调查重点放在外部势力
2. 保持中立，同时从近卫局和感染者两方搜集信息
3. 怀疑林可能在隐瞒什么，暗中调查感染者社区内部
4. 直接追查“灰狐”，跳过政治斡旋

### 章节 3：三个目标

**名称**：猎狐行动
**概要**：博士锁定了三个关键目标——灰狐本人、他的军火库、以及他与近卫局内鬼的接头地点。必须同时行动

**场景设置**：
- 地点：龙门工业区（灰狐的藏身处）、废弃码头（军火库）、近卫局总部（接头点）——三个地点同步推进
- 时间：深夜至黎明
- 氛围：行动前夕的沉默——所有人都在等待第一声枪响
- 出场角色：["陈", "林", "灰狐"]

#### 关键节拍（key_beats）

1. **beat_planning**：制定行动计划
   - **内容**：博士必须分配罗德岛小队、近卫局力量、和感染者志愿者到三个目标。每个目标的难度和风险不同，人员分配决定了成败
   - **强制对话**：陈：“灰狐本人交给我。” 林：“军火库在我们贫民窟附近。那里我们最熟悉。”
   - **决策机制**：三个目标各需要不同的能力——灰狐（战斗技巧/源石技艺适应性）、军火库（战场机动/战术规划）、接头点（战术规划/魅力）
   - keep_on_deviate: false

2. **beat_arsenal**：突袭军火库
   - **内容**：在废弃码头的仓库中，小队发现灰狐的军火库规模远超预期——这批武器足够武装一个中队的兵力。更令人不安的是，一些板条箱上印着维多利亚军方的标记
   - **强制对话**：在场的干员必须警告：“这些不是黑市货。这是正规军的装备。”
   - **揭示信息**：灰狐背后可能有外国势力的支持，这不再是一起简单的内部冲突
   - keep_on_deviate: true

3. **beat_confront_fox**：直面灰狐
   - **内容**：在工业区的废弃工厂顶层，博士和陈终于对上了灰狐。但灰狐似乎并不意外——他一直在等待这一刻
   - **强制对话**：灰狐的独白——“你们以为自己在阻止一场冲突？可笑。冲突是龙门存在的基石。没有感染者的威胁，近卫局拿什么要预算？没有近卫局的压迫，整合运动拿什么招募新人？我只是……加速了必然发生的事。”
   - **核心分支**：灰狐提出一个交易——他可以交出军火库和全部情报，条件是放他走。陈主张逮捕，林主张处决，博士的投票将打破平局
   - keep_on_deviate: true

4. **beat_internal_mole**：内鬼现身
   - **内容**：在近卫局总部的接头点，内鬼的身份终于暴露——不是陈的副官（那是灰狐放的烟雾弹），而是一个更高层的人物：龙门商业联合会的一名代表，他与灰狐合作是为了制造危机、压低贫民窟的地价以进行商业开发
   - **强制对话**：内鬼：“你们想清楚了。动我，就是动龙门的经济命脉。魏先生本人也不会同意你们这么做的。”
   - **揭示信息**：这不是治安问题，而是阶级问题。感染者在龙门的困境根植于经济结构——有人靠他们的苦难获利
   - keep_on_deviate: true

#### 对话方向

- **灰狐**：一个冷静的机会主义者。他不恨感染者，也不爱近卫局。对他来说，冲突是一门生意。语气讽刺而坦诚，甚至对博士本人表现出某种扭曲的尊重——“你和我其实是一类人，博士。我们都看到了世界的真相，只是选择了不同的应对方式”
- **陈**：进入工业区后，陈的克制开始松动。面对灰狐的指控——“龙门利用感染者”，她没有反驳。博士可以察觉到她对体制的信仰正在动摇
- **林**：在军火库的突袭中，林展现出惊人的战斗力——她的源石技艺在感染者中是最好的。她不是受害者，她是幸存者。但她也承认：“如果真的拿了这些武器，整合运动就是我们的榜样。我在努力不让自己变成第二个塔露拉。”

#### 玩家选项方向

1. 逮捕灰狐，交由龙门法律处置（法律途径——陈赞赏）
2. 接受灰狐的交易，放他走以换取情报（务实途径——罗德岛获得最大信息量）
3. 处决灰狐——感染者社区需要正义，而不是另一场交易（道德途径——林信任）
4. 将灰狐交给罗德岛处置——绕过龙门的司法系统（独立途径——得罪近卫局但获得一个囚犯和情报来源）

#### 偏离点（deviations）

- **触发提示**：在军火库的调查中，干员发现了一封装在特殊信封中的信，信封上有一个模糊的整合运动标记
