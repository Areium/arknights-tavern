# 剧情名称

## 剧情概述

用 1-2 句话描述该剧情的核心情境——不是预设的故事走向，而是这个世界此刻存在的矛盾切片。

示例：
阿米娅和凯尔希在控制中枢向博士汇报罗德岛当前的任务状况。三个紧急任务同时出现，罗德岛人手有限——而博士的每一个选择都在塑造指挥官在干员心中的形象。

## 核心冲突与定时炸弹

<!--
  这是剧情的引擎。写清楚：
  1. 谁和谁在冲突？为了什么？
  2. 如果玩家什么都不做，事态会如何一步步恶化？
  3. 定时炸弹给玩家紧迫感——他们可以拖延，但世界不会等他们。
-->

**核心冲突**：罗德岛的资源分配危机——三个任务争抢有限的人手，而每个任务背后都有关键的势力关系

**如果玩家不作为**：

| 时间 | 事件 |
|------|------|
| 第 1 回合 | 凯尔希单独做出决定，将资源全部投入到医疗任务。其他两个任务的窗口期开始关闭 |
| 第 3 回合 | 未被选中的任务窗口彻底关闭。感染者救援目标被整合运动抢先一步带走；龙门方面认为罗德岛“不够重视”而开始与其它组织接触 |
| 第 5 回合 | 罗德岛陷入被动——医疗任务虽然完成，但失去了龙门的外交机会和感染者社区的信任。凯尔希在报告中冷淡地写道：“这就是没有指挥官的结果。” |

**定时炸弹的叙事作用**：NPC 会在对话中提及恶化的迹象（“龙门那边好像不太高兴”“感染者社区那边有动静”），给玩家持续的压力信号。

## 触发场景

**地点**：罗德岛控制中枢
**时间**：早晨
**参与者**：阿米娅、凯尔希、博士
**触发方式**：首次进入控制中枢时自动触发

# 系统设计说明（非模板内容，供开发者参考）

## 六大核心原则

### 1. 写情境，不写故事
准备一个存在尖锐矛盾的世界切片，不预设玩家会怎么做。剧情文件是**情境生成器**而非**剧本**。

### 2. 动机驱动，而非事件驱动
每个 NPC 有独立的“想要/害怕/愿意为此”三要素。事件是 NPC 行动的结果，不是等待玩家触发的机关。

### 3. 节点化弹性结构
章节之间的 next 链是默认路径。每个章节内有多个入口和出口，玩家可以通过偏离点跳出默认路径。

### 4. 三线索规则
任何关键信息至少提供 3 条独立的获取路径（人证、物证、现场痕迹）。一条线索断了，还有别的路。同时接受玩家灵光一闪的合理推断——GM（即 LLM）应根据玩家推理的合理性动态调整线索的可见性。

### 5. 失败即新剧情
判定失败、推理错误不应导致故事卡死。偏离失败的 `fail_forward` 字段定义了失败后的新状况——更棘手、更有趣、但不阻塞推进。

### 6. 定时炸弹
如果玩家什么都不做，世界会自己往前走。时钟的每一阶段都应在 NPC 对话中有所体现，给玩家持续的紧迫感。

### 7. 节奏预算（pacing.md）
每个剧情应在 `pacing.md` 中定义节奏预算。目标总时长 30-60 分钟。内容应包含：
- 每章时间分配（开场合计 ~15%，上升 ~25%，高峰 ~40%，收束 ~25%）
- 每章战斗次数（总数 3-5 场，第一章不设战斗，第三章是峰值）
- 每章对话轮数（总数 12-18 轮，跟随戏剧张力曲线）
- 任务触发时机表（每个任务在哪个场景、以何种方式从 hidden → visible/active）

## 偏离与重规划流程

```
玩家在章节 N 中 → 触发偏离点 D
  ↓
检查条件：stat_check ∧ item_required
  ↓ 满足
Roll 判定：d20 + 相关属性加成 vs (difficulty + deviation_policy.base_difficulty)
  ↓ 通过
执行 on_success.narrative → 标记偏离成功
  ↓ on_success.replan == true
LLM 接收：当前章节之前的历史 + on_success.suggest_path + 剩余章节大纲
  → LLM 输出修改后的后续章节（保持 keep_on_deviate: true 的节拍）
  ↓
玩家进入重规划后的新章节
```

若条件不满足或 roll 失败：
- 执行 on_failure.narrative
- 执行 on_failure.fail_forward（如果存在）→ 产生新的剧情分支而非卡死
- 若 on_failure.lockout == true → 该偏离点永久关闭
- 若 lockout == false → 玩家可在后续回合重试

## 偏离条件设计原则

1. **三重门禁**：stat_check（硬门槛）+ item_required（收集要素）+ roll（随机性）
2. **难度曲线**：早期章节偏离难度高，后期可适当放宽
3. **不可回退**：偏离成功且触发 replan 后，原大纲被覆盖
4. **关键节拍保护**：keep_on_deviate: true 的节拍即使在偏离路径中也必须保留
5. **偏离 ≠ 更优**：偏离提供的是**不同的故事**，而非**更好的故事**。每个偏离应有补偿也有代价

## 章节设计原则

1. **线性主干，网状偏离**：next 链线性，偏离提供非线性分支
2. **每章 1-3 个偏离点**：过多让大纲失去意义，过少限制自由
3. **偏离后果可感知**：on_success.narrative 明确描述世界变化
4. **章节数建议**：主线 4-8 章，支线 2-4 章
5. **场景五感**：每个场景提供视觉、听觉、嗅觉、触觉、直觉/氛围的描述锚点

## key_beats 标记扩展

```yaml
- id: "beat_1"
  content: "阿米娅揭示罗德岛的真实目的"
  mandatory_line: "博士，罗德岛不仅仅是一家医药公司"
  keep_on_deviate: true  # 即使剧情偏离，此节拍也必须保留
  reveal: ["罗德岛秘密"]  # 此节拍揭示的信息
  clue_paths:             # 三线索规则：至少 3 条独立发现路径
    - "直接听阿米娅讲述（社交路径）"
    - "在终端上查到被加密的内部文件（战术规划 ≥ 14）"
    - "从凯尔希的一个口误中推测出来（战场机动 ≥ 12）"
```

## 定时炸弹（tension_clock）设计

时钟阶段数与剧情复杂度匹配：
- 支线：2-3 阶段
- 主线：3-5 阶段

每一阶段应有具体的、可被 NPC 提及的变化。不要在阶段 1 就说“一切正常”，要让玩家在第 1 回合就能感受到暗流涌动。

## 与角色卡的一致性

- stat_check 属性名必须与角色卡中的属性系统一致
- item_required 物品 ID 必须存在于物品索引
- 对话方向中的角色行为应与角色卡性格设定一致
- 关键人物的“想要/害怕/愿意”应基于角色卡的核心动机，但在本剧情中具体化
