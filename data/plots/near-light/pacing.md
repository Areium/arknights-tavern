# 节奏设计：长夜临光

## 一、时间基准

| 动作类型 | 耗时估算 | 说明 |
|---------|---------|------|
| 叙述阅读 | 20-40s / beat | 中文叙事 200-500 字，阅读时间 |
| 选项选择 | 10-20s / 次 | 从 3-4 个选项中选一个 |
| 自行输入 | 30-60s / 次 | 玩家打字思考 |
| 对话轮 | 1-2 min / 轮 | 玩家输入 + NPC 回应 + 叙事 |
| 战斗遭遇 | 3-5 min / 场 | 判定 → roll → 叙事 → 结果 → 后续 |
| 场景过渡 | 30-60s / 次 | 地点切换 + 氛围描述 |

## 二、章节时间分配

总计 **45-55 分钟**（在 30-60 目标区间内，留有弹性）：

| 章节 | 时间预算 | 占比 | 定位 |
|------|---------|------|------|
| 1. 开幕的鲜血 | 5-8 min | 15% | 开场、世界观建立、第一次情感冲击 |
| 2. 光芒与暗影 | 10-14 min | 25% | 角色关系深化、第一次战斗 |
| 3. 大停电之夜 | 18-24 min | 40% | 高峰——多线并行、最多战斗、关键抉择 |
| 4. 长夜将明 | 10-14 min | 25% | 收束——最终战斗、演讲、离别 |

## 三、每章战斗与对话设计

### 第一章：开幕的鲜血（5-8 min）

| 场景 | 类型 | 耗时 | 累积 |
|------|------|------|------|
| 1-1 广场抵达 | 叙述 + 对话 | 1.5 min | 1.5 min |
| 1-2 竞技场观战（杰米死亡） | 叙述（被动观看） | 2.5 min | 4 min |
| 1-3 退场通道（玛恩纳对话） | 对话 | 2 min | 6 min |

**战斗次数**：0（杰米事件是叙事节拍，不是互动战斗）

**对话轮数**：2-3 轮
- 与临光家族简短寒暄（1 轮，场景 1-1）
- 杰米事件后的反应选择（1 轮，场景 1-2）
- 与玛恩纳对话（1 轮，场景 1-3，可能触发 D2 延长 1 轮）

**支线触发点**：S1-1（赛后接触焰尾）、S1-2（询问佐菲娅）

### 第二章：光芒与暗影（10-14 min）

| 场景 | 类型 | 耗时 | 累积 |
|------|------|------|------|
| 2-1 工坊探索 | 叙述 + 对话 | 3 min | 3 min |
| 2-2 临光 vs 烛骑士 | 叙述（被动观看） | 2.5 min | 5.5 min |
| 2-3 巷战 + 绑架阻止 | **战斗** + 对话 | 5 min | 10.5 min |

**战斗次数**：**1 场**
- 工坊外围巷战（vs 白金 + 无胄盟底级成员 ×3-5）
- 设计为 2-3 个回合的中等长度战斗
- 玩家行动：选择 A（赶往现场）/ B（留在工坊）→ 决定战斗视角和奖励

**对话轮数**：3-4 轮
- 瑕光的工坊秘密（1 轮，场景 2-1）
- 比赛观感讨论（1 轮，场景 2-2）
- 巷战后的处理（1-2 轮，场景 2-3，含白金对话）

**支线触发点**：S2-1（套取白金情报）、S2-2（了解瑕光梦想）

### 第三章：大停电之夜（18-24 min）

| 场景 | 类型 | 耗时 | 累积 |
|------|------|------|------|
| 3-1 办事处停电 | 叙述 + 决策 | 3 min | 3 min |
| — 防御第一波袭击 | **战斗** | 3.5 min | 6.5 min |
| 3-2 街巷/长椅（玛恩纳对峙） | 叙述（选择是否到场） | 3 min | 9.5 min |
| — 可能的巷战遭遇（触发 D5） | **战斗**（条件触发） | 4 min | 13.5 min |
| 3-3 总部潜入/接应焰尾 | **战斗** 或 潜行判定 | 5 min | 18.5 min |
| 3-4 银枪天马入城 | 叙述（高潮收束） | 2 min | 20.5 min |

**战斗次数**：**2-3 场**
- 办事处防御（必打——无胄盟清洗小队 ×4，2-3 回合）
- 巷战遭遇（条件——触发 D5 时发生，vs 青金莫妮克 + 罗伊，3-4 回合）
- 总部潜入/接应（主要战斗——潜行 DC 判定链 + 可能的战斗，4-5 回合）
- 如果玩家选择留在办事处保护瑕光 → 办事处防御战加强

**对话轮数**：4-6 轮
- 停电瞬间的决策（1 轮）
- 防御后联络各方（1 轮）
- 与玛恩纳/罗伊/闪灵（条件）（1-2 轮）
- 总部/天台接应焰尾（1-2 轮）

**支线触发点**：S3-1（寻找玛恩纳）、S3-2（潜入总部获取情报）

### 第四章：长夜将明（10-14 min）

| 场景 | 类型 | 耗时 | 累积 |
|------|------|------|------|
| 4-1 半决赛（逐魇骑士） | 叙述 | 2 min | 2 min |
| 4-2 决赛（血骑士） | 叙述 + 赛前对话 | 4 min | 6 min |
| 4-3 颁奖 + 临光演讲 | 叙述（高潮） | 2 min | 8 min |
| 4-4 离别（瑕光赠礼） | 叙述 + 对话 | 3 min | 11 min |

**战斗次数**：0（观战——两场骑士对决是叙事节拍，不是玩家可以参与的互动战斗）

**对话轮数**：3-5 轮
- 半决赛后简短讨论（1 轮）
- 决赛前与临光/血骑士对话（支线 S4-1 / S4-2，各 1 轮）
- 颁奖后的回应（1 轮）
- 离别对话——瑕光（强制）、可选找玛恩纳（支线 S4-3）

**支线触发点**：S4-1（赛前找临光）、S4-2（赛前找血骑士）、S4-3（找玛恩纳）

## 五、节奏控制原则

1. **第一章不设战斗**——让玩家先建立情感连接（对杰米的愤怒、对临光家族的好奇），战斗从第二章开始
2. **第三章是峰值**——近一半时间在第三章，两到三场战斗集中在此，给玩家最密集的选择和后果
3. **第四章不设战斗**——比赛观看是叙事高潮而非互动战斗，结束时让玩家带着情感收束离开
4. **偏离点均分在前三章**——第四章是收束章，不给偏离出口（玩家已经做出了选择，现在是看结果的时候）
5. **对话轮数逐章递增到第三章，第四章回落**——与戏剧张力曲线一致

## 六、任务触发时机

根据上述节奏设计，任务的隐藏→触发时机如下：

| 任务 | 触发时机 | 触发方式 |
|------|---------|---------|
| M1-1 抵达大骑士领 | 场景 1-1 开场 | 自动（narrate 推进时系统激活） |
| M1-2 见证特锦赛开幕 | 场景 1-1 结束后 | 自动（进入竞技场时激活） |
| M1-3 认识玛恩纳 | 场景 1-2 结束后 | 自动（进入退场通道时激活） |
| S1-1 赛后接触焰尾 | 场景 1-3 | 玩家选择接触焰尾 |
| S1-2 询问佐菲娅 | 场景 1-3 | 玛恩纳离开后玩家与佐菲娅对话 |
| M2-1 探访瑕光工坊 | 进入第二章 | 自动 |
| M2-2 观战巅峰对决 | 工坊对话后 | 自动（前往竞技场） |
| M2-3 阻止绑架 | 比赛结束后 | 自动（收到警报） |
| S2-1 套取白金情报 | 场景 2-3 巷战后 | 玩家选择与白金对话 |
| S2-2 了解瑕光梦想 | 场景 2-3 | 玩家选择留在工坊 |
| M3-1 在黑暗中生存 | 进入第三章 | 自动（停电爆发） |
| M3-2 接应焰尾 | 场景 3-1 后 | 自动（收到焰尾通讯） |
| M3-3 见证银枪天马 | 场景 3-3 后 | 自动 |
| S3-1 寻找玛恩纳 | 场景 3-2 后 | 玩家选择寻找玛恩纳 |
| S3-2 潜入总部 | 场景 3-3 期间 | 玩家选择前往总部 |
| M4-1 见证决赛 | 进入第四章 | 自动 |
| M4-2 收束离别 | 决赛结束后 | 自动 |

| S4-2 赛前找血骑士 | 场景 4-2 赛前 | 玩家选择 |
| S4-3 找玛恩纳 | 场景 4-3 后 | 玩家选择 |
