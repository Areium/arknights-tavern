# 长夜临光 — 开局设置指南

## 一、开局总览

### 开场场景

**场景 ID**：`scene_arrival_plaza`
**地点**：大骑士领卡瓦莱利亚基——竞技场外广场
**时间**：特锦赛开幕日，上午
**触发方式**：完成 `first_briefing` 后，罗德岛接受监证会邀请抵达大骑士领时自动触发

### 第一个画面

> 竞技场的巨大阴影将广场切成明暗两半。在阴影与阳光的交界处，一位金发的骑士正等待着——她的身姿笔直，穿着一件普通的旅行外衣，但她站立的姿态仍然告诉你：这是一名骑士。在她身后，一个抱着工具箱的少女探出半个身子，用不加掩饰的好奇目光打量着罗德岛的运输车队。而在更远处，一个穿西装的男人靠在灯柱上，手中拿着一份报纸——报纸的日期是三天前的，他显然不是在看新闻。

### 初始出场人物

| 角色 | 身份 | 初始位置 | 对博士的态度 |
|------|------|---------|------------|
| **临光**（玛嘉烈·临光） | 耀骑士，外卡参赛者 | 广场中央，等候罗德岛车队 | 正式而坦诚——对罗德岛开放，但对妹妹的恐惧避而不谈 |
| **瑕光**（玛莉娅·临光） | 临光的妹妹，天才工匠 | 临光身后，抱着工具箱 | 好奇和期待——她听说过博士的很多事，想亲眼看看 |

## 二、角色选取

### 玩家角色

**博士是固定的玩家角色**——玩家始终以博士的身份行动。博士不需要选择。

博士在长夜临光中的角色定位：
- **身份**：罗德岛战术指挥官，接受监证会邀请访问卡西米尔
- **表面目的**：观看特锦赛、建立罗德岛办事处
- **实际目的**：改善卡西米尔感染者境遇、支持临光的回归
- **核心冲突**：作为外来者，博士在卡西米尔的政治影响力有限——但博士可以选择何时介入、如何介入、以及站在谁的一边

### 可选同行干员（开局配置）

在抵达大骑士领之前，博士需要在罗德岛舰船上选择 **2 名同行干员**（从已解锁的干员中选择）。这些干员将全程陪伴博士，参与所有场景。

**默认配置**（玩家不选择时自动使用）：
- 阿米娅（固定——作为罗德岛领袖，她必须出席外交场合）
- 砾（固定——自动担任博士的贴身护卫）

**推荐可选干员**（根据角色解锁情况）：

| 干员 | 推荐理由 | 独特作用 |
|------|---------|---------|
| **闪灵** | 卡西米尔出身，了解骑士文化 | 在大停电之夜登场（scene_mlynar_bench），与玛恩纳互相尊重；可在医疗场景中提供专业意见 |
| **银灰** | 对政治博弈有丰富经验 | 可在与商业联合会/监证会的谈判中提供策略建议；对权力结构的分析角度独特 |
| **德克萨斯** | 企鹅物流成员，熟悉灰色地带 | 可在工坊区巷战中提供战术支援；与托兰有潜在的雇佣兵行业共同语言 |
| **陈** | 龙门近卫局经验，执法视角 | 可对卡西米尔的法制状况提供对比分析；与临光的正义感产生共鸣 |

**选择建议（给玩家）**：
- 如果这是第一或第二次游玩：建议使用**默认配置**（阿米娅+砾），体验完整的剧情设计
- 如果已解锁闪灵：**强烈推荐**带闪灵——她在第三章有专属登场场景，带她可以解锁额外的对话和背景信息
- 如果想侧重战斗：带**德克萨斯**或**银灰**——他们在巷战（场景2-3）和谈判（场景3-1）中有额外选项

### 角色上下文加载

当博士选择同行干员后，系统自动执行以下加载：

1. **博士的角色卡** → 始终加载（系统注入博士的身份、性格、过往）
2. **同行干员的角色卡** → 完整加载（属性、卡牌、外貌）
3. **临光家族成员** → 随场景触发加载（开场时加载临光、瑕光、玛恩纳、佐菲娅的 core 数据）
4. **相关势力** → 随场景触发加载（开场时注入监证会、商业联合会、临光家族的 summary；后续随剧情深入注入 core）
5. **敌人数据** → 在战斗场景前加载（锈铜骑士在场景1-2加载，无胄盟清洗小队在场景2-3和3-1加载）

### 各章节可达地点

**第一章（开幕的鲜血）**：
- 竞技场外广场 → 竞技场内部 → 退场通道
- 不可自由移动——开幕日的流程由特锦赛赛程决定
- 唯一例外：如果触发偏离 D1（介入杰米死亡），则解锁「竞技场急救通道」

**第二章（光芒与暗影）**：
- 瑕光工坊 ⇄ 竞技场主赛场（通过运输车往返）
- 工坊外围街巷（仅在触发绑架事件后解锁）
- 玩家可以在工坊和赛场之间选择——但时间推进是线性的

**第三章（大停电之夜）**：
- 罗德岛临时办事处 → **三选一分歧**：
  - 方向 A：护送瑕光撤离 → 商业区外围长椅（scene_3-2）
  - 方向 B：支援焰尾 → 商业联合会总部（scene_3-3）
  - 方向 C：前往商业联合会总部（博士自行行动）
- 选择 A 可以顺路看到玛恩纳守街的场景
- 选择 B 可以参与焰尾潜入的接应（但无法同时看到玛恩纳的场景）
- **重要**：三个方向都有独特信息——玩家无法在一次游玩中看到全部内容

**第四章（长夜将明）**：
- 竞技场（半决赛→决赛→颁奖台）→ 城外公路
- 结局章节，线性推进

### 移动规则

- 同区内移动：即时，不消耗「时间回合」
- 跨区移动（如工坊→竞技场）：消耗 1 个「时间回合」，期间砾会汇报局势变化
- 大停电之夜（第三章）：时间回合同步进行——博士的选择直接影响哪些事件"被看到"和"被错过"

### 三选一分歧详解（第三章核心）

在大停电之夜（场景 3-1），博士必须在三条路线中选择一条。这是整个剧情中最重要的决策点——选择将影响第三章获取的信息和后续第四章的选项。

| 选择 | 博士在做什么 | 获得信息 | 错过的信息 |
|------|------------|---------|-----------|
| **A: 护送瑕光** | 保护瑕光撤离到安全地点 | 玛恩纳的真实实力、闪灵的登场、青金二人的态度动摇 | 焰尾潜入的细节、玄铁大位的谈判条件 |
| **B: 支援焰尾** | 潜入总部接应焰尾 | 感染者合同数据、商业联合会内部运作、玄铁大位的立场 | 玛恩纳守街的场景、闪灵的出场 |
| **C: 自行行动** | 不选 AB，自行探索 | 自由度最高，可能发现隐藏信息 | 无法深入参与 A 或 B 的核心事件 |

**建议**：
- 首次游玩：推荐选 **A**（护送瑕光）——这条路线展示玛恩纳的高光时刻和闪灵的登场，情感冲击最强
- 二次游玩：选 **B**（支援焰尾）——获得最多的政治情报和感染者合同数据，对理解整个卡西米尔的政治生态最有价值
- 深度探索：选 **C**——在 A 和 B 都已体验过的基础上，尝试寻找隐藏对话和情报

## 五、开局对话流程

### 第一阶段：抵达与寒暄（自动触发）

1. 罗德岛运输车停在竞技场外广场
2. 砾在博士耳边低声汇报安保状况——"广场上有三个商业联合会的人，两个无胄盟的眼线。但临光家族的人更多。博士——今天应该不会有意外。"
3. 临光走向博士，正式欢迎罗德岛的到来
4. 瑕光从临光身后探出头，开始一段关于她的新发明的长篇大论（被临光轻轻按住肩膀阻止）
5. 阿米娅代表罗德岛与临光进行正式寒暄
6. **第一个玩家选择时机**：博士如何回应临光的欢迎？

### 第二阶段：玩家首次选择

**选项 1**：「临光，罗德岛会尽我们所能。但在这之前——你妹妹刚才想说什么？」（转向瑕光，优先了解她）
  → 瑕光被点名后惊喜，讲述她设计的减震装置。临光的表情柔软了一瞬。砾在博士耳边低语："那个工具箱就是她的全部世界。保护好她，也就是保护了临光。"

**选项 2**：「感谢你的邀请，临光。但在承诺之前，我需要亲眼看看卡西米尔的骑士竞技。」（保持观察——这与临光开场词一致）
  → 临光点头——这正是她希望博士做的。瑕光微微失望（她期待博士会直接承诺帮助），但砾注意到临光眼中一闪而过的尊重——博士不轻易许诺。

**选项 3**：「阿米娅代表罗德岛做出正式回应。」（让阿米娅主导外交，博士保持沉默观察）
  → 阿米娅简短而体面地完成了外交辞令。博士的沉默被不同角色不同解读——临光认为是谨慎，瑕光认为是冷漠，玛恩纳认为是……似曾相识。

**选项 4**：（走向玛恩纳）「您一直站在远处。您也是临光家族的人。」（直接与最沉默的人对话）
  → 玛恩纳放下报纸。不是因为他被冒犯了——而是因为很少有人会在这种场合直接与他说话。"我姓临光。但我不需要自我介绍。博士——罗德岛在切尔诺伯格的事，我听说了。你运气很好。或者你很有种。我希望是后者。"

### 第三阶段：进入竞技场

在对话自然结束后，佐菲娅会过来提醒比赛即将开始。所有人进入竞技场。场景转换到 1-2。

## 六、核心系统交互

### 场景转换时的自动操作

当场景转换时，系统自动执行：
1. **角色加载/卸载**：新场景出场角色加载 core/full 数据；离开场景的角色卸载（保留好感度和状态变化）
2. **势力注入**：新场景涉及的势力注入 summary 或 core
3. **敌人加载**：如果新场景有敌人，加载敌人 core 数据
4. **氛围设置**：根据 scenes.md 的五感描述，为 LLM 注入场景氛围
5. **可选方向提示**：为玩家展示当前场景的可选行动方向

### 偏离判定

长夜临光的偏离判定使用全局 `base_difficulty: -3`（比默认更难偏离——卡西米尔是政治高压环境）。具体判定：
- 玩家输入 → 匹配预设偏离点（scenes.md 的 D1-D6）
- 未匹配 → 判断是否在可即兴范围内（场景的 `可即兴范围` 字段）
- 超出范围 → 判断是否触及硬边界（场景的 `场景硬边界` 字段）
- 未触及硬边界 → 视为动态偏离，设定临时 DC + roll

### 时间推进

卡西米尔特锦赛的时间是线性的——玩家不能回到过去的场景。时间推进由以下因素触发：
- 完成当前场景的关键节拍 → 自动推进
- 玩家选择移动（工坊→赛场）→ 消耗 1 时间回合
- 在大停电之夜，时间被压缩——多条事件线同时发生
