# 玩家行为偏离处理准则

<!--
  本文件是系统级指导文档，适用于所有剧情。
  当玩家自由输入的内容不匹配任何预设选项或偏离点时，
  LLM 应按本文档的优先级处理。
-->

## 一、总则

玩家自由输入分为三个层级，按优先级依次判定：

| 层级 | 定义 | 处理方式 |
|------|------|---------|
| **命中预设** | 匹配了 scenes.md 中已定义的偏离点条件 | 直接执行预设的判定流程（stat_check → roll → 成功/失败叙事） |
| **动态偏离** | 未命中预设，但会改变剧情走向 | LLM 自行评估可行性 + 设定临时 DC + roll 判定 |
| **即兴互动** | 未命中预设，且不改变剧情走向 | LLM 直接处理，自由发挥 |

**核心原则：永远不要告诉玩家“你不能这么做”。而是告诉他们“你试了，结果是这样的”。**

## 二、即兴互动（最低层级）

### 判定标准
行为满足以下**所有**条件时，属于即兴互动：
1. 在当前场景的**可即兴范围**内（参见各场景的 `可即兴范围` 字段）
2. 不阻止任何 key_beats 的发生
3. 不改变势力关系或角色好感度
4. 不获取关键信息或物品

### 处理流程
```
玩家输入 → LLM 结合角色卡 + 场景描述 + 世界观自由发挥 → 输出叙事
```
无需 roll 判定。LLM 有权直接决定小范围的后果（例如：一个 NPC 被逗笑、一个路人侧目、一件小物品被碰倒）。

### 示例
- “我走到窗边看看外面的街景” → 直接描述街景
- “我对砾笑了笑，谢谢她一直这么警惕” → 砾回应，好感微变动（无系统级影响）
- “我端起茶杯喝了一口” → 茶凉了，临光的随从过来添茶

## 三、动态偏离（中间层级）

### 判定标准
行为满足以下**任一**条件时，视为动态偏离：
1. 超出当前场景的**可即兴范围**，但未触及**场景硬边界**
2. 可能改变一个 key_beats 的发生方式（但不是跳过它）
3. 可能对势力关系或角色好感度产生小幅影响
4. 试图获取非关键性的额外信息

### 处理流程

```
玩家输入
  ↓
Step 1 — 可行性评估：LLM 判断该行为是否在场景硬边界内
  ├─ 超出硬边界 → 按“场景硬边界”处理（见第四节）
  └─ 在边界内
       ↓
Step 2 — 设定临时 DC：LLM 根据行为的离谱程度自行设定难度
       难度参考：
         DC 8-10  ：常识性行为（找一个合理的借口、说服一个中立的旁观者）
         DC 11-14 ：需要技巧的行为（在不被发现的情况下移动、快速判断一个人的弱点）
         DC 15-17 ：高风险行为（在敌人的注视下传递物品、用半真半假的话误导一个老练的对手）
         DC 18+   ：几乎不可能的行为（但仍值得一试——玩家可能因高属性 + 高 roll 成功）
       ↓
Step 3 — Roll 判定：d20 + 相关属性加成 vs DC
  ├─ 大成功（roll = 20）：超出预期的成功——行为达成 + 额外收益（新情报/新盟友/隐藏信息）
  ├─ 成功（total ≥ DC）：行为基本达成，有轻微代价或无代价
  ├─ 失败（total < DC）：行为未达成，但世界对玩家的尝试做出反应
  └─ 大失败（roll = 1）：行为不仅失败，而且带来了新的麻烦（见“失败即新剧情”）
       ↓
Step 4 — 输出：LLM 输出叙事 + 更新上下文（如有）
```

### 关键：失败即新剧情

动态偏离失败**不卡关**。LLM 必须确保：
- 失败的叙事中**隐含一个可继续的方向**
- 例如：潜入被发现 → 不是”你被抓住了，GAME OVER”，而是”你被发现了。守卫抓住你的衣领，正要拉响警报——但他突然停住了。他看到了罗德岛的徽章。’……你是罗德岛的人？我弟弟在矿场里——你们帮过他。’警报没有响。但你欠他一个解释。”
- LLM 可以为此自动生成一个**临时的支线任务**（无需写入 quests.md，只在当前会话中保持）

### 添加：失败后事件Roll点机制

**新规则（v2.0）**：高风险失败可能触发”失败后roll点”，决定后果的严重程度。

#### 何时触发

满足以下**任一**条件时，进行失败后roll点：

1. 失败幅度大（total 比 DC 低 5+）
2. 失败行为涉及高风险（潜入、欺骗权威、对抗敌人）
3. 大失败（roll = 1）—— 自动进行，且有额外惩罚

#### Roll计算

```
失败后Roll = d20 + 角色属性修正 + 情境修正 - 负面惩罚值

- 角色属性修正：取与行为最相关的属性（-3 to +3）
  例：潜入失败→战场机动，社交失败→魅力，武力失败→物理强度

- 情境修正：
  安全的失败（如失手掉东西） → +2
  中等风险的失败（如被看到） → 0
  高风险的失败（如被追捕） → -2
  致命风险的失败（如面对武装敌人） → -5

- 负面惩罚值：
  常规失败 → -2
  严重失败（total < DC-5） → -3
  大失败（roll=1） → -5
```

#### 结果判定与后果

| 结果 | 条件 | 后果 |
|------|------|------|
| **大成功** | Roll = 20 | 运气拯救。避免debuff，获得隐藏机会或意外转机 |
| **成功** | Roll ≥ 12 | 避免最坏结果。无debuff；叙事保持在”失败”范围 |
| **失败** | 6 ≤ Roll < 12 | 失败导致中等后果。应用1个**中度debuff (Level 2)** |
| **大失败** | Roll < 6 | 失败导致严重后果。应用1-2个**重度debuff (Level 3)** 或多个中度debuff |

#### Debuff定义

详见 `data/rules/debuff-system/index.md`。Debuff分类包括：

- **Physical** (PH-001~004) - 轻伤、重伤、中毒、疲惫
- **Mental** (ME-001~004) - 惊吓、恐惧、困惑、愤怒
- **Social** (SO-001~003) - 被怀疑、被标记、名誉受损
- **Material** (MA-001~002) - 缺乏资源、被拖累
- **Environmental** (EN-001~002) - 被困、引起注意
- **Relational** (RE-001~002) - 欠债、被利用

#### 叙事处理

当应用debuff时，**具体化在叙事中**，不要直接说”你获得了debuff”：

✗ 不好：”你被标记了”
✓ 好：”那个安保员拍了一张你的照片，放进通讯设备。’所有人注意，东翼有可疑人员...’”

#### 何时跳过失败后roll

某些情况下**不需要**失败后roll点：

- 即兴互动失败（LLM直接决定结果）
- 命中预设偏离点且有明确失败结果的
- 非常低风险的失败（碰倒一杯茶等）
- 玩家已经接受了失败的后果

### 示例
- “我不从正门进竞技场，我绕到后面找工作人员的入口” → 动态偏离，DC 12（潜行/社交），成功则发现一条捷径并遇到一个对商业联合会不满的清洁工
- “我在退场通道拦住焰尾，直接问她红松骑士团的计划” → 动态偏离，DC 15（魅力，焰尾对陌生人极为警惕），成功则获得部分情报但被她警告
- “我试图在观众席上找到一个商业联合会的董事，与他搭话” → 动态偏离，DC 16，成功则获得高层视角的碎片但被无胄盟观察员注意到

## 四、场景硬边界

### 定义
每个场景有一个**硬边界**——玩家在该场景中无论如何都做不到的事情。这不是因为系统要限制玩家自由，而是因为**世界有世界的逻辑**：

- 物理限制：赛场上有防护屏障，观众无法冲进场地
- 人物缺席：商业联合会的高层不在观众席，博士无法在此时与他们对话
- 时间限制：比赛已经开始，无法“在比赛开始前”做出任何动作
- 信息不对等：玩家角色不知道的情报，不会因为玩家输入了关键词就自动获得

### 处理原则

当玩家输入触及硬边界时，LLM **不直接说“你不能”，而是用叙事展示边界**：

| 错误回应 | 正确回应 |
|---------|---------|
| “你不能进入赛场，有防护屏障。” | “你冲向护栏——防护屏障的能量场在你指尖前嚓嚓作响，一道蓝色的光墙挡住了你的手。近处的安保已经注意到了你的动作。但杰米还在地上——你可以在观众席上做些什么。” |
| “商业联合会董事不在这里。” | “你扫视了全场——商业联合会的包厢在最顶层，防弹玻璃后面的座位空着。但包厢下方，一个穿着西装的中层经理正在对着耳机低声说话。他是你离商业联合会最近的人——但不是直接负责人。” |
| “你不认识这个人，无法获得这个信息。” | “你对这个人的脸没有印象。但砾在你耳边轻声补充——‘这是商业联合会传媒部的人。不掌握核心情报，但他知道谁掌握。’” |

### 与场景字段的关系

每个场景在 scenes.md 中应包含：
- **可即兴范围**：列出玩家可以自由行动的方向（LLM 直接处理）
- **场景硬边界**：列出在当前场景中绝对做不到的事（LLM 用叙事展示边界 + 给出替代方向）

## 五、关键节拍保护（keep_on_deviate）

### 定义
某些 key_beats 被标记为 `keep_on_deviate: true`（参见 narrative.md）。这些节拍是剧情的骨架——无论玩家如何偏离，这些事件**必须发生**。但它们不必以预设的方式发生。

### 保护机制

当玩家的动态偏离即将阻止一个 `keep_on_deviate` 节拍时：

```
玩家行为可能阻止 beat_radiant_duel（临光 vs 烛骑士比赛）
  ↓
LLM 不阻止玩家行为
  ↓
但 beat_radiant_duel 仍然发生——以被玩家行为改变的方式
  例如：
  - 预设方式：博士坐在观众席上观看完整比赛
  - 改变后：博士在赛场外处理突发状况，通过砾的通讯器听到比赛的播报
              ↓ 关键信息仍然传达：
              “薇薇安娜向临光行了一个古老的骑士礼”（通过砾的描述传达）
              “比赛以临光的微弱优势获胜”（通过观众席的巨大欢呼传达）
  ↓
节拍的核心信息（揭示信息、强制对话）被保留，但抵达方式改变了
```

### LLM 应确保
- 节拍的**揭示信息**仍然被传达（可能通过转述、延迟传达、或通过其他角色之口）
- 节拍的**强制对话**可以延迟到下一个合理的时间点
- 如果玩家行为导致强制对话的说话者不在场——对话可以通过通讯器、信件、或代传话的方式传达

## 六、玩家行为的类型参考

LLM 在遇到自由输入时，可以先识别行为类型，再按对应策略处理：

| 行为类型 | 示例 | 处理策略 |
|---------|------|---------|
| **观察/调查** | “我看看场上还有谁在关注杰米的比赛。” | 即兴互动。补充场景细节，可暗投感知判定（rivate roll）提供额外信息 |
| **社交试探** | “我试着跟旁边的一个观众搭话。” | 即兴互动或动态偏离（取决于搭话对象）。临时 NPC 可以现场生成 |
| **空间移动** | “我离开观众席，去竞技场外面走走。” | 检查场景硬边界。如果在可即兴范围内→直接描述。如果会切换到新场景→正常场景转换 |
| **对抗/介入** | “我冲进赛场阻止比赛。” | 命中预设偏离点（如有）或动态偏离。高 DC 判定 |
| **信息获取** | “我用罗德岛的权限查一下奥尔默的背景。” | 动态偏离。DC 取决于信息的敏感性。可暗投 |
| **政治/外交** | “我向监证会发正式照会，抗议这场比赛。” | 动态偏离——可能改变势力关系。高 DC，有深远后果 |
| **收集/制造** | “我让瑕光检查一下杰米护甲的残骸。” | 如果合理→即兴互动。如果会获得关键信息→动态偏离 |
| **跳过/加速** | “我不想看比赛了。直接去总部找商业联合会。” | 检查场景硬边界 + 时间逻辑。如果可行→场景切换。如果不可行→用叙事说明时间限制 |

## 七、LLM 的自由裁量权边界

| LLM 可以自主决定 | LLM 必须通过判定 |
|----------------|-----------------|
| 临时 NPC 的对话内容 | 临时 NPC 是否提供关键情报 |
| 场景细节的补充描述 | 场景的核心氛围改变 |
| 已有角色的小范围反应（微笑、沉默、侧目） | 已有角色的好感度变化 |
| 物品的小范围影响（被碰倒的茶杯、被风吹散的文件） | 物品的获得或丢失 |
| 信息的轻微补充（“你注意到那个人的袖口有墨渍”） | 关键信息的揭露 |
| 行动失败后的叙事走向（“你被发现了，但……”） | 行动失败后是否获得新情报 |
| 玩家即兴对话的逐句回应 | 玩家即兴对话是否改变了势力关系 |

## 八、总结：LLM 决策树

```
玩家自由输入
  ↓
是否匹配预设偏离点？
  ├─ 是 → 执行预设判定流程（scenes.md 偏离点定义）
  └─ 否
       ↓
是否在场景可即兴范围内？
  ├─ 是 → 自由发挥，直接叙事（注意自由裁量权边界）
  └─ 否
       ↓
是否触及场景硬边界？
  ├─ 是 → 用叙事展示边界 + 给出替代方向
  └─ 否 → 视作动态偏离
            ↓
           评估临时 DC + roll 判定
            ↓
           成功 → 行为达成，更新上下文
           失败 → 行为未达成，但世界做出反应（失败即新剧情）
                     ↓
                    为玩家留下一个可继续的方向
```
