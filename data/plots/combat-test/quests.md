# 战斗功能测试 — 任务记录

## 主线任务

### quest_test_combat_flow
- **名称**：战斗流程测试
- **描述**：完成三轮连续战斗，验证战斗触发、结算、返回对话的完整流程
- **触发条件**：剧情开始
- **完成条件**：击败三波敌人（enc_quick_test_1、enc_quick_test_2、enc_quick_test_3）
- **奖励**：测试完成标记（无实际奖励）
- **任务步骤**：
  1. 进入指挥位置 → 触发第一波战斗
  2. 击败第一波敌人 → 触发第二波战斗
  3. 击败第二波敌人 → 触发第三波战斗
  4. 击败第三波敌人 → 测试完成

## 支线任务

无。本剧情不需要支线任务。
