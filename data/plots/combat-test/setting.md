# 战斗功能测试 — 常量设定

## 核心设定

- **场景**：罗德岛训练场，模拟战斗系统已启动
- **目的**：验证战斗触发→结算→回到对话的完整流程
- **战斗模式**：`tactical`（战术模式）
- **登场角色**：阿米娅、银灰、霜星

## 关键规则

1. **开场即战斗**：第一条叙述必须包含 `[COMBAT:enc_quick_test_1]`
2. **连续触发**：每波战斗结束后，场景日志中的战斗结果会提示 LLM 下一波敌人已出现
3. **三波结束**：第三波战斗完成后，不再触发新战斗，宣布测试完成
4. **无偏离系统**：本测试剧情不允许偏离（deviation_policy.allow = false）

## 角色属性

使用默认角色属性即可。无需 overlay 修改。
