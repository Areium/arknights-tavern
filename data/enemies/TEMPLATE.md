# 战斗信息

<!--
  敌人在战斗系统中的数值与行为。
-->

| 字段 | 内容 |
|------|------|
| **战斗定位** | 近战输出 / 远程输出 / 防御坦克 / 辅助支援 / 炮灰 |
| **攻击方式** | 近战 / 远程物理 / 法术 / 混合 |
| **伤害类型** | physical / arts |
| **基础生命值** | 公式：`生理耐受 × 2 + tier × 3`（杂兵 8-12，首领 20-35） |
| **SP 上限** | 公式：`tier + 1`（杂兵 2，首领 7） |
| **物理防御 DC** | 公式：`10 + 生理耐受` |
| **法术防御 DC** | 公式：`10 + 源石技艺适应性` |
| **先攻加值** | 公式：`战场机动 - 5`（-3 到 +5） |
| **部署费用** | 击败后获得的部署费用（通常 = tier） |

# 能力

<!--
  敌人的特殊能力/技能。与角色卡牌类似格式，但更精简。
  每个能力包含：名称、类型、SP 消耗、基础数值（含公式）、效果、判定 DC。
  能力的 SP 消耗通常与 tier 挂钩——杂兵 1-2 SP，首领可达 5-6 SP。
-->

### 技能名

| 字段 | 内容 |
|------|------|
| **类型** | 攻击 / 防御 / 辅助 / 法术 |
| **消耗** | X SP |
| **基础数值** | 公式：`属性A + 属性B` |
| **效果** | 技能效果的详细描述。写明触发条件、作用范围、持续时间。 |
| **判定** | d20 + 基础数值 vs 目标对应防御 DC |

# 行为模式

<!--
  定义敌人在战斗中的 AI 行为。GM/LLM 依据此节运作敌人。
-->

- **优先攻击目标**：最近的 / 生命值最低的 / 治疗者 / 术师 / 无差别
- **撤退条件**：生命值低于 X% / 队长阵亡 / 绝不撤退
- **增援行为**：呼叫增援（写明条件和增援类型）/ 不会增援
- **特殊行为**：警戒巡逻 / 扼守要道 / 保护特定目标 / 搜索隐藏敌人

# 外貌描写

<!--
  精简版——重点写战斗中可见的特征：体型、武器、防具、标志性外观。
  不需要角色的详细描写（发型、配饰等），但要有足够细节供战斗叙事使用。
-->

## 整体印象
一句话概括体型、姿态、给人的第一印象。

## 关键特征
- **体型**：身高、体格
- **武器**：武器类型、大小、状态（崭新/磨损/临时拼凑）
- **防具**：护甲类型、覆盖范围、破损情况
- **标志**：所属势力的徽章/标记位置、是否可见
- **源石结晶**：（仅感染者）结晶位置、大小
