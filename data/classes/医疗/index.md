# 医疗 / Medic

## 战斗定位

医疗干员是罗德岛战斗编队的生命线，负责恢复友方单位的生命值、解除异常状态，以及在战场上分散式的医学问题做出快速判断。他们的存在直接决定了队伍在持久战中的生存能力。医疗干员在非战斗场景中通常担任罗德岛的医生、研究员或教官。

## 子职业一览

- **医师**：单体治疗，治疗量稳定可靠
- **群愈师**：同时治疗范围内所有友方单位
- **疗养师**：额外提供强化效果或持续恢复
- **行医**：治疗附带元素损伤恢复
- **咒愈师**：以攻击敌人来治疗友方，输出与治疗并存
- **链愈师**：治疗可以弹射到多个目标

### 卡牌池概述
医疗的战斗卡牌以治疗、异常状态解除和生命维持为核心主题。卡牌效果注重生命回复、负面状态驱散和濒死守护。医疗卡牌的基础数值主要依赖「源石技艺适应性」和「情绪稳定性」——精湛的医疗源石技艺和冷静的判断力是医疗干员的灵魂。

**核心属性**：源石技艺适应性、情绪稳定性、战术规划
**战斗风格**：生命治疗、状态解除、濒死抢救、持续回复

- 医疗角色在对话中常表现出对生命状态的关注（"你看起来脸色不太好"）
- 在非战斗情境中自然承担起医疗职责，关注队友的健康状态
- 习惯于评估风险——对潜在的受伤可能性有专业的预判
