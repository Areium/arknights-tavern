# 罗德岛干员证 / Operator ID Card

## 物品描述

罗德岛正式干员的身份证明，一张卡片大小的证件，内置微型源石回路。正面印有持卡人的照片、代号和所属部门，背面是罗德岛的标志和一段编号。在罗德岛舰船上，干员证是通行、消费、获取资源的唯一凭证。

## 功能与效果

1. **身份识别**：干员证上的编号对应PRTS系统中的个人档案，是干员在罗德岛的唯一身份标识。
2. **门禁通行**：根据干员的权限等级，可开启对应区域的门禁。
3. **紧急定位**：内置的源石回路可发送定位信号，在遇险时便于搜救队定位。
