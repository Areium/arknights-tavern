# 剧情偏离状态系统

<!--
  本文档定义玩家与主线剧情关系的三种元状态，以及状态间的转换规则。
  与 _deviation-handbook.md 的区别：
  - _deviation-handbook.md 处理**行为层级**的判定（即兴互动 / 动态偏离 / 场景硬边界）
  - 本文档处理**叙事层级**的状态——玩家当前处于剧情的什么位置
-->

## 一、三种剧情状态

| 状态 | 四字 | 英文 | 定义 |
|------|------|------|------|
| **状态一** | **大纲之内** | On the Rails | 玩家沿主线大纲推进，场景、节拍、偏离点均在剧情文件的约束下运作 |
| **状态二** | **旁逸斜出** | Branching Out | 玩家偏离了预设章节路径，但行为仍在故事的世界观、角色关系和核心冲突范围内 |
| **状态三** | **天高海阔** | Off the Map | 玩家完全脱离当前剧情框架——离开剧情地区、拒绝核心冲突、或主动选择“不做这个故事”。游戏进入自由探索模式 |

> “旁逸斜出”出自古典文论，原指树木在主干之外自然斜生出枝杈——虽不循主线，却仍是同一棵树的血肉。恰喻状态二：偏离大纲，不失故事。

---

## 二、状态判定标准

### 大纲之内（状态一）

**进入条件**（默认状态）：
- 加载剧情后自动进入
- 玩家行为命中预设选项、预设偏离点、或在场景可即兴范围内

**特征**：
- 所有 key_beats 正常触发
- 偏离点按 scenes.md 中的预设判定执行
- tension_clock 正常推进
- 任务系统正常运作（hidden → visible → active → completed）

**LLM 叙写方案**：
- 严格遵循 narrative.md 的章节大纲和对话方向
- 场景五感、角色动机、节拍强制对话全部生效
- 偏离判定执行完整流程（stat_check → roll → 成功/失败叙事 + fail_forward）

---

### 旁逸斜出（状态二）

**进入条件**（满足任一）：
1. 玩家通过动态偏离判定（见 `_deviation-handbook.md` 第三节），行为改变了剧情走向但未脱离故事范围
2. 玩家通过预设偏离点且 `on_success.replan == true`——大纲被重规划，但仍是“同一个故事的不同版本”
3. 玩家连续 2 次以上选择“暂不推进主线”的选项（如反复探索、社交但不接任务），系统自动标记此状态

**特征**：
- 关键节拍（`keep_on_deviate: true`）仍会触发，但抵达方式可能改变
- 预设偏离点仍可触发，但 DC 可获得 -1 ~ -2 的宽松修正（玩家已在探索状态）
- tension_clock 继续推进，但 NPC 提及恶化迹象的频率降低（给玩家探索空间）
- 任务系统正常运作，但支线任务的触发概率提高

**LLM 叙写方案**：
- 以玩家的当前位置和兴趣点为中心展开叙事，而非强制拉回主线
- 主线事件的进展通过**间接方式**传达（传闻、通讯、NPC 提及），而非强制玩家到场
- 保留核心冲突的“引力”——NPC 的态度、环境的变化、定时炸弹的滴答声仍然存在，但不喧宾夺主
- 动态偏离的临时 DC 获得 -1 修正（玩家已处于探索状态，世界对他们更宽容）
- 每 3-5 轮对话，LLM 应提供一个**回到主线的自然入口**（如：一个 NPC 主动联系、一条紧急通讯、一个无法忽视的事件）

**示例**：
- 玩家在第一章结束后不进第二章的工坊，而是在大骑士领街头游荡 → 进入旁逸斜出。LLM 描述街头见闻、可能引入随机 NPC、但砾会在适当时机提醒“瑕光在工坊等我们”
- 玩家在巷战后不处理后续，开始调查无胄盟的内部结构 → 偏离成功，进入旁逸斜出。LLM 展开调查线，但临光的比赛仍在背景中推进

---

### 天高海阔（状态三）

**进入条件**（满足任一）：
1. **主动逃离**：玩家明确表示要离开当前剧情的地理范围（如“我离开大骑士领，回罗德岛”），且经过警告后仍确认
2. **拒绝核心冲突**：玩家明确拒绝剧情中所有可用任务和冲突方，且表示“我不想参与这件事”
3. **剧情自然结束**：主线剧情已通关，玩家选择继续在游戏世界中自由行动

**进入流程（逃离/拒绝触发时）**：

```
玩家输入表明逃离/拒绝意图
  ↓
Step 1 — LLM 识别：该行为超出场景硬边界，且不属于动态偏离（因为不是“换个方式推进故事”，而是“不做这个故事了”）
  ↓
Step 2 — 发出警告：
  “博士，如果你现在离开[地区]，[核心冲突]将按最坏的方向发展。
   [关键 NPC] 会 [具体后果]。
   你确定要离开吗？(y/n)”
  ↓
Step 3 — 玩家确认：
  ├─ 否定 → 继续当前状态（大纲之内 或 旁逸斜出）
  └─ 确认
       ↓
Step 4 — 生成结局叙事：
  LLM 基于 plot 文件的 tension_clock.final 字段 + 玩家已做出的关键选择，
  生成一段 200-500 字的“结局叙事”——描述玩家离开后世界如何发展，关键角色的命运如何收束。
  
  这段叙事是**终局性的**——它给这个剧情一个情感上的句号。
  ↓
Step 5 — 输出结局叙事 + 状态切换通知：
  “【剧情结束：长夜临光 — 逃离结局】
   
   [结局叙事正文...]
   
   ---
   剧情已结束。你仍可以在这片土地上自由探索、与NPC互动。
   输入 /plot 可加载新剧情。”
  ↓
Step 6 — 进入天高海阔状态
```

**特征**：
- 所有剧情约束解除：key_beats、tension_clock、任务系统全部停用
- 该剧情的 effects 字段**不生效**（因为剧情以“逃离”而非“完成”结束）
- 玩家可自由移动、社交、探索——纯沙盒模式
- 已建立的角色关系、好感度、获得的物品**保留**
- 玩家可以通过 `/plot` 命令加载新剧情，回到状态一

**LLM 叙写方案**：
- 完全自由的即兴叙事——没有章节大纲，没有预设节拍，没有偏离判定
- LLM 仅依赖：角色卡 + 世界观设定 + 已知势力关系 + 当前环境 + 已发生的历史
- 世界仍然“活着”——角色有自己的日常行为，势力关系可能因时间推移而自然演变
- NPC 会记得剧情中发生过的事，并在对话中提及
- 可以为玩家生成临时的小型事件和遭遇（不需要预设，纯即兴）
- **与“无剧情时的自由模式”行为一致**——本质上就是回到加载剧情前的沙盒状态

## 三、状态转换规则

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   ┌──────────┐    动态偏离成功      ┌──────────┐   │
│   │ 大纲之内 │ ─────────────────→  │ 旁逸斜出 │   │
│   │          │ ←─────────────────  │          │   │
│   └────┬─────┘   回到主线入口      └────┬─────┘   │
│        │                               │          │
│        │  主动逃离/拒绝冲突             │ 主动逃离  │
│        │  (警告→确认)                  │ (警告→确认)│
│        │                               │          │
│        │   ┌───────────────────────────┘          │
│        │   │                                      │
│        ▼   ▼                                      │
│   ┌──────────┐     加载新剧情(/plot)   ┌──────────┐
│   │ 天高海阔 │ ─────────────────────→ │ 大纲之内 │
│   │          │                         │ (新剧情) │
│   └──────────┘                         └──────────┘
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 转换细节

| 从 | 到 | 条件 | 说明 |
|------|------|------|------|
| 大纲之内 | 旁逸斜出 | 动态偏离成功 / 预设偏离 replan / 连续不推进主线 | 自动切换，不警告 |
| 旁逸斜出 | 大纲之内 | 玩家选择 LLM 提供的“回到主线”入口 | 自动切换，不警告 |
| 大纲之内 | 天高海阔 | 玩家主动逃离/拒绝冲突 → 警告 → 确认 | **必须经过警告和确认（双重确认）** |
| 旁逸斜出 | 天高海阔 | 同上 | **必须经过警告和确认（双重确认）** |
| 天高海阔 | 大纲之内 | 玩家使用 `/plot` 命令加载新剧情 | 新剧情的章节、任务、时钟全部重新初始化 |

### 不可逆性

- **大纲之内 → 旁逸斜出**：可逆（玩家随时可以回到主线）
- **大纲之内 / 旁逸斜出 → 天高海阔**：**不可逆**（该剧情已结束。即使加载同一个剧情，也是从头重来——之前的选择和后果已被结局叙事“封存”）
- **天高海阔 → 大纲之内**：只能通过加载**新剧情**实现（加载已结束的剧情视为重新开始）

## 四、逃离警告模板

当 LLM 识别到玩家有逃离/拒绝核心冲突的意图时，使用以下模板：

```
⚠ **剧情偏离警告**

你即将 [具体行动描述，如“离开大骑士领，放弃特锦赛”]。
这将导致以下后果：

- [剧情名称] 将以非正常方式结束
- [关键 NPC 1] 将 [具体后果]
- [关键 NPC 2] 将 [具体后果]  
- 该剧情的所有奖励无法获得
- 已建立的角色关系保留，但后续发展将按最坏方向收束

确定要这样做吗？请回复“确定”以继续。
```

**设计原则**：
1. 警告中的后果必须**具体**——引用实际的 NPC 名字、地点、和 tension_clock.final 内容
2. 不恐吓玩家——客观描述，不夸大
3. 给玩家一个“先看看结局再决定”的心理预期——结局叙事本身就是一种回报

## 五、结局叙事生成指南

当玩家确认进入天高海阔状态时，LLM 生成结局叙事应遵循：

### 内容要素
1. **时间跳跃**：以“XX天后/周后/月后”开头，描述玩家离开后的时间跨度
2. **关键角色收束**：至少提及 2-3 个主要 NPC 的最终命运（基于 tension_clock.final + 玩家已建立的关系）
3. **核心冲突的结局**：描述没有玩家介入时，核心冲突如何收场
4. **玩家的影子**：提及玩家角色的离开对世界的影响——哪怕只是“罗德岛的人走了，但他们留下的[某物/某人/某句话]没有被遗忘”
5. **开放结尾**：最后一句留一个“也许有一天……”的余地——不是为了续写，而是让这个结局像一扇虚掩的门

### 语气
- 不评判玩家的选择——不说“你本可以拯救他们”
- 写出自然而然的因果——玩家选择离开，所以世界按自己的逻辑走到了终点
- 保持剧情的基调——如果剧情是悲剧性的，结局可以沉重；如果是冒险性的，结局可以洒脱

### 长度
- 200-500 字（中文）

## 六、与现有系统的关系

| 现有系统 | 在天高海阔状态下的行为 |
|---------|----------------------|
| tension_clock | **停用**——时钟停止推进 |
| key_beats | **停用**——不再触发任何节拍 |
| 预设偏离点 | **停用**——无剧情框架可供偏离 |
| 动态偏离判定 | **停用**——所有行为均为即兴互动 |
| 任务系统 | **停用**——所有未完成任务自动标记为 failed |
| 场景硬边界 | **解除**——玩家可以前往任何已知地点 |
| 角色好感度 | **保留**——已建立的 NPC 关系仍在 |
| 已获得物品 | **保留** |
| buff/debuff 池 | **保留**——仍可通过命令抽取 |
| 环境系统 | **保留**——时间、天气、地点正常运作 |
| 角色卡 | **保留**——角色人格、记忆、对话风格不变 |
| 势力关系 | **保留**——但不会因新剧情而更新 |
| 结局叙事 | **仅生成一次**——在进入天高海阔时生成 |

## 七、系统实现要点

### GameAgent 新增属性

```python
self.narrative_state: str = "大纲之内"  # "大纲之内" | "旁逸斜出" | "天高海阔"
self.plot_ending_generated: bool = False  # 确保结局叙事只生成一次
```

### run() 分流

```
玩家输入
  ↓
检查 narrative_state：
  ├─ "天高海阔"
  │    ↓ 跳过所有剧情处理
  │    ↓ 直接调用 CharacterAgent / 自由叙事
  │    ↓ 检查 /plot 命令 → 加载新剧情 → 切回 "大纲之内"
  │
  ├─ "大纲之内" 或 "旁逸斜出"
       ↓ 正常处理（现有流程）
       ↓ 额外检查：是否触发“逃离”判定
       ↓ 如果触发 → 警告流程 → 结局叙事 → 切到 "天高海阔"
```

### 切换到旁逸斜出的自动检测

在 `run()` 中，连续检测到以下模式时自动标记为旁逸斜出：
- 连续 2 次以上输入未匹配任何预设选项或偏离点
- 且当前行为在场景硬边界内但不在主线推进方向上
- 不警告，静默切换（玩家可能没注意到状态变了，这是设计意图）
