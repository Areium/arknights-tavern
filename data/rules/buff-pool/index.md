# Buff & Debuff 抽取池

本文件定义 Buff（增益）和 Debuff（减益）的稀有度体系、抽取规则、以及完整池子。
与 `../04-debuff-system/` 的区别：本池是**随机抽取池**（gacha 式），04 是**失败后果系统**（因果式）。

## 一、稀有度体系

所有 Buff 和 Debuff 按六星稀有度分级：

| 星级 | 稀有度 | 英文 | d20 抽取范围 | 特征 |
|------|--------|------|-------------|------|
| ★ | 普通 | Common | 1-5 | 轻微效果，持续 1-2 回合 |
| ★★ | 稀有 | Uncommon | 6-10 | 适中效果，持续 2-3 回合 |
| ★★★ | 精良 | Rare | 11-14 | 显著效果，持续 3-4 回合 |
| ★★★★ | 史诗 | Epic | 15-17 | 强力效果，持续 1 个场景 |
| ★★★★★ | 传说 | Legendary | 18-19 | 改变局面级别，持续 1 个场景 |
| ★★★★★★ | 神话 | Mythic | 20 | 极其稀有，可跨场景持续或改变剧情走向 |

## 二、抽取规则

### 基础抽取

```
玩家或 LLM 决定"从 Buff 池/Debuff 池抽取"
  ↓
roll d20（无修正，纯运气）
  ↓
d20 结果映射到稀有度档位
  ↓
在该档位内随机选取 1 个 Buff/Debuff
  ↓
LLM 在叙事中具体化效果
```

### 抽取时机

| 时机 | 说明 |
|------|------|
| **剧情奖励** | 完成关键节拍、支线任务后，GM 可奖励一次 Buff 抽取 |
| **大成功** | roll = 20 时，除原有大成功效果外，额外赠送一次 1★-3★ Buff 抽取 |
| **大失败** | roll = 1 时，除原有大失败效果外，额外施加一次 1★-3★ Debuff |
| **场景转换** | 进入高风险场景时，GM 可暗中抽取环境 Buff/Debuff |
| **特殊事件** | 接触源石能量场、获得角色祝福、被势力标记等 |

### 修正抽取（可选）

如果玩家行为或情境提供了有利/不利条件，可以在 d20 上加减修正：

| 条件 | 修正 |
|------|------|
| 角色拥有相关专长 | +2 |
| 在有利环境中（如圣地、医疗站） | +1 ~ +3 |
| 在不利环境中（如活性源石区、敌占区） | -1 ~ -3 |
| 受到势力庇护 | +1 |
| 已背负多个 Debuff | -1（每 2 个 Debuff 额外 -1） |

修正后的 d20 结果不可低于 1，不可高于 20（超出范围的截断至边界）。

## 三、池子切换

### Buff 池 vs Debuff 池

| 池子 | 抽取场景 |
|------|---------|
| **Buff 池** | 奖励性抽取、大成功追加、角色祝福、战术优势 |
| **Debuff 池** | 惩罚性抽取、大失败追加、环境危害、敌对行动 |

### 定向抽取（可选规则）

玩家可以声明"我要在 [类别] 中抽取 Buff"（如"战斗类"），此时：
- d20 映射档位后，只在该类别内随机选取
- 如果该类别在该档位无可用条目 → 降级到通用池

## 四、Buff/Debuff 的生命周期

```
抽取 → 即时生效（LLM 叙事中体现）
  ↓
持续指定回合数/场景数
  ↓
到期自动消除（LLM 叙事中体现消退）
  ↓
部分 Buff/Debuff 可提前清除（通过特定行动）
```

### 叠加规则

- 同名 Buff/Debuff **不可叠加**（后抽取的刷新持续时间）
- 同类别不同名 Buff/Debuff **可叠加**（效果累加）
- 不同类别 Buff/Debuff **可并存**（互不影响）
- 最大同时持有数：Buff 3 个，Debuff 3 个（超出时玩家选择保留哪些）
