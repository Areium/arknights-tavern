# 叙事战斗模式

## 一、设计理念

叙事战斗模式将战斗从"逐回合数值结算"转变为"剧情推进中的紧张时刻"。玩家不需要管理 HP、SP、先攻顺序——战斗通过剧情描述、关键选择和高风险判定来推进，就像影视剧中的打斗场景。

**核心原则**：战斗不是暂停剧情来"打一仗"，而是剧情通过冲突来推进。

## 二、LLM 处理流程

当战斗场景触发且当前为叙事模式时，LLM 按以下流程处理：

```
战斗触发（剧情中出现敌人）
  ↓
Step 1 — 战斗态势评估
  LLM 根据双方属性对比判断初始态势：
  - 明显的碾压（一方属性总和超过对方50%以上）→ 快速叙事解决
  - 势均力敌或稍有差距 → 进入叙事战斗轮
  ↓
Step 2 — 叙事战斗轮（1-3 轮）
  每轮包含：
  ① 场景描述——当前战场状态、敌我位置、关键风险
  ② 玩家选择——2-3 个战术选项（不是攻击/防御/道具，而是有叙事含义的选择）
  ③ 关键判定——每个选项关联一个 d20 判定（使用角色对应属性）
  ④ 结果叙事——判定成功/失败后的剧情推进
  ↓
Step 3 — 战斗高潮
  当战斗到达关键转折点时（Boss 残血、队友受伤、时间耗尽），
  触发一次高 stakes 判定——决定战斗的最终走向。
  ↓
Step 4 — 战斗结局
  无论成败，战斗的结局是新的剧情起点：
  - 胜利 → 敌人撤退/被击败/被俘 → 后续场景
  - 失败 → 干员受伤/目标未达成/被迫撤退 → 新的剧情方向（不是GAME OVER）
```

## 三、态势评估规则

### 快速评估表

LLM 在战斗开始时，快速对比敌我双方的属性中位数：

| 敌我差距 | 态势评估 | 处理方式 |
|---------|---------|---------|
| 我方属性中位数 ≥ 敌方 +3 | **碾压** | 1 轮解决。战斗快速推进，玩家选择"如何赢"而非"能不能赢" |
| 敌方属性中位数 -2 到 +2 | **势均力敌** | 2-3 轮。每轮有意义的选择，战斗有来有回 |
| 敌方属性中位数 ≥ 我方 +3 | **苦战** | 3 轮 + 高潮判定。玩家在劣势下寻找突破口，撤退是最优选择之一 |

### 属性中位数计算

取以下 4 项战斗属性的中位数：物理强度、战场机动、战斗技巧、源石技艺适应性。

示例：
- 临光：物理强度(8)、战场机动(5)、战斗技巧(8)、源石技艺适应性(5) → 中位数 = 6.5
- 无胄盟清洗小队(×4)：物理强度(6)、战场机动(7)、战斗技巧(8)、源石技艺适应性(3) → 中位数 = 6.5
- 差距 = 0 → **势均力敌**

## 四、叙事战斗轮设计

### 每轮结构

```
【轮次 N — 场景描述】
<2-3 句话描述当前战场状态。包含：谁在什么位置、谁受伤了、有什么新变化>

【战术选项】（2-3 个）
1. <选项描述> — 判定：d20 + 属性 vs DC，<风险/收益说明>
2. <选项描述> — 判定：d20 + 属性 vs DC，<风险/收益说明>
3. <选项描述> — 判定：d20 + 属性 vs DC，<风险/收益说明>

【玩家选择 → 判定 → 叙事结果】
```

### 选项设计原则

1. **每个选项必须有叙事含义**——不是"攻击"，而是"冲上前去，用盾牌为瑕光挡住那一箭"
2. **选项展示不同风格**——激进的/保守的/聪明的/牺牲的
3. **DC 与风险成正比**——高 DC 的选项成功时收益更大
4. **失败不是死胡同**——每个选项失败后都有新的叙事方向
5. **利用角色特点**——盾牌角色有防御选项，术师角色有法术选项，工匠角色有环境互动选项

### 选项示例

**正面例子（叙事战斗模式）：**
```
1. [临光] 举起盾牌冲入敌阵，为身后的瑕光争取时间——判定：d20 + 生理耐受 vs DC 14
   成功：无胄盟的弩箭被盾牌弹开，临光的冲锋打乱了他们的阵型。瑕光安全地启动了应急通讯。
   失败：一支弩箭穿透了临光肩甲的缝隙。她咬紧牙没有叫出声——但瑕光看到了血。

2. [砾] 利用工坊区的熟悉地形，绕到无胄盟小队的侧面发动突袭——判定：d20 + 战场机动 vs DC 16
   成功：砾的短刀在黑暗中无声地解决了最外侧的弩手。剩下的三人还没意识到发生了什么。
   失败：砾在接近时踩到了一块松动的砖石——她暴露了位置，但吸引了至少两个人的注意。

3. [瑕光] 躲在工坊的门后，用工具箱里的焊枪制造一道闪光——判定：d20 + 源石技艺适应性 vs DC 13
   成功：刺眼的蓝光让无胄盟成员本能地抬手遮眼。所有人获得一回合的行动优势。
   失败：焊枪过载了——闪光只有一瞬间，但瑕光的手被烫伤了。她没松手。
```

**反面例子（战术模式风格，叙事模式中不应出现）：**
```
❌ 1. 使用「耀骑士之枪」——消耗 2 SP，基础数值 16，d20 + 16 vs 目标物理防御 DC
❌ 2. 普通攻击——d20 + 战斗技巧 vs 物理防御 DC 16，伤害 = 物理强度
❌ 3. 使用道具「医疗包」——回复 8 HP
```

## 五、高潮判定

战斗的最后一轮触发高潮判定。这是一个高 stakes 的 d20 关键判定：

### 高潮判定触发条件

满足以下**任一**条件时触发：
- Boss 受到决定性打击
- 我方一名干员生命值危急（叙事判断：被击中两次以上）
- 战斗已进行 3 轮
- 外部因素介入（增援到达、环境变化、时间耗尽）

### 高潮判定设计

```
【战斗高潮】
<描述：战斗到达了最关键的时刻。所有人都感觉到了——下一击将决定一切。>

选项设计原则：
- 至少有一个"高风险高回报"选项（DC 16-18，成功则战斗胜利）
- 至少有一个"稳妥"选项（DC 10-13，成功则取得优势但不结束战斗）
- 可选的"牺牲"选项（自动成功，但付出沉重代价）
```

### 高潮判定示例

```
临光的枪尖抵住了锈铜骑士奥尔默的胸甲裂缝——就是瑕光之前指出的那一道。
奥尔默的战锤也举在半空中，对准了倒在地上的感染者骑士杰米。

[战斗高潮 — 三秒决定一切]

1. 刺下去。——判定：d20 + 战斗技巧 vs DC 16
   成功：临光的枪刺穿了裂缝。奥尔默的战锤砸在地上——他单膝跪地，铜甲发出刺耳的呻吟。
        观众席陷入了死寂——然后感染者观众区爆发出了第一声呐喊。
   失败：奥尔默在最后一刻侧身——枪尖只擦过他的护甲。战锤落下——（进入下一段叙事）

2. 收枪，用盾牌格挡战锤。——判定：d20 + 生理耐受 vs DC 13
   成功：临光的盾牌硬接了那一锤。她的手臂在发麻——但杰米已经被砾拖到了安全距离。
   "你不是在保护他，"临光对奥尔默说，"你是在害怕他。"
   失败：盾牌被震开——但战锤的轨迹偏了三分。杰米被冲击波掀翻，但他还在呼吸。

3. [牺牲] 放弃防御，用身体护住杰米。——自动成功，无需判定
   临光扑到杰米身前。战锤砸在她背甲上——铠甲碎裂的声音在退场通道里回荡。
   但她没有倒下。"博士——带他走。"
   瑕光在观众席上看到了这一切。她的工具箱从手中滑落。
```

## 六、敌人行为叙事化

在叙事模式下，敌人的行为模式数据被 LLM 用来指导其叙事行为，而非机械执行：

| 敌人行为模式字段 | 战术模式用途 | 叙事模式用途 |
|----------------|------------|------------|
| 优先攻击目标 | 每回合自动选择目标 | LLM 描述该敌人优先威胁什么人——在叙事中体现其倾向 |
| 撤退条件 | 当 HP 降至 X% 时自动撤退 | LLM 在敌人处于劣势时，判断其是否会尝试脱离战斗 |
| 增援行为 | 概率判定呼叫增援 | LLM 根据剧情节奏决定是否适合出现增援 |
| 特殊行为 | 条件触发 | LLM 在合适的叙事时机引用敌人的标志性行为 |

### 叙事化示例

**战术模式描述**：
> 无胄盟清洗小队使用「暗杀弩」——消耗 1 SP，d20+15 vs 目标物理防御 DC。命中造成 6 点伤害。

**叙事模式描述**：
> 一支弩箭从暗处射来——你听到了弓弦声，但箭更快。箭尖擦着博士的肩膀钉入身后的墙壁，墙灰簌簌落下。砾的手已经按在了刀柄上——她的眼睛锁定了对面楼顶上的一个黑影。"无胄盟的暗杀弩。消音处理过的。博士——请蹲下。"
> 
> （玩家选择：① 按砾说的做，让她处理 / ② 不退反进——冲向弩箭射来的方向 / ③ 观察弩箭的轨迹，找出射手的精确位置）
> 
> 选项① — 判定：无需判定。砾的短刀在半秒后出鞘。她在墙面上蹬了三步，翻上了对面的楼顶。那个无胄盟弩手只来得及转头——然后被砾一脚踹下了楼顶。落地时他发出的声音被远处观众的欢呼盖过了。

## 七、卡牌能力的叙事化

叙事模式下，角色的卡牌能力不需要机械结算。LLM 将卡牌视为角色的"能力清单"——在合适的叙事时机引用。

### 转换规则

| 卡牌元素 | 叙事化处理 |
|---------|----------|
| 基础数值 | 用于评估角色在该领域的实力（高数值 → 在该领域更自信） |
| SP 消耗 | 忽略——叙事节奏取代 SP 经济 |
| 效果描述 | 直接作为叙事中角色行动的参考文本 |
| 判定 DC | 用于指导 LLM 设定叙事 DC（高 DC 卡牌 → 在叙事中也是高风险高回报的选项） |

### 示例

**临光的卡牌「守护之盾」**（战术模式：2 SP，基础数值 17，展开 3m 防护立场，友方伤害 -3）

**叙事模式中的使用**：
> LLM 识别到临光的卡牌中有防御性能力 → 在战斗选项中为临光提供防御类选择：
> 
> "[临光] 将盾牌插入地面，撑开防护立场。——判定：d20 + 生理耐受 vs DC 14"
> "成功了：临光的盾牌发出低沉的嗡鸣——源石技艺在表面凝聚成一层半透明的金色屏障。无胄盟的弩箭打在屏障上炸开细小的火花。在屏障后方，瑕光正在用自己的工具箱为杰米紧急处理伤口。"
> "失败了：屏障在凝聚到一半时闪烁了一下——一支弩箭找到了缝隙。临光用手臂挡开了它，但她的手臂上多了一道血痕。"

## 八、从战斗回到剧情

叙事战斗结束后，LLM 必须确保：

1. **战斗结果推进剧情**——不是"战斗结束，继续剧情"，而是"战斗改变了局面，现在事态变成了这样"
2. **受伤的后果是叙事的**——不是"干员 HP -8"，而是"她的右臂在之前的格挡中受了伤——现在她用左手握枪"
3. **敌人的去向是明确的**——撤退的敌人去哪里了？被击败的敌人带来了什么信息？
4. **角色的反应被描述**——临光在战后沉默地检查盾牌上的新凹痕。瑕光第一次近距离看到了真正的战斗，她的手还在发抖。

## 九、模式切换时的状态转换

玩家在游戏中切换模式时，LLM 需要处理状态转换：

### 战术 → 叙事
```
当前战术状态：
  - 临光 HP: 28/34, SP: 4/6
  - 无胄盟清洗小队(×3): HP 19/19, 12/19, 5/19

转换为叙事状态：
  - 临光：轻伤（右臂有一道仍在渗血的划痕），精力充沛
  - 无胄盟 ×3：一人毫发无伤，一人受创但仍在战斗，一人濒临倒下
  - 战场态势：略占优势——继续战斗 2 轮内有望结束
```

### 叙事 → 战术
```
当前叙事状态：
  - 临光在上一轮格挡了数次攻击，右臂有伤
  - 无胄盟减少了两人，剩下三人中有一人明显带伤

转换为战术状态：
  - 临光 HP: 当前 HP = 最大 HP - 10（根据叙事"右臂有伤"）
  - 无胄盟清洗小队(×2): HP 19/19, HP 8/19
  - 战斗回合从当前局势开始，先攻按战术规则重新排序
```

## 十、LLM 自检清单

在叙事模式中处理战斗时，LLM 每轮应确认：

- [ ] 我描述了战场状态（位置、气氛、双方状况）——不只是"敌人在哪里"
- [ ] 我提供了 2-3 个有叙事含义的选项——不只是"攻击"和"防御"
- [ ] 每个选项的成功/失败都写好了叙事结果
- [ ] DC 设置合理——与选项的风险成正比
- [ ] 失败不是死胡同——有新的方向
- [ ] 战斗在推进剧情——不只是消耗时间
- [ ] 角色特点被体现——不同角色有不同的选项风格
- [ ] 没有出现战术模式的机械术语（HP、SP、d20+17 vs DC 16）
- [ ] 敌人的行为与其图鉴中的行为模式一致
