# 战斗系统规则

## 〇、战斗模式（玩家可选）

本系统支持两种战斗模式，玩家可在游戏开始前选择，也可在游戏中随时切换：

| 模式 | 设置值 | 适用玩家 | 战斗表现 |
|------|--------|---------|---------|
| **战术模式** | `tactical` | 喜欢策略战斗和数值判定的玩家 | 完整的回合制 d20 战斗系统（本文档第1-8节） |
| **叙事模式** | `narrative` | 只喜欢剧情、不想管理战斗数值的玩家 | 战斗自动转为叙事推进，通过剧情选择 + 少量 d20 关键判定解决（详见 [narrative-mode.md](narrative-mode.md)） |

**默认设置**：`narrative`（叙事模式）——降低新玩家门槛。熟悉系统的玩家可切换为战术模式。

**切换方式**：
- 游戏中输入 `/combat tactical` → 切换为战术模式
- 游戏中输入 `/combat narrative` → 切换为叙事模式
- 创建会话时在设置中指定默认模式

**底层数据不变**：两种模式共用相同的角色属性、敌人图鉴、卡牌数据。叙事模式下，这些数据作为 LLM 判断战斗走向的参考（谁更强、哪一方有优势），而非逐回合结算的数值。

## 一、设计原则（战术模式）

本战斗系统为轻量级 d20 判定系统，兼顾数值公平与叙事流畅。核心原则：

1. **属性驱动**：所有战斗数值由 8 项属性通过公式计算，与角色卡/敌人图鉴系统完全兼容
2. **敌我对称**：角色与敌人使用相同的公式体系，确保数值公平
3. **卡牌化行动**：特殊能力以卡牌形式呈现，包含消耗、基础数值、效果、判定 DC
4. **叙事优先**：判定失败不等于回合浪费——每次失败都推动叙事向前

## 二、角色战斗数值公式

### 生命值（HP）

```
角色 HP = 生理耐受 × 3 + 10

参考范围：
  生理耐受 3 → HP 19（脆皮术师）
  生理耐受 6 → HP 28（标准干员）
  生理耐受 9 → HP 37（重装干员）
```

### 防御 DC

```
物理防御 DC = 10 + 生理耐受
法术防御 DC = 10 + 源石技艺适应性
```

### SP 上限

```
角色 SP 上限 = 6

说明：角色 SP 上限统一为 6，通过卡牌消耗设计区分强弱——
低星卡牌消耗 1-2 SP，高星卡牌消耗 3-6 SP。
```

### 先攻加值

```
先攻加值 = 战场机动 - 5（范围 -3 到 +5）
```

## 三、敌人战斗数值公式

### 生命值（HP）

```
敌人 HP = 生理耐受 × 2 + tier × 3

参考范围（按 tier）：
  tier 1（杂兵）：HP 8-12
  tier 2（标准）：HP 13-18
  tier 3（精锐）：HP 19-24
  tier 4（精英）：HP 25-30
  tier 5（首领）：HP 31-37
  tier 6（传说）：HP 38-45
```

### 防御 DC

```
物理防御 DC = 10 + 生理耐受
法术防御 DC = 10 + 源石技艺适应性
```

### SP 上限

```
敌人 SP 上限 = tier + 1（范围 2-7）
```

### 先攻加值

```
先攻加值 = 战场机动 - 5（范围 -3 到 +5）
```

## 四、回合结构

每个战斗回合按以下顺序执行：

1. **先攻判定** — 所有参与者投 d20 + 先攻加值，从高到低排序
2. **角色回合** — 角色依次行动，每个回合可执行：
   - 1 个**主要行动**（攻击、使用卡牌、互动）
   - 1 个**移动**（最多 10m，或按战场机动值调整）
   - 1 个**自由动作**（简短对话、切换武器、拾取物品）
3. **敌人回合** — 敌人按行为模式行动
4. **回合结束** — SP 自然回复 1 点（敌我双方）

## 五、攻击判定

### 基础攻击

角色进行普通攻击时，使用以下判定：

```
物理攻击：d20 + 战斗技巧 vs 目标物理防御 DC
法术攻击：d20 + 源石技艺适应性 vs 目标法术防御 DC
```

- 命中（≥ DC）：造成基础伤害
- 暴击（d20 = 20）：伤害 ×2
- 未命中（< DC）：攻击落空——但叙事上不是"你打偏了"，而是"目标挡开了你的攻击"

### 基础伤害

```
物理伤害 = 物理强度（最低 1 点）
法术伤害 = 源石技艺适应性（最低 1 点）
```

### 卡牌能力

卡牌能力有独立的**基础数值**和**判定 DC**，详见角色卡牌或敌人能力。基础数值由属性公式计算，判定方式在卡牌中声明。

## 六、伤害与生命值

- 伤害先由护甲/减伤减免，再从 HP 中扣除
- HP 降至 0：角色**无法战斗**（不是死亡——除非剧情明确要求）
- HP 降至 25% 以下：GM 可描述受伤的视觉效果（血迹、踉跄、呼吸困难）

## 七、敌我差异

| 项目 | 角色 | 敌人 |
|------|------|------|
| HP 公式 | 生理耐受 × 3 + 10 | 生理耐受 × 2 + tier × 3 |
| 防御 DC | 与敌相同 | 与角色相同 |
| SP 上限 | 固定 6 | tier + 1 |
| 先攻 | 与敌相同 | 与角色相同 |
| 伤害 | 物理强度 / 源石技艺适应性 | 同左（由属性决定） |

角色 HP 高于同属性敌人，体现代入感——玩家的干员比敌人更耐打。

## 八、特殊规则

### 掩体

- 半掩体：远程物理攻击判定 -2
- 全掩体：远程物理攻击判定 -4，但自身也无法攻击

### 高地

- 从高处攻击低处：远程攻击判定 +2
- 从低处攻击高处：远程攻击判定 -2

### 夹击

- 两个角色/敌人从正反方向夹击同一目标：攻击判定 +2

### 状态效果

- **失衡**：本回合无法移动
- **恐惧**：本回合只能移动（远离恐惧源）
- **困惑**：攻击目标随机（包括友方）
- **眩晕**：本回合无法执行任何行动
