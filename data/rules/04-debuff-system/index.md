# 负面效果系统 (Debuff System)

本文件定义了所有可能影响角色的负面效果（debuff），以及它们如何与"失败后事件roll点"机制互动。

## 一、概述

### 何时应用Debuff

1. **失败后roll点失败** - 动态偏离失败后，LLM 进行补充roll判定时，失败则应用debuff
2. **重大失败** - 大失败(roll=1)时，自动应用更严重的debuff
3. **剧情触发** - 特定场景的预设事件可能自动应用debuff

### Debuff的性质

- **临时性** - Debuff 持续若干个行动轮（通常1-5回合）
- **可叠加** - 同类debuff可以叠加，强化效果
- **互相影响** - 某些debuff组合会产生联动效果
- **可清除** - 通过特定行动、消耗资源、或寻求帮助可清除debuff

---

## 二、Debuff 池

### 分类

所有debuff按**严重程度**分为三档：

| 档位 | 特征 | 持续时间 | 应用场景 |
|------|------|--------|--------|
| **轻度** (Level 1) | 轻微困扰，可继续行动 | 1-2回合 | 常规失败的小代价 |
| **中度** (Level 2) | 明显影响，需要应对 | 2-5回合 | 重要失败或连续失败 |
| **重度** (Level 3) | 严重影响，需要专门处理 | 3-8回合 | 大失败或高风险行为失败 |

## 三、Debuff 详表

### A. 身体状态 (Physical)

#### PH-001: 轻伤 (Minor Wound) — Level 1
- **触发条件** - 涉及身体对抗的失败（如被追捕、被推搡）
- **效果** - 后续涉及灵活性或耐力的判定 -2
- **持续** - 2回合
- **清除** - 医疗照顾、短暂休息
- **剧情效果**
  - "你的左臂有点疼，被那个警卫的枪托擦中了。"
  - "走路时能感觉到腿上的擦伤。"

#### PH-002: 重伤 (Serious Wound) — Level 2
- **触发条件** - 大失败涉及身体伤害、或多次轻伤的叠加
- **效果** - 涉及灵活性/耐力的行动需要额外判定，或者基础判定 -3
- **持续** - 3-5回合
- **清除** - 医生治疗、充分休息
- **剧情效果**
  - "肋骨可能有裂纹。每次深呼吸都会疼。"
  - "你需要找到医疗援助，否则伤口可能恶化。"

#### PH-003: 中毒 (Poisoned) — Level 2
- **触发条件** - 接触有毒物质、被有毒生物攻击
- **效果** - 力量判定 -3，每回合需进行体质check防止更坏后果
- **持续** - 4-6回合
- **清除** - 解毒剂、专业医疗
- **剧情效果**
  - "你能感觉到毒素在血液里蔓延。手开始发抖。"
  - "你的视线有些模糊。需要尽快找到医疗。"

#### PH-004: 疲惫 (Exhaustion) — Level 1
- **触发条件** - 高体力消耗行为的失败、连续行动
- **效果** - 所有判定 -1，但可以在休息后快速消除
- **持续** - 1-2回合
- **清除** - 短暂休息（15分钟）、进食、睡眠
- **剧情效果**
  - "你感到疲惫不堪。呼吸有点急促。"
  - "需要找个地方缓一缓。"

---

### B. 心理状态 (Mental)

#### ME-001: 惊吓 (Threatened) — Level 1
- **触发条件** - 遭遇突然威胁、被追捕、被发现
- **效果** - 下一个判定 -1；如果再次触发同类威胁，升级为"恐惧"
- **持续** - 1回合
- **清除** - 逃脱威胁、得到安心、同伴安慰
- **剧情效果**
  - "你的心跳加速。他们可能发现了你。"
  - "要冷静。要冷静。"

#### ME-002: 恐惧 (Fear) — Level 2
- **触发条件** - 重复被威胁、或面对极其危险的情况
- **效果** - 社交判定 -2，勇气相关判定 -3；可能主动选择逃离
- **持续** - 2-4回合
- **清除** - 消除威胁、深呼吸、得到强有力的支持
- **剧情效果**
  - "你的双手在发抖。那东西... 会杀了你。"
  - "理性告诉你需要逃离这里。"

#### ME-003: 困惑 (Confused) — Level 1
- **触发条件** - 收到矛盾信息、被欺骗成功、突然环境变化
- **效果** - 信息判定/推理判定 -2
- **持续** - 1-2回合
- **清除** - 得到澄清、冷静思考
- **剧情效果**
  - "等等... 这不对劲。什么地方出了问题？"

#### ME-004: 愤怒 (Enraged) — Level 2
- **触发条件** - 严重背离、被侮辱、看到不公正的事情
- **效果** - 冷静判定 -3；可能导致鲁莽行为；社交判定 -2
- **持续** - 2-3回合
- **清除** - 冷静下来、得到理由为什么不应该这样做
- **剧情效果**
  - "血冲上你的头顶。你的拳头不由自主地握紧。"
  - "一切都变成了红色。"

### C. 社交声誉 (Social)

#### SO-001: 被怀疑 (Distrusted) — Level 1
- **触发条件** - 欺骗被识破、行为不一致、说谎失败
- **效果** - 该NPC对你的社交判定 +3DC；可能拒绝合作
- **持续** - 5-8回合（场景级别，可能跨越多个地点）
- **清除** - 证明自己、时间冷却、做出补偿
- **剧情效果**
  - "她的眼神冷了下来。'你刚才在骗我？'"
  - "在这个人眼里，你已经失去信任。"

#### SO-002: 被标记 (Marked) — Level 2
- **触发条件** - 敌对势力记住了你、被通缉、身份泄露
- **效果** - 与该势力的所有成员判定DC +2；可能被追捕；其他该势力的成员会认出你
- **持续** - 8-12回合（长期，可能跨越多个场景）
- **清除** - 逃离该地区、伪装自己、消除证据
- **剧情效果**
  - "你听到身后的通讯器："那就是那个人。罗德岛的间谍。""
  - "现在你在这个城市不安全了。"

#### SO-003: 名誉受损 (Reputation Damage) — Level 2
- **触发条件** - 公开失败、被证明不可靠、背弃承诺被传播
- **效果** - 所有陌生NPC的初始态度 -1档（从"中立"变"冷漠"等）；相关势力的判定DC +1
- **持续** - 10-15回合（长期）
- **清除** - 做出显著补偿、时间流逝、英勇行为
- **剧情效果**
  - "某个商人摇头拒绝了你。'我听说过你的事。不足为信。'"
  - "你在这座城市的名声受损了。"

### D. 物质状态 (Material)

#### MA-001: 缺乏资源 (Resource Depletion) — Level 1
- **触发条件** - 行为中消耗了关键物品、被没收、损坏
- **效果** - 后续没有该资源的行为DC +2
- **持续** - 直到重新获得资源
- **清除** - 重新获取资源、找到替代品
- **剧情效果**
  - "你的弹药在那次对抗中用完了。"
  - "没有工具，你无法进行这个操作。"

#### MA-002: 被拖累 (Encumbered) — Level 1
- **触发条件** - 打破隐蔽、留下明显痕迹、困境中无法快速移动
- **效果** - 移动/逃脱判定 -2
- **持续** - 1-3回合（直到摆脱或找到掩护）
- **清除** - 丢弃物品、逃脱追捕、躲藏
- **剧情效果**
  - "你身上的装备太重了。你无法快速移动。"
  - "脚步声越来越近。你需要加速，但身体不配合。"

---

### E. 环境状态 (Environmental)

#### EN-001: 被困 (Trapped) — Level 2
- **触发条件** - 试图离开/逃脱失败、被包围、陷入困局
- **效果** - 所有逃脱判定 +2DC；如果需要帮助才能逃脱，则需要引入新NPC或消耗资源
- **持续** - 直到逃脱或接受当前局面
- **清除** - 成功逃脱、获得帮助、局面改变
- **剧情效果**
  - "你意识到自己被包围了。没有明显的出口。"
  - "现在你处于守卫的包围中。"

#### EN-002: 引起注意 (Noticed) — Level 1
- **触发条件** - 隐蔽失败、行为过于醒目、被发现但没有被直接威胁
- **效果** - NPC对你的警惕 +1档；随意搜索判定 -1
- **持续** - 2-3回合，或直到离开该地区
- **清除** - 离开、消除疑虑
- **剧情效果**
  - "那个安保的目光在你身上停留了太久。他可能注意到什么了。"

---

### F. 关系状态 (Relational)

#### RE-001: 欠债 (In Debt) — Level 2
- **触发条件** - 被迫接受帮助、承诺将来的行为、被救出但有附带条件
- **效果** - 该NPC或势力可以在后续剧情中要求你还债；你必须完成或付出代价
- **持续** - 直到偿还债务
- **清除** - 完成所承诺的事、支付代价、局面改变
- **剧情效果**
  - "那个人救了你一命。现在你欠他一个人情。"
  - "当他开口要求什么时，你很难拒绝。"

#### RE-002: 被利用 (Compromised) — Level 3
- **触发条件** - 秘密被掌握、证据被握住、陷入两难困境
- **效果** - 该掌握秘密的NPC可以强制某些行为；影响相关判定；后续需要特别处理才能摆脱
- **持续** - 直到秘密不再有价值或失效
- **清除** - 揭示秘密、获得反制证据、改变局面
- **剧情效果**
  - "他拿出了那份文件。你知道如果这东西被公开..."
  - "现在你成了他的工具。"

## 四、失败后Roll点机制

### 应用场景

当动态偏离/预设偏离点**失败**时，触发"失败后事件"：

```
玩家行为失败（total < DC）
  ↓
LLM 选择基本失败叙事
  ↓
判断是否需要"升级风险" ——
根据情境的严重程度、失败的程度（roll多少低于DC）
  ↓
如果需要升级 → 执行"失败后roll点"
```

### Roll点规则

#### 触发条件

**满足以下任一条件时，进行失败后roll点**：

1. 失败幅度大（total 比 DC 低 5+ ）
2. 失败行为涉及高风险（如潜入、欺骗权威、对抗）
3. LLM判定"失败本身会导致新麻烦"
4. 大失败（roll = 1）—— 自动进行，且+额外修正

#### Roll计算

```
失败后Roll = d20 + 角色属性修正 + 情境修正 - 负面惩罚值

其中：
- d20: 标准20面骰
- 角色属性修正: 取与行为最相关的属性
  例如：
    潜入失败 → 敏捷属性
    欺骗被识破 → 魅力属性
    武力对抗失败 → 力量属性
  修正范围通常 -3 to +3

- 情境修正:
  安全的失败 (e.g. 失手掉了东西) → +2
  中等风险的失败 (e.g. 被看到) → 0
  高风险的失败 (e.g. 被追捕) → -2
  致命风险的失败 (e.g. 面对武装敌人) → -5

- 负面惩罚值:
  常规失败 → -2
  严重失败（roll < DC-5） → -3
  大失败（roll = 1） → -5
```

#### 结果判定

| 结果 | 条件 | 后果 |
|------|------|------|
| **大成功** | Roll = 20 | 虽然行为失败，但发生了意外好运。避免debuff，获得1个隐藏机会 |
| **成功** | Roll ≥ 12 | 避免最坏的结果。无debuff应用；叙事保持在"失败"范围内 |
| **失败** | 6 ≤ Roll < 12 | 失败导致中等后果。应用1个**中度debuff (Level 2)** |
| **大失败** | Roll < 6 | 失败导致严重后果。应用1个**重度debuff (Level 3)** 或多个中度debuff |

#### 叙事案例

**示例1：潜入被发现**

```
行为：博士试图在不被发现的情况下进入禁区
原始roll：8（DC 14）→ 失败
失败幅度：-6 → 触发失败后roll点

失败后Roll：
- d20 = 14
- 敏捷属性修正 = +1
- 情境修正 = -2（被发现的风险）
- 负面惩罚值 = -3（严重失败）
- 总计 = 14 + 1 - 2 - 3 = 10

结果：失败（6-12范围）
应用debuff：SO-002 被标记 (Marked) — Level 2

叙事：
"你试图悄悄地穿过走廊，但一个摄像头在你经过时转动了。警报还没有响起，
但你听到对讲机的声音：'走廊东侧有可疑人员移动。派队伍去检查。'

现在整个安保系统都知道有入侵者，虽然他们不确定你具体在哪——但你的形象
已经被记录。这个设施的所有安保人员现在都会注意你。"
```

**示例2：欺骗被识破 — 大成功逆转**

```
行为：骗守卫说自己是设施的维修工人
原始roll：7（DC 15）→ 失败
失败后Roll：
- d20 = 20 ✓ 大成功！
- 魅力属性修正 = +2
- 情境修正 = 0
- 负面惩罚值 = -2
- 总计 = 20 + 2 + 0 - 2 = 20

结果：大成功

叙事：
"守卫看穿了你的说辞。他正要按警报按钮——突然，他的对讲机响了。

守卫的手停在了按钮上。'认真的？'他小声骂了一句，转身快步离开去支援。

```

**示例3：武力对抗失败 — 连锁debuff**

```

原始roll：5（DC 12）→ 失败
失败后Roll：
- d20 = 3（糟糕的roll）

- 情境修正 = -5（面对武装敌人）
- 负面惩罚值 = -5（大失败，roll=1）
- 总计 = 3 + 1 - 5 - 5 = -6

结果：大失败

应用debuff组合：
- PH-002 重伤 (Serious Wound) — Level 2
- ME-002 恐惧 (Fear) — Level 2
- SO-002 被标记 (Marked) — Level 2

叙事：
"你被第一个守卫的警棒直接击中了肋骨。疼痛像闪电一样穿过你的身体，

背后传来呼救声和急促的脚步声。你们被看到了。而且你能感觉到，你的身体

后续剧情钩子：
- 需要医疗处理肋骨伤

- 该设施的安保现在知道了你的样子
```

## 五、Debuff 清除与交互

### 清除方式

#### 1. **主动清除**
- 通过特定行动（如医疗照顾、心理安慰、获得资源）
- LLM在叙事中提供清除机会

#### 2. **时间清除**
- 回合数到期自动消除
- 关键节点推进时可能加速消除

#### 3. **剧情清除**
- 承诺的行为完成后清除（如欠债还清）
- 外界事件改变使debuff失效（如被标记状态下政权更替）

### Debuff叠加规则

同一debuff可以叠加：
- 每次叠加强化效果 1.5倍
- 例如：两个"被怀疑"debuff = DC +4.5（四舍五入 +5）
- 不同debuff可以并存

### Debuff联动效果

某些debuff组合产生增强:

| 组合 | 联动效果 |
|------|--------|
| 重伤 + 恐惧 | 移动速度判定额外 -2 |
| 被标记 + 名誉受损 | 新的陌生NPC自动警惕 |
| 中毒 + 疲惫 | 每回合需额外体质check |
| 欠债 + 被利用 | 债权人可以要求更高代价 |

## 六、LLM 使用指南

### 何时应用失败后roll点

**应该应用** ✓
- 玩家试图对抗权威人物，结果失败
- 潜入/隐蔽行为失败被发现
- 欺骗/社交判定严重失败
- 高风险行为的失败（可能改变剧情或引发新问题）

**不应该应用** ✗
- 即兴互动失败（LLM直接决定结果，无roll）
- 命中预设偏离点且有明确失败结果的
- 非常低风险的失败（如失手掉了东西）

### 编写Debuff相关叙事的建议

1. **具体化** - 不要笼统地说"你获得了debuff"，而是在叙事中体现
   - 不好："你获得了'被标记'debuff"
   - 好："那个安保员拍了一张你的照片，放到通讯设备里。'广播，所有人注意...'"

2. **给出应对路线** - 每个debuff出现时暗示可能的清除方式
   - "你需要找到医疗帮助"（暗示医疗清除）
   - "你需要证明自己的诚意"（暗示行为清除）
   - "也许躲一阵子就没人记得了"（暗示时间清除）

3. **跟踪debuff** - 在后续叙事中持续提及活跃的debuff
   - "你的肋骨还在疼，每步都提醒你之前的失败"
   - "在经过安保时，他们的目光滑过你，但停留了一下——他们在查看名单"

## 七、Debuff 配置模板

当LLM需要创建**情境特定的临时debuff**时，使用此模板：

```yaml
debuff_id: "CUSTOM-[number]"
name: "[中文名称]"
level: "[Level 1/2/3]"
category: "[Physical/Mental/Social/Material/Environmental/Relational]"
trigger: "[触发条件描述]"
effect: "[机制影响]"
duration: "[持续时间]"
removal: "[清除方式]"
narrative_hook: "[情节钩子]"
can_stack: "[布尔值]"
```

示例：
```yaml
debuff_id: "CUSTOM-101"
name: "被怀疑是间谍"
level: "Level 2"
category: "Social"
trigger: "在商业联合会总部被发现携带罗德岛机密文件"
```
