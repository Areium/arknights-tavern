# 稀有度分级体系

## 概述

在本作中，几乎所有可被获取或遭遇的实体都按照统一的六星稀有度体系进行分级。这套体系既是**游戏机制的基础**（决定卡牌数值上限、物品效果强度），也是**叙事权重的标尺**（五星及以上的实体自带剧情影响力）。

分级适用于以下系统：
- **角色**：干员的潜力上限和稀有程度
- **卡牌**：技能强度、SP 消耗、是否附带剧情影响
- **物品**：装备品质、效果强度、是否可成长
- **Buff / Debuff**：效果等级、清除难度
- **事件**：稀有事件的触发概率和回报

## 六级定义

### 一星：粗制（Crude）

| 属性 | 内容 |
|------|------|
| **颜色** | 灰色 `#808080` |
| **稀有度** | 极为常见，几乎无获取门槛 |
| **力量上限** | 最低。仅能满足最基础的功能需求 |
| **卡牌 SP** | 1 |
| **属性参与数** | 1 个属性参与公式计算 |
| **剧情权重** | 无。不影响剧情走向 |

**说明**：
一星代表该实体仅具备最基本的功能性。一件一星物品可以正常使用但不会有任何额外效果；一张一星卡牌是最基础的攻击或防御动作；一个一星 Buff 提供微量加成。一星实体不会在任何判定中提供优势，也不会被 NPC 特别关注。

**典型范例**：
- 卡牌：「源石技艺·凝」——最基础的法术攻击
- 物品：一支普通的钢笔、一件无防护功能的衣物
- Buff：微弱的感知提升（+1 修正，持续 1 回合）

---

### 二星：普通（Common）

| 属性 | 内容 |
|------|------|
| **颜色** | 绿色 `#4CAF50` |
| **稀有度** | 常见，可通过基础途径稳定获取 |
| **力量上限** | 略高于基础水平，开始出现辅助性效果 |
| **卡牌 SP** | 2 |
| **属性参与数** | 1-2 个属性参与公式计算 |
| **剧情权重** | 极低。可能在特定情境下被提及 |

**说明**：
二星代表该实体已经具备了一定的实用价值。经过一定训练或基础投入后可以稳定发挥效果。二星卡牌开始出现增益/削弱类的辅助效果（而非纯粹的攻防）；二星物品开始有微弱的附魔或强化特性。

**典型范例**：
- 卡牌：「法术增幅」——下一次法术伤害 ×1.5
- 物品：一把保养良好的制式武器、一件轻质护甲
- Buff：清晰头脑（战术规划 +2，持续 2 回合）

---

### 三星：精良（Refined）

| 属性 | 内容 |
|------|------|
| **颜色** | 蓝色 `#2196F3` |
| **稀有度** | 非随处可见，需要一定条件才能获得 |
| **力量上限** | 有明显的战术价值，可以改变局部战况 |
| **卡牌 SP** | 2-3 |
| **属性参与数** | 2 个属性参与公式计算 |
| **剧情权重** | 低。可能引出支线对话或小型情报 |

**说明**：
三星是"精良"的起点。三星实体在各自的领域中已经具备不可忽视的存在感。三星卡牌可以影响战场态势（场地效果、护盾、多目标攻击）；三星物品通常带有明确的特殊效果或属性加成；三星角色拥有标志性的个人能力。在战斗中，三星卡牌的使用时机常常决定了局部战斗的走向。

**典型范例**：
- 卡牌：「源石共鸣」——创造提升法术效果的领域；「情绪感知」——被动感知他人情绪
- 物品：一把带有属性附魔的武器、一件能抵抗特定元素伤害的防具
- 角色：罗德岛精英干员的中位数水平

---

### 四星：稀有（Rare）

| 属性 | 内容 |
|------|------|
| **颜色** | 紫色 `#9C27B0` |
| **稀有度** | 稀有，需要通过特定任务、战斗或关系获取 |
| **力量上限** | 强大，可显著改变战斗节奏或社交态势 |
| **卡牌 SP** | 3-4 |
| **属性参与数** | 2 个属性参与（加权平均） |
| **剧情权重** | 中。可能解锁支线任务或改变 NPC 态度 |

**说明**：
四星是"稀有"的标尺——大多数角色终其一生都未必能掌握一项四星能力。四星卡牌通常是角色的核心战斗手段（范围清场、强力单体、光环效果）；四星物品往往有独特的来历和不可替代的功能。四星实体在剧情中会被 NPC 主动注意和评价——"那把剑"或"那个技巧"可能成为角色的标志。

**典型范例**：
- 卡牌：「精神爆发」——情感冲击类法术，阿米娅的核心输出卡牌；「法术扩散」——范围法术清场
- 物品：一件有名字的武器（如陈的"赤霄"）、一件有家族历史的护甲
- 角色：经验丰富的精英干员、小有名气的独立佣兵

---

### 五星：史诗（Epic）

| 属性 | 内容 |
|------|------|
| **颜色** | 金色 `#FFD700` |
| **稀有度** | 极为稀有，往往需要突破重大剧情节点才能获得 |
| **力量上限** | 极强，使用后可改变整场战斗的格局 |
| **卡牌 SP** | 5-6 |
| **属性参与数** | 2-3 个属性参与计算 |
| **剧情权重** | **高。自带剧情影响，使用后会在世界中留下痕迹** |

**说明**：
五星是"史诗"的领域。一张五星卡牌不仅仅是战斗工具——它的每一次使用都在向世界宣告使用者的存在。五星卡牌必须附带**剧情影响**（对环境的改变、对在场角色的影响、对使用者的代价、情报扩散）。五星物品通常是传承级别的装备，有着完整的来历故事。五星角色是能够在历史上留名的人物。

**使用五星卡牌时，必须回答以下问题**：
1. 使用后环境会发生什么变化？（范围、持续时间、可被谁观察到）
2. 谁会感知到这股力量？（列出具体的势力/角色类型）
3. 使用者付出什么代价？（立即的 + 长期的）
4. 如果连续使用会发生什么？（累计效应）
5. 这次使用是否会改变其他角色对使用者的态度？

**典型范例**：
- 卡牌：「影霄」——解放魔王之力，周围源石活性大幅提升，可能引起第三方势力注意；「不灭之壁」——震撼人心的守护意志，在场所有友方信任度永久提升
- 物品：一件被历史铭记的武器（如临光的骑士铠甲）、一件与重大事件关联的信物
- 角色：一方势力的领袖、传说中的战士、罗德岛的核心决策层

---

### 六星：传说（Legendary）

| 属性 | 内容 |
|------|------|
| **颜色** | 橙色 `#FF5722` |
| **稀有度** | 独一无二。通常是整个剧情线的高潮节点产物 |
| **力量上限** | 终极。使用后可彻底改变一场战斗乃至一条剧情线的走向 |
| **卡牌 SP** | 8-10（且通常有额外触发条件） |
| **属性参与数** | 3 个属性参与计算，或享受 ×3.0 稀有度系数 |
| **剧情权重** | **极高。使用后产生不可逆的永久剧情后果** |

**说明**：
六星代表"传说"——不是每个人都能达到的境地，而是被命运选中或被历史记住的少数。六星卡牌不只是一次攻击或一次防御——它是一次**世界观的表态**。使用六星卡牌意味着使用者愿意承受**不可逆的永久代价**（属性永久变化、关系永久改变、世界线分支）。六星物品往往本身就是一件剧情核心道具。六星角色……与其说是"稀有"，不如说是"承载着一条完整的剧情线"。

**六星卡牌的代价设计原则**：
- 必须是**永久的**——不能通过休息或常规手段恢复
- 必须是**有叙事意义的**——不只是"扣 5 点血"，而是"颈部源石结晶扩大 1cm，所有萨卡兹族人感知到魔王气息"
- 必须在**后续剧情中持续体现**——代价会在之后的所有场景中被提及和引用
- 如果是正面效果（如属性提升），必须伴随等量的负面代价（如器官损伤、寿命缩短、被某个势力标记）

**典型范例**：
- 卡牌：「奇美拉觉醒」——双血脉完全觉醒，全属性+2 三回合，但使用后生理耐受永久-1，且各方势力获知"魔王继承者"情报
- 物品：一件能改写世界规则的遗物（如"魔王之冠"）、一件与整个文明的命运绑定的圣物
- 角色：博士（战术规划的极限代表）、传说时代的幸存者、背负整个种族命运的人物

## 各系统的稀有度应用

### 卡牌系统

| 稀有度 | SP | 属性数 | 公式类型 | 剧情影响 |
|--------|-----|--------|---------|---------|
| ★ 粗制 | 1 | 1 | 单属性 | 无 |
| ★★ 普通 | 2 | 1-2 | 简单加和 | 无 |
| ★★★ 精良 | 2-3 | 2 | 加权平均 | 无 |
| ★★★★ 稀有 | 3-4 | 2 | 加权平均 | 无 |
| ★★★★★ 史诗 | 5-6 | 2-3 | 多属性加权 | **有**——环境、关系、代价 |
| ★★★★★★ 传说 | 8-10 | 3+系数 | 多属性 × 系数 | **有**——不可逆永久后果 |

### 物品系统

| 稀有度 | 典型效果 | 示例 |
|--------|---------|------|
| ★ 粗制 | 无额外效果，仅基础功能 | 普通武器、日常用品 |
| ★★ 普通 | 微弱属性加成（+1） | 制式装备、消耗品 |
| ★★★ 精良 | 明确属性加成（+2）或特殊效果 | 附魔武器、防护衣物 |
| ★★★★ 稀有 | 强属性加成（+3）或独特功能 | 有名号的装备 |
| ★★★★★ 史诗 | 大幅度加成（+4-5）或改变规则级效果 | 传承装备、剧情信物 |
| ★★★★★★ 传说 | 颠覆级效果，通常直接与主线剧情绑定 | 世界规则相关遗物 |

### Buff / Debuff 系统

| 稀有度 | 效果等级 | 持续回合 | 清除难度 |
|--------|---------|---------|---------|
| ★ 粗制 | ±1 | 1 | 自动清除 |
| ★★ 普通 | ±2 | 1-2 | 简单清除 |
| ★★★ 精良 | ±3 | 2 | 需主动清除 |
| ★★★★ 稀有 | ±4 | 2-3 | 需特定条件清除 |
| ★★★★★ 史诗 | ±5 | 3+ | 需剧情事件清除 |
| ★★★★★★ 传说 | ±6 以上 | 永久 | 不可清除（或需主线级事件） |

### 角色系统

角色的稀有度标识其**潜力上限**和**剧情重要性**，而非单纯的战斗力：

| 稀有度 | 角色类型 | 卡牌数量 | 剧情角色 |
|--------|---------|---------|---------|
| ★ 粗制 | 普通民众、路人 | 仅通用卡牌 | 背景板 |
| ★★ 普通 | 初级干员 | 通用卡牌 + 1 张专属 | 支线配角 |
| ★★★ 精良 | 精英干员 | 通用 + 2-3 张专属 | 支线核心 |
| ★★★★ 稀有 | 核心干员 | 通用 + 3-4 张专属 | 主线重要角色 |
| ★★★★★ 史诗 | 领袖级干员 | 通用 + 4-5 张专属 | 主线关键角色 |
| ★★★★★★ 传说 | 传说级人物 | 通用 + 5+ 张专属 | 剧情核心推动者 |

## 稀有度与叙事

### 五星以上：从"战斗工具"到"剧情推动器"

五星和六星实体的核心区别不在于数值——而在于**使用后世界会记住它**。

- 一张四星卡牌「法术扩散」使用后，战斗继续，无人提及。
- 一张五星卡牌「影霄」使用后，周围的源石活性改变了，某些人感知到了"异常的力量波动"，这件事可能在下一次与第三方势力的交涉中被提及。
- 一张六星卡牌「奇美拉觉醒」使用后，矿石病永久恶化，萨卡兹族人感知到"魔王"的气息，凯尔希要求全面体检，各方势力更新了关于"魔王继承者"的情报档案——这些后果在**此后的所有场景中持续发酵**。

### GM 判定参考

当玩家使用五星以上卡牌或遭遇五星以上实体时，GM 应额外描述：
1. **环境的反应**：空气中有什么不同？温度变化？光线的扭曲？周围物体的异变？
2. **旁观者的反应**：谁注意到了？他们的表情、动作、低语是什么？
3. **代价的体现**：使用者的身体、装备或精神状态发生了怎样的可观测变化？
4. **后续影响**：在下一个场景/剧情节点中，这次使用会以什么方式被重新提起或产生影响？
