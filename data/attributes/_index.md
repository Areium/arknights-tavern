# 等级体系
# ==============================================================================
# 每个属性使用 1-10 级细分量表，每级对应一个 d20 roll 修正值。
# 同时标注明日方舟综合体检测试的五档评级（缺陷/普通/标准/优良/卓越）。
#
# 基础公式：d20 + 属性修正 + 情境修正 vs 难度等级（DC）
# ==============================================================================

## 等级-修正-评级对照表

| 等级 | 修正 | 方舟评级 | 叙事含义 |
|------|------|---------|---------|
| 1 | **-3** | 缺陷 | 严重缺陷——d20 出 20 才可能成功 |
| 2 | **-2** | 缺陷 | 明显不足——简单任务也充满不确定性 |
| 3 | **-1** | 普通 | 稍逊常人——需要情境加成才可靠 |
| 4 | **-1** | 普通 | 略低于平均——勉强够用，不宜主攻此领域 |
| 5 | **0** | 标准 | 基准——健康成年人的正常水平，全靠 d20 的运气 |
| 6 | **+1** | 标准 | 略高于平均——简单判定大概率成功 |
| 7 | **+1** | 优良 | 明显优势——中等难度判定有较高成功率 |
| 8 | **+2** | 优良 | 精英水平——困难任务也有相当把握 |
| 9 | **+3** | 卓越 | 传奇水平——极端困难的挑战也能应对 |
| 10 | **+4** | 卓越 | 神话水平——常规 DC 几乎不可能失败 |

## 修正值公式

```
level_to_modifier = {1:-3, 2:-2, 3:-1, 4:-1, 5:0, 6:+1, 7:+1, 8:+2, 9:+3, 10:+4}
```

## 判定公式

```
最终结果 = d20 + 属性修正 + 情境修正

结果判定：
  大成功（d20 = 20）：自动成功，且获得额外收益
  成功（最终结果 ≥ DC）：行为达成，按预期执行
  失败（最终结果 < DC）：行为未达成，世界做出反应
  大失败（d20 = 1）：自动失败，且附带新的麻烦
```

## 情境修正参考

| 情境 | 修正值 | 示例 |
|------|--------|------|
| 极度有利 | +3 ~ +5 | 有详细情报、内应协助、目标不设防 |
| 有利 | +1 ~ +2 | 有准备时间、队友配合、环境优势 |
| 正常 | 0 | 标准的判定条件 |
| 不利 | -1 ~ -2 | 时间紧迫、信息不足、环境干扰 |
| 极度不利 | -3 ~ -5 | 重伤状态、被包围、目标在最高戒备下 |

## 多属性判定

当一项行为涉及多个属性时：

1. **主属性**：取与行为最直接相关的属性修正（全值）
2. **副属性**：取第二相关属性的修正值的一半（向下取整）
3. **最终修正 = 主属性修正 + floor(副属性修正 / 2)**

示例：躲避+说服 = 战场机动修正（全值）+ floor(魅力修正 / 2)
